# 群星挂机 · 从坠落到银河

低资源消耗的挂机策略游戏 —— 从几名坠毁殖民者(环世界式)发展到火箭升空,走向星辰(群星式)。
当前为 **M1 演示版:第一幕 · 坠落殖民地**。

## 运行

```bash
npm install          # 已装则跳过
npm run dev          # 浏览器开发模式 → http://localhost:5173
npm run tauri dev    # 桌面应用(Tauri,需要 Rust 工具链)
npm run build        # 生产构建(dist/)
```

## 玩法(M2)

- **方向自治**:顶栏「🧭 方向」胶囊选择方向,殖民地自动调配岗位、建造与研究;自治 A0-A4 逐级解锁自动化
- **全球争霸**(第一幕重构):星球地表地图,视野雾随扩张揭开;殖民地作为据点图标演化(🛖木屋→🏘️叠房→🏰城堡→🏙️城市→🌆都市圈);扩张占领领土、自动铺设道路;6 个势力外交/边境摩擦/战争/吞并,最终统一全球
- 顶部资源条显示资源与每秒净收入;支持 1x/2x/4x/暂停
- 研究:五线 30 项科技(第一幕)+ 方向自动选线,可手动锁定
- 事件:袭击/补给舱/天灾等 + 抉择事件(90 秒未答自动决定)
- 离线收益:60% 效率,上限 8 小时
- 星球视窗:旋转星球小组件

## 第一幕 → 第二幕 三门槛

统一全球(政治) + 太空计划完成(空间站 4 舱段 + 轨道船坞造船能力 + 太空电梯) + 科研船/工程船 → 全部满足才进入第二幕

## 太空计划(第一幕终点,参考真实航天史)

- 17 个里程碑任务:探空火箭×3(戈达德/V-2) → 卫星(斯普特尼克1号) → 生命舱(莱卡) → 载人飞行(东方1号/水星) → 舱外活动(双子座4号) → 交会对接(双子座8号) → 空间站舱段×4(礼炮号/ISS) → 轨道船坞 → 飞船模块×4(推进/燃料/居住/指挥)
- 每次发射消耗材料,有基础成功率 + 可靠性成长(成功+4%、失败+6%教训,上限+30%);失败损失材料、挫伤士气,载人任务失败会重伤宇航员
- 空间站/飞船组装进度以模块槽位展示;飞船四模块齐全即可启航
- 发射有准备冷却(60~150 秒),发射台建筑为轨道任务前置

## 第二幕 · 母星系(M3 框架)

- 飞船启航后进入母星系时代,主视图切换为**星系图**:恒星 + 7 颗行星公转 + 轨道设施 + 舰队
- 新资源:**合金**(采矿站产出)、**燃料**(精炼站产出);新增第二幕科技五线 24 项(轨道/资源/自动化/能源/舰队)
- 轨道设施随科技自动部署(采矿站/精炼站),舰队随科技自动造船(护卫舰→驱逐舰→巡洋舰,消耗合金)
- 自治 A4:AI 调度中枢 → 自动扩张轨道设施;舰队军力在星系图与详情面板实时显示
- 点击行星/设施/舰队查看详情;殖民地地面仍在后台持续运转(可切换「地面」视图)
- 第二幕专属事件:小行星撞击/海盗来袭/恒星耀斑/富矿发现/星际商队
- **第二幕终点**:研究「超空间引擎」→ 攒够 5000 合金 + 3000 燃料 → 跃迁进入第三幕

## 第三幕 · 银河时代(M4 框架)

- 跃迁后进入银河图:12 个恒星系 + 超空间航道网络,家园系统受我方控制
- **三色科技卡池**:物理(舰队军力加成)/ 社会(占领星系上限)/ 工程(战列舰→泰坦→巨像→戴森球→环世界)
- 星系扩张:舰队沿航道自动占领邻接星系(消耗合金,上限由社会科技决定)
- **天灾终局**:跃迁 30 分钟后「肃正协议」降临,舰队军力需超越其强度;击败后银河统一
- **转生**:击败天灾后开启新纪元,保留声望,起始资源 +50%/级

## 性能目标

- 空闲 CPU ≤2%、内存 ≤200MB;模拟与渲染分离,tick 为纯函数
- 地图/UI 用 Canvas 2D,星球特写为程序化逐像素球体(零依赖、无 WebGL)

## 目录

```
src/core/      模拟引擎(tick/事件/存档/数值) — 无 DOM 依赖,可 headless 测试
src/content/   游戏内容数据(建筑/科技/特性/名称)
src/render/    Canvas 渲染器(殖民地/旋转星球)
src/ui/        React 组件
scripts/       gen-icon.mjs(图标生成) / sim.ts(数值模拟)
src-tauri/     Tauri 桌面壳(主窗口 + 星球视窗小组件)
```
