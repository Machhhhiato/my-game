# Always Game 世界运行规则

## 1. 科技发展规则

1. 科技不是等级条。每项技术必须回答：它第一次让社会能做什么、依赖什么、解锁什么实体或制度、带来什么维护/风险/社会后果。
2. 发展链固定为：**知识与试验 → 设备/工艺 → 产业与维护 → 服务覆盖/劳动组织 → 制度与权利 → 日常生活变化**。
3. 主干突破提供新能力；分支提供效率、韧性或扩散路线；分级提供可靠性、规模、安全或制度化。不得用“永久 +1%”代替现实意义。
4. 高级科技需要跨领域条件和已运行工程证明。没有材料、能源、测量、教育、行政、物流或设施基础，理论可存在，规模化能力不可直接获得。
5. 遗产技术可被发现、译读、修复和复现，但不能跳过本时代可维持的供应链。

## 2. 时间线规则

1. 时代节点是文明能力与冲突的锚点，不是所有战役在同一年发生的脚本开关。
2. 可变的是达成速度、路径、事故、伤亡、社会代价、盟友和局部结果；不可随意删除的是导致下一时代成立的能力链和历史问题。
3. 任何跨阶段跃迁必须留下前一阶段解决不了、但下一阶段必须承担的新矛盾。
4. 速度提升不等于社会同步成熟：例如火星工程、星际航线、戴森工程和银河统合都必须有试验、法规、救援、维护和代表权的滞后期。

## 3. 社会演化规则

1. 人口不是抽象劳动力。增长、迁徙、照护、教育、居住、健康、伤亡、资格与代际机会都影响可用能力。
2. 每次生产力提升都要回答：谁获益、谁失业或迁移、谁承担污染/工伤/等待、谁获得新教育和迁徙机会。
3. 阶层冲突应来自岗位、资源权、居留权、合同、养老、矿山转型、轨道风险、信息权或代表权，而不是凭空阵营标签。
4. 宗教、习俗和地方文化可以保留记忆、互助与意义；它们不能成为截留公共生存资源、组织独立武装或否认基本身份的借口。

## 4. 政治与战争规则

1. 中央主权完整，但执行不是全知全能。信息质量、机构负荷、地方适应、申诉、腐败、服务覆盖和统合压力决定执行效果。
2. 军事能力独立于安全事件，但军力不等于自动胜利。战争结果同时受工业、人口动员、情报、路线、补给、社会支持、外交与战后治理约束。
3. 战争必须留下伤亡、照护、军政关系、基础设施破坏、迁徙、财政与统合成本。武力统一不是默认捷径。
4. 核威慑、轨道优势、战略技术首先改变预警、核查、封锁和谈判位置；不得把它们写成无风险的绝对控制。
5. 统一的稳定条件至少包括防务、财政物流、行政执行、公共服务和社会认受性；任何单一数值达到阈值都不足以完成统合。

## 5. 经济与产业规则

1. 资源先服务于“能否维持”，再服务于“能否扩大”。维护、替换件、培训、检修、库存、保险和修复与新建同等重要。
2. 具体物资处于设施、项目、事件和地区层；国家层显示可维持能力、覆盖、储备时间、趋势与风险。
3. 工程不是政策。工程必须形成位置/服务/网络/设施/维护中的至少一个实体事实；政策只改变有限期内的优先顺序、程序与分配。
4. 能源、材料、交通、公共卫生、教育和行政互为产业底座。任何“单线冲刺”应产生对其他底座的挤压和可见账单。
5. 环境不是装饰。水土、污染、气候、热排放、矿山修复、生态暂停权和灾害恢复决定长期生产基础。

## 6. 文明发展与地图规则

1. 自然世界的因果顺序不可倒置：行星参数 → 构造地貌 → 水文 → 气候 → 生态/资源潜力 → 人类工程增量。
2. 聚居、矿场、港口、水坝和道路不是自然贴图；它们由技术、合格选址、端点、施工与试运行产生。
3. 自然骨架、通用工程模块、实际工程实例、视觉表现为四个数据层。视觉可替换，地理事实不可由视觉反推。
4. 道路与网络是连接既有节点和已决定开发目标的工程；路线应可解释长度、土方、桥渡、隧道、维护、风险和前置。
5. 地图上的城市与工程必须与发展阶段、气候、地貌、规模和工程状态相符；远中近景是同一事实的不同读取精度，不是三套互相矛盾的地图。

## 7. 叙事限制

- 不用突然的万能技术或神秘资源修复前置缺口。
- 不让单一英雄、单次战争或单项工程无代价解决制度性问题。
- 不把地方自治写成中央主权不存在，也不把中央写成没有执行成本的全知机器。
- 不把普通人只作为人口数字；至少通过服务、工时、迁徙、教育、医疗、家庭或文化之一表现后果。
- 不把测试夹具、固定名称和演示数值误写成全局真相。
