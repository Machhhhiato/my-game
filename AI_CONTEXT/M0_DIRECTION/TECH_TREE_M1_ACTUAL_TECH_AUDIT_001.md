# 实际单科技节点身份审计

## 第一规则

实际展示只包含可单独研究的具体科技；总结、方向、阶段、终点能力、产品目录、事件族和实体结果一律不进入科技树。

## 判定合同

一个对象只有同时满足以下条件才被接纳：使用位置明确为科技树节点；研究完成会形成一项可采用的方法、设计、标准、制度、组织、训练或型号定型；具有明确直接效果与完整正文；可以由具体科技前置约束；不以日期作为完成门槛。

- 302 个原稳定对象全部获得明确分类，无遗漏。
- 278 个接纳对象均有唯一稳定身份、完整名称、直接效果、正文与第二段。

- 所有可见前置关系均为具体科技到具体科技；实体条件只进入科技详情。
