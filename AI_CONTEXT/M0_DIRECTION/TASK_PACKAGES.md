## M0-L4-000 · 四层入口安装

- 层级：第四层
- 模式：`sync`
- 当前状态：`deferred`；项目内入口已经由 `WF-M0-PROJECT-001` 满足，本任务只保留全局跨项目路由扩展与完整多设备测试。
- 路由修订：`D-M0-DIR-006` 取消它对 `M0-L1-101` 的阻塞；需要从任意其他项目目录自动定位 Always Game 时再重启。
- 依赖：`D-M0-DIR-004`、`D-M0-DIR-005`
- 目标：让 Mac 上的新会话能只凭“你是第 N 层”读取正确角色和当前任务；为 Windows 留下相同安装与测试方法。
- 输入：本目录的启动入口、四张角色卡、白话规则、任务路由和任务包。
- 输出 ID：`WF-M0-001`
- 必须输出：
  - 先核对 Mac 实际加载的是全局 `AGENTS.override.md` 还是 `AGENTS.md`，保留原有规则并只追加最短路由；
  - 项目根入口只增加一条稳定路由，不复制任务正文；
  - Mac 全局入口只负责找到唯一仓库并转入 Git 工作流；
  - 四个启动语分别在全新任务中的 Mac 只读测试结果；
  - Windows 的同等安装步骤和四项待测清单；
  - 实际修改文件、提交、验证和限制。
- 完成条件：四个启动语分别识别正确层级；第一层显示 `M0-L1-101` 被工作流任务阻塞或在安装验收后可切换；第二、三层显示准确上游阻塞；第四层识别本任务；任何启动都不自动写文件。
- 禁区：不改游戏代码、数据、资产、产品规格、`main` 产品决定或任务顺序；不在 Git 中保存两台电脑的绝对路径。
- 官方依据：Codex 每个新任务只建立一次说明链；全局先读 `AGENTS.override.md`，不存在时才读 `AGENTS.md`，随后再叠加项目说明。[OpenAI Docs](https://learn.chatgpt.com/docs/agent-configuration/agents-md)
- 一次性引导语：

```text

请先在 Always Game 的 context/m0-direction 分支读取

ACTIVE_TASKS.md、TASK_PACKAGES.md 和第四层角色卡。

```

- 下一任务：无；这是可选基础设施任务，不在当前产品串行链中。

## M0-L1-101 · 试玩起点、终点与非目标

- 层级：第一层
- 依赖：项目内入口 `WF-M0-PROJECT-001` 已安装；`D-M0-PROD-007`
- 目标：写清玩家从什么状态开始、30–45 分钟内经历什么、结束画面显示什么。
- 输出 ID：`SPEC-M0-PLAY-001`
- 输出路径：`specs/spec-m0-play-001.md`
- 必须输出：开局人口与可用能力的暂定口径；前 90 日路径；第二座工业废墟回收前哨稳定运行的结束条件；看海时段；成功、未通过和明确非目标；明确区分链路测试骨架与正式内容路径，至少为食物循环、废墟探索循环、维护/零件循环保留不可被占位替代的正式内容槽位。
- 完成条件：用户能仅看这份规格判断“做到这里是否足以证明核心玩法”；所有数字标明暂定或已确认；不得用链路测试通过代替内容完整可玩验收。
- 禁区：不写事件正文、最终文案、代码结构或 Steam 发布内容。
- 下一任务：`M0-L1-102`。

## M0-L1-102 · 人力、资源、库存底线与压力

- 层级：第一层
- 依赖：`M0-L1-101` 已接受
- 目标：定义有限人力怎样在日常生产、科研、勘测、工程和物流间调度，以及随机运行事故怎样通过同一套资源与状态规则自然结算。
- 输出 ID：`SPEC-M0-OPS-001`
- 必须输出：资源种类和来源；人力池；最低、标准、加速投入；库存底线；项目优先级；自动暂停与恢复；随机事故的候选、影响、结束与损失保留；至少两个由同一套调配规则产生的纸面配置；用临时数字核对人力总和与真实水账。
- 完成条件：集中建设不能绕过生命线值守；纸面核对随机事故的无损处置、受损后继续和真正终局三种自然结果；玩家能看懂每次暂停与损失原因。纸面演算不得变成额外通关卡点。
- 禁区：不增加逐人模拟、隐藏智能调度、强制极端二选一，或把集中/稳定做成独立路线卡、模式与数值加成。
- 下一任务：`M0-L1-103`。

## M0-L1-103 · 小地图、地形、选址与运输

- 层级：第一层
- 依赖：`M0-L1-102` 已接受
- 目标：确定 M0 小地图实际包含的地点，以及地点条件怎样影响建设与回运。
- 输出 ID：`SPEC-M0-MAP-001`
- 必须输出：总部、水源、两个工业废墟和未来资源地点；地貌、水文、资源、工程风险、距离与交通标签；适合、有条件适合、不可用三个示例；运输批次和中断规则。
- 完成条件：每个可建或不可建判断都有具体物理原因、额外成本和玩家可见说明。
- 禁区：不做程序化世界、全球寻路、其他前哨完整玩法或固定河谷硬编码。

## M0-L1-104 · 科研、高级资产与前哨复制

- 层级：第一层
- 依赖：`M0-L1-103` 已接受
- 目标：把集中科研、普通科研自动推进、勘测无人机、首座前哨和第二座自动复制连成一条规则链。
- 输出 ID：`SPEC-M0-PROGRESSION-001`
