# 方向十六：维修、备件与再制造

## 1. 方向结果

本方向把临时抢修推进为日常保养、定期维护、大修、再制造和跨地点维修保障。任何先进产品若没有此方向的对应能力，只能作为逐渐耗尽的遗产资产。

## 3. 四级养护

1. 日常保养；
2. 定期维护；
3. 大修；
4. 再制造。

玩家管理标准、工场、班组、备件与优先级，不逐台点击拧螺丝。维护债务必须对应具体资产和未完成工作。

## 4. 聚合备件池

- 通用机械件；
- 泵阀与流体件；
- 密封、过滤与润滑件；
- 电气与仪表件；
- 动力与传动总成；
- 轮胎与行走件；
- 刀具、工装与量具；
- 产品专用备件包。

## 5. 第 730 日验证

- 关键水务、能源、机床、车辆和通信资产均有维护标准；
- 至少一类总成完成大修，至少一类零件完成再制造；
- 远端设备能现场抢修或返厂处理；
- 缺件、停机和维护积压产生真实结果；
- 无日期门。
