# SPEC-M0-MAP-001 · M0 小地图、地形、选址与运输

## 1. 本规格要决定什么

本规格决定 M0 小地图实际有哪些地点，玩家开始时知道多少，怎样勘测地点和比较选址，地形与道路怎样改变工程成本，以及总部和前哨怎样按批次运输。

本规格不做程序化世界、全球寻路、逐格移动、逐车微操或第二种完整远程前哨，也不授权修改游戏代码。

## 2. 已确认边界

- 开局准确显示总部、水源、附近食物点和待勘测方向，不直接显示两处工业废墟的完整资料。
- 地图规则必须能表达山地、泥地、河边、沙滩、矿产和城市废墟；工程用途必须受土地和资源条件限制。
- M0 只完整制作工业废墟回收前哨。农田、矿山和岸边工程可以显示未来潜力，但不能在本阶段扩成完整玩法。
- 第一处废墟由玩家完整主导首建；第二处废墟由玩家批准地点、优先级和投入上限后自动复制。两处最终都必须可建设同类前哨。
- 废墟资料逐步揭示方向、距离、道路、地形、风险和资源；玩家决定勘测顺序、路线与投入，不能一键揭示全部资料。
- 远程物流使用已确认的 2、3、5 人三档；非紧急运输只在白昼推进，服从 P0 至 P3、安全线、暂停与恢复规则。
- 运输是双向实体流：总部向前哨送水、食物和普通零件，前哨留下生产与维护所需后，向总部回运工程构件和合金料。
- 主管道破裂只影响经过破裂段的实际进水；只有真正绕开破裂段的新管线才形成有效替代路线。

## 4. 第一项提案：地图形式与地点

### 4.1 地图形式

M0 使用一张人工设计的小区域地图。玩家看到地点，以及地点之间的道路、步道和管线；点击地点查看资料。不做方格移动，不让玩家逐车下命令，也不随机生成世界。

这张 M0 地图可以固定，方便调试和平衡；判断规则不能写成“所有地图都必须是同一条河谷”。地点和连接都使用可替换的数据与标签，后续地图可以换布局继续使用同一套规则。

### 4.2 地点清单

下面的距离是第一轮暂定平衡值，不是世界设定常数。

| 地点 | 暂定关系 | 玩家开始时看到什么 | M0 作用 |
|---|---|---|---|
| 总部 | 地图中心 | 居住区、仓库、拆解区、道路与管线接口 | 人口、库存和项目调度中心 |
| 水源与旧供水设施 | 约 1.2 公里 | 水源、取水/净化设施、旧主管和维护通路 | 总部供水；保留可建设绕行管线的空间 |
| 附近食物点 | 约 0.7 公里 | 河边平地、可采集资源和短途通路 | 每日采集并送回总部，不做完整农业前哨 |
| 工业废墟 A | 约 3.2 公里 | 开局只显示大致方向 | 旧路较稳，现场破损和清理工作较重；工程构件较多 |
| 工业废墟 B | 约 5.6 公里 | 开局只显示大致方向 | 现场工业地面较好，路线包含泥地和受损通路；合金料较多 |
| 未来农田候选地 | 约 1.8 公里 | 平坦土壤与水源潜力 | 只显示未来用途，不开放农业前哨 |
| 未来矿产坡地 | 地图边缘，约 6.8 公里 | 山地、陡坡和矿产迹象 | 只显示未来矿山方向 |
| 未来沙滩/河岸候选地 | 地图边缘，约 4.5 公里 | 沙地、岸线和交通条件 | 只显示未来岸边工程方向 |

未来地点不是三个额外可玩系统，只负责让玩家看见不同土地条件和之后可以扩张的方向。

### 4.3 两处废墟不是永久二选一

- A 的难点在现场：距离较近，运输路线较稳定，但需要更多清理工作。
- B 的难点在路上：现场更适合建设，但距离较远，途中泥地和受损通路会增加开路与运输负担。
- 两处建设地面都满足工业废墟回收前哨的硬条件，因此第一座形成的标准工程经验能够用于第二座。
- 玩家决定先勘测哪边、先建哪座。先建 A 或 B 都能继续主线，只会改变前期成本结构和首先获得的资源比例。

### 4.4 开局知道多少

- 总部、水源和食物点的地点与基础资料已知。
- 两处工业废墟只显示搜索方向，不显示精确距离、完整道路、风险和资源量。
- 勘测后依次补齐地点、路线、现场条件与资源资料；具体层级在第三项确认。
- 查看地图和比较地点不花资源；勘测、开路、建造和运输才消耗人力、白昼与物资。

本项尚未接受。用户确认地点清单、两处废墟的差异和开局信息边界后，才写成正式产品决定。
