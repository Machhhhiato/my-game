# 道路、车辆、运输、仓储与区域物流闭环

## 1. 容量、产品、设施与组织

8类容量：徒步畜力、人力车辆、摩托、轻卡、中卡、重卡工程车辆、道路桥涵、仓储装卸转运。运输任务必须同时具备货物、车辆、驾驶员、路线、燃料、装卸、护运和目的库存。

15项明确产品：标准推车、自行车、摩托车、轻型卡车、中型卡车、重型卡车、工程牵引车、拖车、标准周转容器、危险品运输容器、冷藏运输设备组、装卸托盘、机械装卸设备、道路养护设备组、车辆维修总成。车辆型号族沿`TC-A1 → ZC-A1 → MT-A1 → QK-A1 → ZK-A1 → ZK-B1`形成真实载重与可靠性里程碑。

设施12类：路线测绘站、道路养护站、桥涵检查站、车辆调度场、驾驶培训场、加油维护点、综合车库、仓库、冷库、装卸站、转运中心、区域物流指挥中心。组织5种：交通道路、车辆运营、仓储库存、区域物流调度、运输安全与事故调查。

## 3. 制度、状态与结算

法令5项：道路桥梁使用、驾驶车辆登记、货运与在途责任、危险品冷链运输、交通事故救援调查。政策5项：关键物资优先运输、道路抢修、燃料限额运输、季节通行管制、物流积压清理。状态8项：主干路连续、桥涵安全、车辆可用、驾驶员合格、仓储可追溯、冷链连续、在途库存可核对、区域物流无单点失效。

`完成运输量 = min(车辆载能, 驾驶员, 路线容量, 装卸仓储容量, 燃料, 护运) × 车辆道路状态 − 中断损失`。车辆速度、吨位和油耗共同决定结果，不只比较型号数值。第2年必须具备推车至卡车的多级运输、主干道路、桥涵检查、仓储装卸、车队调度、维修、危险品和冷链接口。本轮不填吨位、速度、路线长度、车数和周转时间。

旧类型修正：装卸站是设施，车辆/驾驶员调度是行动，区域补给网是组织关系，库存覆盖是状态，在途货物仍属于真实产品库存而非消失的运输数值。
