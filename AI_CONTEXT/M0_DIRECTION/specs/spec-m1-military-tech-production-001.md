# 军队科技、装备生产与部队组建方案

## 1. 本轮要解决的问题

军队科技线不能只是一列武器加成，也不能让科研完成后凭空出现枪、坦克或部队。

本方案把军队发展拆成四类可研发内容：

1. **军队类型与编制**：决定可以组织什么部队、需要哪些人员和装备；
2. **军事风格与指挥方法**：决定军队倾向怎样准备和使用力量；
3. **战术方法**：决定符合条件的部队在具体地形、任务和敌情下可以怎样行动；
4. **武器装备与型号**：决定可以试制、定型、生产和维护什么装备。

科研只产生知识、设计、编制、训练大纲或指挥方法。最终实体结果只有两类：

- 生产线制造出的**明确武器装备型号**；
- 经过征募、装备、训练和编组形成的**明确实体部队**。

## 2. 借鉴《钢铁雄心 IV》的部分与本项目差异

借鉴方向：

- 装备按产品家族、代际和具体型号进入生产线与库存；
- 军队由明确编制消耗人员和装备组建；
- 军事学说、军队组织和装备科研是不同对象；
- 旧型号继续存在，生产换线和部队换装都需要真实过程；
- 部队战斗力来自编制、装备、训练、补给和指挥的组合，不来自一条综合军力值。

本项目不照搬：

- 不让科研直接提供无对象的全军百分比；
- 不把玩家变成逐营逐连战术微操者；
- 不允许一个抽象军工厂吞入资源后直接生成任何装备；
- 不按历史年份解锁装备；
- 不把现实国家的装备名称直接套入本世界。

## 3. 完整因果链与下级依赖

任何军事结果必须沿以下链条生成：

```text
材料、能源、化工、母机、车辆、通信、医疗等下级工业能力
  + 人口登记、基础训练、军纪、指挥和补给等下级组织能力
    ↓
装备技术 / 编制技术 / 军事风格 / 战术方法研究
    ↓
试制、演习、检验或已有部队运行证明
    ↓
正式装备型号 / 正式部队编制 / 正式训练与指挥标准
    ↓
生产装备 + 征募人员 + 建立训练、维修、医疗、通信和补给
    ↓
组建实体部队
    ↓
部署、行军、警戒、护运或战斗
    ↓
产生真实战果、损失、故障、经验与下一轮改进需求
```

上层节点必须依赖下层能力或下层运行证明，不能只依赖另一张科技卡：

- 改进枪械型号依赖已有枪械生产、检验和使用反馈；
- 摩托化步兵依赖常备步兵、军用卡车、驾驶训练、燃料、车队维修和道路保障；
- 装甲部队依赖摩托化指挥、装甲车辆、车组训练、抢修拖救、燃料和弹药运输；
- 纵深防御依赖基础阵地构筑、通信、预备队和补给转移演习；
- 合成兵种协同依赖步兵、工兵、火力支援、通信和至少一次联合演习；
- 高级战术必须由能执行该战术的真实部队完成演练或战斗验证。

时间不作为前置。玩家提前取得下级能力和证明，就可以提前研究、定型和组建后期部队。

## 4. 四类军事科技的准确产物

| 科技类别 | 研究完成后得到什么 | 仍需完成什么 | 最终实体结果 |
|---|---|---|---|
| 军队类型与编制 | 编制表、岗位、装备表、训练标准、指挥与支援关系 | 征募、装备、训练、指定驻地和指挥人员 | 一支有稳定 ID、番号和实际状态的部队 |
| 军事风格与指挥方法 | 参谋作业、行动原则、预备队和补给使用方法 | 参谋训练、演习、通信与组织采用 | 部队在符合条件时按该风格准备和行动 |
| 战术方法 | 适用任务、地形、部队、触发条件、行动步骤和退出条件 | 对应部队训练、演习或战场验证 | 战斗中实际使用并产生可追溯结果 |
| 武器装备与型号 | 设计、材料标准、试验标准、生产工艺和养护标准 | 试制、定型、建线、生产、检验和入库 | 有完整名称、代号、型号和数量的装备 |

任何军事科技都必须写出完整内容。例如：

- 不能叫`步兵科技二级`，应写成`常备步兵编制与班组协同训练`；
- 不能叫`机动战加成`，应写成`道路机动、侧翼展开与车队连续补给`；
- 不能叫`枪械二型`，应写成`制式枪械新一代定型与批量验收`，其生产结果再使用正式型号名称；
- 不能叫`装甲加十`，应写成`焊接装甲结构、乘员防护与战场抢修标准`。

## 5. 军队类型与编制科技树

### 5.1 基础根节点

| 科技名称 | 下级依赖 | 解锁的明确内容 |
|---|---|---|
| 统一警戒、值勤与武器保管制度 | 人口登记、库存登记、基础通信、枪械安全 | 聚居点警戒队编制 |
| 基础步兵训练与班组协同 | 警戒队运行、标准口令、基础医疗 | 基础步兵分队训练标准 |
| 战地命令确认与通信纪律 | 无线电/有线通信、识字与地图训练 | 正式指挥岗位、命令回执和通信组 |
| 军需登记与持续补给 | 仓储、运输、公共账目、弹药与食品库存 | 部队装备表、消耗表和补给编组 |

### 5.2 地面部队类型

| 部队类型科技 | 必须先有 | 解锁的编制结果 |
|---|---|---|
| 聚居点守备部队编制 | 统一警戒制度、基础步兵训练 | 聚居点守备分队/守备连 |
| 常备步兵部队编制 | 基础步兵训练、军需补给、战地通信 | 常备步兵连，后续可扩展为步兵营 |
| 侦察与路线警戒部队编制 | 常备步兵、路线测绘、短程通信 | 侦察分队或侦察排 |
| 工兵与战场救援部队编制 | 常备步兵、工务、排险、急救 | 工兵分队/工兵连 |
| 摩托化步兵部队编制 | 常备步兵、军用卡车、驾驶、燃料、车辆维修 | 摩托化步兵连，后续可扩展为摩托化步兵营 |
| 火力支援部队编制 | 常备步兵、班组支援武器或火炮、弹药运输 | 火力支援分队、迫击炮排或炮兵连 |
| 装甲侦察部队编制 | 侦察部队、装甲汽车、车组与抢修训练 | 装甲侦察排/连 |
| 轻型装甲部队编制 | 装甲侦察、轻型坦克、燃料弹药和专业维修 | 轻型坦克连 |
| 中型装甲部队编制 | 轻型装甲部队运行、摩托化补给、中型坦克 | 中型坦克营 |
| 重型装甲支援部队编制 | 中型装甲、重型坦克、重载运输和专用工场 | 重型坦克支援连/营 |
| 通信保障部队编制 | 战地通信、无线电设备、维修与供电 | 通信分队/通信连 |
| 卫生与后送部队编制 | 基础医疗、车辆/担架、药品与后送路线 | 卫生分队/野战救护连 |
| 军需与维修部队编制 | 军需登记、仓储、车辆、维修工场 | 补给运输连/维修连 |

上表中的`分队、排、连、营`是完整中文编制名称，不以英文字母或内部 ID 代替。准确人数和下辖单位由后续人口与装备账本校准。

## 6. 军事风格与指挥方法科技树

军事风格不是一次选择后永久获得的国家加成，而是需要参谋、训练、通信、补给和部队结构共同维持的作战方法。

| 风格科技 | 下级依赖 | 形成的完整能力 |
|---|---|---|
| 聚居点区域防御与快速增援 | 守备部队、通信、路线档案 | 守备点互相预警并调动最近预备队 |
| 阵地构筑、纵深迟滞与轮换防御 | 工兵、守备、仓储、伤员后送 | 多道阵地、交替撤退、轮换与局部反击 |
| 集中火力、观察校射与预备队反击 | 火力支援、侦察、通信、弹药运输 | 在确认目标后集中有限火力，并保留反击力量 |
| 道路机动、侧翼展开与车队连续补给 | 摩托化步兵、车辆、道路、燃料、维修 | 通过真实路线形成更快部署和侧翼行动 |
| 分散渗透、隐蔽接敌与短促突击 | 侦察、班组协同、夜间通信 | 小编组接敌、局部集中和及时脱离 |
| 步兵、工兵、火力与装甲协同 | 各对应部队、联合通信、联合演习 | 不同兵种围绕同一任务互相支援 |

一个国家可以研究多种风格，但只有完成对应训练、演习和组织采用的部队才能真正使用。部队也可以有主训练风格和辅助风格，不要求全军被锁死在唯一学说分支。

## 7. 战术方法科技树

战术科技必须声明适用部队、地形/任务、进入条件、退出条件和失败风险，不成为玩家逐分钟点击的战斗技能。

### 7.1 基础战术

| 战术科技名称 | 下级依赖 | 实际应用 |
|---|---|---|
| 班组火力掩护与交替前进 | 基础步兵、标准枪械、班组协同 | 开阔地或接敌时减少无掩护暴露 |
| 掩体构筑与交替阵位 | 工兵工具、基础步兵 | 防御任务中形成可轮换阵位 |
| 路线伏击、观察与安全脱离 | 侦察、地图、通信 | 护运与路线争夺中的短促伏击 |
| 夜间行军、灯火管制与有限夜战 | 纪律、通信、路线识别 | 降低夜间迷失和误击，但增加疲劳与组织压力 |
| 伤员现场处理与分级后送 | 急救训练、卫生部队、运输 | 缩短伤员滞留并保留可救治人员 |

### 7.2 进阶战术

| 战术科技名称 | 下级依赖 | 实际应用 |
|---|---|---|
| 城镇街区封锁、观察与逐点清理 | 基础战术、工兵、通信、医疗 | 城镇战中控制通路并减少失联小组 |
| 火力观察、目标确认与弹着修正 | 火力支援、侦察、通信 | 减少无效弹药消耗和误击 |
| 道路机动、下车展开与车辆隐蔽 | 摩托化步兵、车队训练 | 车辆负责机动而不直接暴露在近战中 |
| 反装甲障碍、侧后接敌与近程阻击 | 工兵、反装甲武器、侦察 | 阻滞装甲并争取打击薄弱方向 |
| 装甲突破、步兵跟进与工兵开路 | 轻型装甲、步兵、工兵、通信 | 装甲不脱离步兵和补给独自前冲 |
| 预备队接替、局部反击与有序脱离 | 纵深防御、通信、预备队 | 防止一次接战演变成全线崩溃 |

高级战术只有在下级战术、对应部队和至少一次演习/实战证明存在后才能稳定采用。

## 8. 武器装备科技与完整生产名称

> 本节原19项装备是首批军队产品，不再代表现代集团军的完整装备上限。现代集团军的十五种部队类型、51项军事产品和第2年19项基础产品补齐范围，以 `SPEC-M1-MODERN-FIELD-ARMY-EQUIPMENT-UNITS-001` 为追加规格；本文件既有已接受规则继续有效。

### 8.1 生产名称合同

每个正式生产结果必须同时包含：

1. **拟真型号或军械代号**；
2. **完整产品类型**；
3. **必要时的正式绰号或用途后缀**；
4. **当前定型批次或重大改型**；
5. 稳定内部 ID，但内部 ID 不直接展示给玩家。

玩家界面不能只写：

- `枪械二`；
- `步兵装备`；
- `轻坦一`；
- `支援装备`；
- `火炮科技加十`。

应显示成类似以下结构的完整名称：

- `“守望”制式单兵枪械（军械定型编号：步武—01）`；
- `“远行”轻型军用卡车（车辆定型编号：军运—02）`；
- `“壁垒”装甲侦察车（装甲项目编号：装侦—01）`；
- `“磐石”轻型坦克（装甲项目编号：轻装—01）`；
- `“回声”班组无线电台（通信定型编号：军通—03）`。

以上名称只用于确认格式和信息完整度，不在本方案接受时自动冻结为最终玩家文字。最终具体代号必须结合政体、军械机构、定型时间和产品来源逐项生成。

## 9. 部队组建的明确结果

### 9.1 组建合同

建立一支部队必须同时满足：

- 已研究并采用对应部队编制；
- 有符合编制的实际人口和岗位；
- 有明确型号和数量的主装备、支援装备、通信、医疗和运输；
- 有弹药、燃料、食品、药品和维修备件；
- 有训练场、教官、训练时间和合格记录；
- 有驻地、指挥人员、补给来源和维护单位；
- 所需战术已经训练，而不是因国家研究完成就自动灌入所有部队。

完成后生成一支实体部队，至少保存：番号、完整名称、编制、实际人员、装备型号与数量、训练、主/辅助风格、已掌握战术、士气/凝聚、补给、维修、医疗、通信、驻地、任务和经历。
