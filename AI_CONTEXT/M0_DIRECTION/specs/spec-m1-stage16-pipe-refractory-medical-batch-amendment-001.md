# 决策

| 稳定ID | 候选名称 | 结论 |
|---|---|---|
| `MAT-PIP-001` | 焊接钢管生产 | 收窄为Q235B低压流体焊接钢管，不包含无缝和高压管 |
| `MAT-REF-001` | 高铝耐材制备 | 交付LZ-55高铝砖和LCC-60低水泥高铝浇注料，并保留原料链缺口 |
| `MED-DIA-001-A` | 基础医学检验 | 从复合诊断节点拆出基础样本检验与结果适用边界 |
| `MED-DIA-001-B` | 旧影像设备修复 | 后移到维修链，只恢复具体遗产设备到待临床质控状态 |
| `MED-DIA-001-C` | 临床诊断记录标准 | 删除独立科研，作为具体诊疗行动的运行记录 |
| `MED-MAT-001` | 孕产连续照护 | 按原正文真实身份改名，承担孕产妇侧连续照护 |
| `MED-SUP-001-A` | 医用敷料制造 | 交付三类明确的非无菌敷料，灭菌由后续节点承担 |

# 点数

- 五个源节点原230点，形成六项有效候选共450点，净增加220点。
- 增量主要来自把原90点复合诊断节点拆为50点基础检验和80点设备修复，并恢复钢管、高铝耐材与孕产照护的真实成本。
