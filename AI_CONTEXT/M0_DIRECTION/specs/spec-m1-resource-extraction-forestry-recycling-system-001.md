# 采矿、林业、回收与基础资源闭环

## 1. 对象边界

资源储量、采掘容量、原矿/原木/废料产品、选矿加工、矿场设施和可恢复环境分别登记。资源发现不等于储量可采，矿山建成不等于产品入库，废墟拆解不等于自动获得合格金属。

## 4. 法令、政策、状态与结算

| 类型 | ID 范围 | 独立对象 |
|---|---|---|
| 法令 5项 | M1-RAW-LAW-001—005 | 资源调查与采矿许可；矿山安全；林业采伐更新；废料拆解与危险物；矿山关闭复垦污染责任 |
| 政策 5项 | M1-RAW-POLICY-001—005 | 关键矿物优先；应急废料回收；矿山安全停产整治；木材采伐限额；枯竭矿区转产复垦 |
| 状态 8项 | M1-RAW-STATE-001—008 | 储量可信；关键原料可补充；采掘安全；矿石质量稳定；木材持续更新；废料回收可追溯；资源物流连续；关闭复垦责任成立 |

`实际资源入库 = 可用采掘容量 × 人员设备 × 地质可采率 × 安全与运输状态 × 品位合格率 − 开采选矿损失`。储量随采出减少；回收依赖真实废物流；跨地点必须运输。

第2年至少具备砂石、石灰石/黏土/石英砂中的建材路线，铁或废钢路线，铜/铝至少一种导电有色来源，木材或替代材料路线，以及矿山安全、回收和复垦接口。本轮不填储量、品位、产量、矿井深度、林木生长和设备数量。

旧类型修正：资源候选区是地点记录，矿场与选矿站是设施，矿石和废料是产品，采储计划是组织记录，复垦是工程与状态；不能用“基础矿物”万能库存替代十六项资源。
