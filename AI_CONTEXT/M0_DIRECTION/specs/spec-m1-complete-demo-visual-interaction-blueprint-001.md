# 完整Demo视觉方向与首批界面蓝图

> 地图场景、缩放、设施占地等级与常驻地图模式已被`SPEC-M1-STRATEGIC-ATLAS-MAP-ARCHITECTURE-001`取代。本文件继续保留整体视觉语言、顶栏、系统入口、科技、生产、军事、治理和事件页面方向；不得再用本文件的远中近、1格/4格/7格校准或五模式实验作为正式地图规则。

## 1. 用户接受的核心方向

完整Demo采用“地图承担战略态势、侧边系统承担管理、现实工业对象承担拟真”的混合方向：

- 借用《群星》地图中心、稳定系统入口、事务总览、科技卡与事件阅读的信息层级；
- 借用《钢铁雄心4》顶栏资源、地图模式、生产线、补给、部队标识与行动反馈的战略表达；
- 不复制两者的素材、构图、配色、图标或具体页面；
- 世界本身使用战后工业文明的现实地形、废墟、道路、管线、电网、厂区、车辆和聚居地；
- 拟真来自每个显示对象都对应实际地点、设施、产线、产品、人员、路线或部队，不依赖无意义做旧。

## 2. 主界面固定结构

1. 顶部常驻人口、岗位、关键资源、工业状态、日期、速度与行动警报；
2. 左侧常驻地图、科研、工程、生产、内政、外交、军事与档案入口；
3. 中央地图始终是最大视觉对象；
4. 右侧可折叠事务总览只收正在执行、停滞和真正需要处理的事项；
5. 底部指令栏只在选中地点、设施、生产线或部队后出现；
6. 常规操作使用侧边抽屉，不频繁遮挡地图；
7. 科技树、政策法律、部队编制和终局报告可以进入全屏页面。

## 3. 视觉语言

| 职责 | 视觉规则 |
|---|---|
| 基础环境 | 煤黑、深海军蓝、冷灰，低反光烤漆和氧化钢材质 |
| 常规信息 | 灰白文字与低饱和青蓝，不用霓虹光污染 |
| 正在执行 | 钨丝灯般的琥珀色 |
| 稳定运行 | 低饱和绿色 |
| 缺口与危险 | 铁锈红，只用于会改变玩家行动的事实 |
| 科技里程碑 | 蓝白高光与真实技术插图，不用抽象发光球 |
| 军事 | 橄榄绿、土黄、暗红与地图兵牌 |
| 世界材料 | 地形测绘、卫星照片、工程蓝图、真实机械侧视图与少量纸质档案 |

界面字体以紧凑、清楚的简体中文无衬线为主，数字使用等宽或表格数字。事件档案可以局部使用适合长文阅读的宋体，但按钮、状态和数值不得混用装饰字体。

## 4. 地图与缩放层级

- 区域层显示聚居地、控制关系、道路、电网、供水、贸易、补给、部队和未调查地区；
- 地点层显示厂区、农区、仓储、公共设施和路线连接，不让玩家逐栋摆放普通建筑；
- 选中对象后由底部指令栏与侧边详情显示生产线、岗位、库存、维护和动作；
- 地图模式只改变同一世界事实的强调方式，不生成另一套地点；
- 缩放只能减少标签和插图细节，不能把多个实际科技、设施或地区合成新的总结对象。

### 4.1 六角格是规则底座，不是地形画风

地图按六层叠加，不把每个格子画成独立棋盘块：

1. 连续地形层：山脉、河流、森林、农地、废墟和城镇纹理跨格连续绘制；
2. 六角规则层：保存稳定格ID、相邻关系、地形条件、情报、控制和选址合法性；
3. 基础设施层：道路、输电、供水、运输和补给沿真实路径跨越多个格子；
4. 实体层：聚居地、厂区、农区、仓库、部队和工程锚定到格子，但插图允许略微越过格线；
5. 情报层：未知区域由战争迷雾覆盖，调查程度决定能看到哪些真实信息；
6. 交互层：选中、候选、危险、路线和目标范围按当前操作临时显色。

六角线按操作场景改变可见度：

| 场景 | 六角边界 |
|---|---|
| 默认战略观察 | 基本隐藏，只保留地区、控制和必要边界 |
| 探索与情报 | 显示已知、未知和可调查格，未探索边缘微弱可见 |
| 工程选址 | 显示候选、选中、禁止和工程影响范围 |
| 基础设施 | 突出道路、供水、电网、运输与相邻接通关系 |
| 军事 | 突出控制、前线、补给、通行和任务范围 |

默认格线使用低透明冷灰蓝；选中格使用明亮青白轮廓；合法候选使用克制琥珀虚线；危险或禁止格使用铁锈红斜纹。颜色只说明状态，不改变底层地形类型。

道路与河流不强迫沿六角中心折线行走。规则层记录它经过哪些格和边，画面层仍绘制自然曲线；只有铁路节点、桥梁、边界关口和必须沿格边成立的对象才强调格边。

当前候选采用局部平面投影演示六角层。六角坐标与稳定ID不依赖投影；以后若保留行星球面或切换到更大区域视角，同一格子事实可以换投影显示，不需要重建世界数据。

### 4.2 设施可以跨格扩张，但地图只有一种标准格

- 全地图只使用一种尺寸和坐标规则的标准六角格，不建立道路小格、建筑大格或聚居地特大格三套坐标；
- 道路、铁路、输电、供水和补给是穿过格子或连接格边的线性设施，本身没有另一种“道路六角格”；
- 临时营地、小型取水点、单体作坊等小设施通常只占一个标准格；
- 标准工厂、仓储区、医院、学校和军营可以占用一个或多个相邻标准格；
- 联合厂区、城市建成区、机场和大型军事基地由多个连续标准格组成；
- 扩建不是把一个六角形等比放大，而是把新的相邻标准格加入同一设施或厂区的`occupiedCellIds`；
- 选中大型设施时，画面沿全部占用格的外缘绘制一个连续轮廓，内部公共边界弱化；不得再用一个更大的完整六角形包住它；
- 建筑插图可以为可读性略微越过格线，但插图尺寸不等于规则占地，悬停和详情必须能够查看真实占用格；
- 聚居地名称与图标是多格地区的视觉锚点，不代表聚居地只有一个放大的格子。

设施扩建必须产生实际空间后果：占用土地、改变道路和管线连接、增加运输距离、挤压农业或居住用地，并受到地形、污染、安全距离和相邻基础设施约束。玩家不逐栋摆放普通车间；默认由系统在已经批准的厂区范围内安排。只有新增占地会改变地区用途、路线或居民时，才要求玩家选择扩建方向或新厂址。

## 5. 关键页面合同

### 5.1 科技树

- 五百一十九项候选中的每项实际科技都保留独立节点身份；
- 分支标题、过滤、缩放和里程碑背景只用于浏览，不冒充科技；
- 默认节点显示名称、图像、科研点和状态；
- 选中后显示直接解锁、前置关系和完整正文；
- 科技只有未研发与已研发两种完成身份，正在研究仍属于未研发并附进度；
- 连接线必须表达真实前置，不能为构图方便补边。

### 5.2 工程

- 工程绑定真实地点与对应实体；
- 在建只显示进度、已投入物资、占用人力和可操作的停滞原因；
- 建成后退出工程队列，设施运行状态进入对应设施页；
- 不把底层施工工序拆成七八个玩家状态。

### 5.3 生产与工厂

- 主体采用逐产品生产线列表；
- 每行显示产品与型号、分配工厂、输入、产出、效率、库存、维护和缺口；
- 工厂数量使用明确减号、数量与加号，不用复选框；
- 厂区是地点上的实体，生产线是厂区内可协调能力；
- 过细零件可以归入已经接受的基础零件产品族，但不得出现食品与罐、枪与弹药等跨产品混厂名称。

### 5.4 军事

- 地图显示地区控制、部队兵牌、行动方向、补给覆盖和战斗结果；
- 玩家管理部队类型、编制、装备满足率、训练、补给和任务，不进行单兵微操；
- 装备优势通过战斗损失、推进、补给和维修结果表现，不在主界面制造直接爽点比较表。

### 5.5 政策、法律与法令

- 政策按类别选择一个长期倾向；
- 法律显示当前执行标准及覆盖；
- 法令显示启动原因、临时效果和退出条件；
- 三者不使用同一种卡片状态，也不把内部行政步骤做成玩家科技。

### 5.6 事件与日志

- 重大事件使用居中档案式窗口、专属插图和真实选择；
- 没有选择的重大事实允许展示后自动归档，不制造假按钮；
- 普通进度进入原页面，已发生事实进入日志，需要改变行动的事实才进入通知；
- 取消目前可随意拖动且长期遮挡地图的通用事件窗。

## 6. 文明进步的视觉阶段

| 阶段 | 地图必须出现的变化 |
|---|---|
| 0至5分钟 | 避难所附近有限可见区域、临时路线、手工作坊和千人聚居地接触 |
| 早期恢复 | 农地、取水、基础供电、道路修复和稳定运输开始连成小循环 |
| 中期工业化 | 厂区、仓库、电站、医院、学校、地区道路和贸易线形成网络 |
| 后期现代化 | 区域电网、公路物流、现代厂区、通信节点和成建制部队同时可见 |
| 能力终局 | 玩家不打开统计页，也能从地图看出避难所已经成长为现代地区政权 |

同一生产地点的主要视觉迭代为：临时工棚、专业作坊、标准厂房、联合厂区。产品里程碑通过真实型号插图、地图运输工具和实际使用场景体现，不只改变数字颜色。

## 7. 现有M0骨架的取舍

保留概念：地图中心、顶栏、左侧系统入口、侧边面板、选择对象后操作、当前状态回到原系统查看。

必须替换：圆形抽象球面、字符图标、通用拖动事件窗、同质化卡片、六资源全部平铺、只有两项科技的水平链、把一次性项目显示成工厂、缺少区域基础设施和物流态势的地图。
