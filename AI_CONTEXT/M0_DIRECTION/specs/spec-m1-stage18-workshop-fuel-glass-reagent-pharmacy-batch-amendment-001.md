# 决策

| 稳定ID | 候选名称 | 结论 |
|---|---|---|
| `IND-SIT-002` | 作坊公辅设计 | 保留小型专业作坊共用的容量接口，不扩成工业园公辅 |
| `MAT-FUL-001` | 柴油调合控制 | 收窄为0号与负10号柴油调合，并后移到实际组分存在时 |
| `MAT-GLS-001` | 平板玻璃成形 | 交付3毫米建筑用普通平板玻璃，配料熔制退火保持独立 |
