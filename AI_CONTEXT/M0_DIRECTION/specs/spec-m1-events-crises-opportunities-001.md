# 方向三十二：事件、危机与外部机会

## 1. 方向边界

事件不是独立科技，也不绑定日期或章节。事件从真实人口、设施、库存、路线、关系、维护、生产批次、军队和环境状态进入候选；处理手段来自玩家已经拥有的正常能力。

## 3. 生命周期

```text
真实状态进入候选
→ 固定种子选择与事实快照
→ 事件开始并改变状态
→ 玩家使用已有手段或让系统按现行规则运行
→ 原因消失时自然结束
→ 已发生损失、关系和库存变化保留
→ 结果进入科研、改型、维护或政策反馈
```

## 4. 禁区

- 不指定唯一解法；
- 不因事件自动暂停整个游戏；
- 不把通知阅读当作处理；
- 不提供独立于世界账本的奖励；
- 不为了戏剧性凭空增加死亡、战争或背叛；
- 普通进度不重复通知，只有会改变下一步判断的事实进入通知候选。
