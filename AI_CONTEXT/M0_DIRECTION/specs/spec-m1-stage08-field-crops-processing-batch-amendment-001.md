# SPEC-M1-STAGE08-FIELD-CROPS-PROCESSING-BATCH-AMENDMENT-001

## 结论

源序号131—135重建为六个明确科技：饲草栽培、饲草保藏、食用豆类栽培、谷物清理磨制、块根作物栽培和蔬菜栽培。栽培科技只开放行动、标准和记录，农产品由实际种植行动产生；加工科技只开放工艺与可生产产品，不自动生成设施或库存。

### 131 饲草路线

- `AGR-FOR-001-A`饲草栽培：前置露地耕作组织，候选20点；实际行动产出鲜饲草批次。
- `AGR-FOR-001-B`饲草保藏：前置饲草栽培，候选15点；干草与青贮分别具有行动、等级、记录和产品批次。

### 132—135 作物与加工

- `AGR-LEG-001`食用豆类栽培：前置露地耕作组织，30点；实际行动产出食用豆类批次。
- `AGR-MIL-001`谷物清理磨制：前置谷物脱粒干燥，35点；清理谷物和谷物粉分别保留状态与产品等级，粉尘防护属于工艺必要标准。
- `AGR-TUB-001`块根作物栽培：前置露地耕作组织，30点；食用块根与留用繁殖材料分批。
- `AGR-VEG-001`蔬菜栽培：前置露地耕作组织，30点；实际行动产出鲜食蔬菜批次。

删除所有科研自动生成的生产线、种子种苗、繁殖材料和收获物。农业批次使用品类、等级、成熟或质量状态和批次号，不强行套用装备型号。
