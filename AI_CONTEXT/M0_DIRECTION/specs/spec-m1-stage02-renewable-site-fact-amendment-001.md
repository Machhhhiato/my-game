# M1第二阶段可再生能源站址科技事实修正

## 1. 问题

R6把`NRG-REN-001-A/B/C`分别命名为三种“小型发电现场适配”，并把“小型水力发电”“小型风力发电”“小型太阳能发电”登记为产品。三者既不是明确产品，也与后续`ENE-HYD-001`、`ENE-WND-001`、`ENE-SOL-001`的机组、场站和维护能力重复。

此外，`NRG-DSP-001`同时要求三项可再生能源科技，会把本应由地点资源决定的条件路线误写成主线必修组合。

## 2. 临时独立身份

在终局整树裁决前，三项只保留为早期站址资源评估，不设计机组、不建设场站、不产生电力：

### `NRG-REN-001-A`

- 候选名称：水能站址评估；
- 直接前置：`SET-SUR-001-A`、`LOG-RTE-001-C`；
- 行动：水能站址调查行动；
- 记录：水能站址评估记录；
- 记录：候选水力站址。

本项只判断水头、流量、季节变化、泥沙、漂浮物、施工接近条件和基本生态约束能否支持后续小型水力站设计。

### `NRG-REN-001-B`

- 候选名称：风能站址评估；
- 直接前置：`SET-SUR-001-A`、`LOG-RTE-001-C`；
- 行动：风能站址调查行动；
- 记录：风能站址评估记录；
- 记录：候选风力站址。

本项只判断风况、湍流、极端风、地基、施工接近条件和周边安全间距能否支持后续风力场设计。

### `NRG-REN-001-C`

- 候选名称：太阳能站址评估；
- 直接前置：`SET-SUR-001-A`、`LOG-RTE-001-C`；
- 行动：太阳能站址调查行动；
- 记录：太阳能站址评估记录；
- 记录：候选太阳能站址。

本项只判断日照、遮挡、坡向、积尘、清洁用水、地基和接近条件能否支持后续太阳能场设计。

## 3. 与后续科技的边界

- `ENE-HYD-001`负责水轮机组、水力站工程和维护规程；
- `ENE-WND-001`负责风力机组、风力场工程和安全停机规程；
- `ENE-SOL-001`负责光伏组件分级、阵列、逆变、太阳能场工程和组件分级行动；
- 三项站址评估应分别成为对应设备与场站科技的条件前置，不得直接生成设备、场站或电力；
- `NRG-DSP-001`不得同时要求三条条件路线全部完成。能源调度只要求实际已经存在的至少一种可调度电源、计量、储能或备用能力，具体前置在终局整树复审中改线。

## 4. 终局裁决保留项

整树复审必须比较“保留三项站址科技”与“将站址评估下沉为三项后续场站科技的工程前置条件”两种方案。若单独站址科技不能形成玩家可感知的选址决策或条件路线分歧，则裁决为`DEMOTE`或`MERGE`，不得仅因本修正已写正文而强行保留。
