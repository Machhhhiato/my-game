# SPEC-M1-STAGE09-MATERIAL-INSTRUMENT-GRID-BATCH-AMENDMENT-001

## 结论

源序号144—149重建六项明确能力：绕组绝缘配制后移到树脂路线；材料汇总节点替换为建筑石灰烧制；万能仪表收窄为电工仪表制造；配电变压器定型先于中压线路设计；小型风机以`FL-A1`整机和小型风力站落地。

- `CHM-INS-001-A`绕组绝缘配制：产品为`Q-155`漆包线绝缘漆和`J-155`绕组浸渍漆，不概括全部电气绝缘材料。
- `CNS-MAT-001`建筑石灰烧制：只生产`CL90-Q`级建筑生石灰批次，不再汇总木材、砖石、骨料或再生构件。
- `ELC-INS-001`电工仪表制造：只生产`V-A1`电压表与`A-A1`电流表；温度、压力和流量交还专门科技。
- `ENE-TRF-001`配电变压器定型：产品为`S-A1`标准配电变压器。
- `ENE-MVD-001`中压线路设计：承接变压器定型和绝缘线缆制造，不生产电缆。
- `ENE-WND-001`小型风机定型：产品为`FL-A1`小型风力发电机组，工程完工后才形成小型风力站。
