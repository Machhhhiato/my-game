# 通信、数据、仪器与行政信息闭环

## 1. 容量、产品、设施与组织

8类服务容量：有线电话、基础无线电、区域通信骨干、数据记录与本地网络、时间同步、工业测量、远程计量、应急通信。通信服务按地点、带宽/信道、供电、设备和网络连通结算。

16项明确产品：有线电话机、电话交换设备组、基础无线电台、便携无线电台、天线馈线组、信号电缆、区域通信中继设备组、基础计算设备、数据存储设备组、本地网络设备组、统一时钟设备组、电压表、电流表、温度仪表、压力仪表、流量仪表。型号族草案`DH-A1`、`JH-A1`、`WXD-A1`、`WXB-A1`、`TX-A1`、`ZJ-A1`、`JS-A1`、`WL-A1`及仪表`V/A/T/P/F-A1`。

设施12类：通信设备工场、电话交换站、无线电站、中继站、区域骨干线路、本地数据中心、档案备份库、时间基准站、仪器校准室、远程计量中心、应急通信车/站、网络运行与故障中心。组织5种：通信管理、网络运营、数据档案、计量仪器、频率与信息安全监督。

## 3. 制度、状态与结算

法令5项：通信设施与频率、数据记录档案、个人与行政信息权限、计量数据责任、应急通信保障。政策5项：关键通信优先、无线电临时管制、断网应急、数据补录清理、仪器集中校准。状态8项：主要节点可通信、关键机构有冗余、无线覆盖可测、数据可恢复、时间一致、仪器可校准、远程计量可信、权限和变更可审计。

`有效通信/数据服务 = min(设备容量, 线路/信道, 供电, 值班维护, 终端覆盖) × 网络状态 − 拥塞丢失`。数据不是现实对象的替代品，错误记录必须通过核查纠正。第2年必须具备电话、无线、区域骨干、本地数据、备份、统一时钟、五类基础仪表、校准和应急通信。本轮不填带宽、频率、终端数量和精度值。

旧类型修正：值班通信不是产品，可编程逻辑是方法，区域骨干和本地网络是设施/关系，数据校验是行动，远程计量是服务与记录，通信稳定度只由真实网络证据形成。
