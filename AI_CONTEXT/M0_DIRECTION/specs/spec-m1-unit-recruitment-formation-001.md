# 方向二十九：部队征募、组建与番号

## 1. 组建链

```text
人口与健康资格
→ 自愿/依法征募与岗位分配
→ 编制采用
→ 具体型号装备入库
→ 基础训练与专业训练
→ 通信、医疗、补给、维修与驻地
→ 编成检验
→ 生成实体部队
```

## 2. 组建节点

| 稳定 ID | 完整结构名称 | 直接前置 | 明确结果 |
|---|---|---|---|
| `UNT-REC-001` | 征募资格、健康检查与服役登记 | `POP-REG-003`,`MED-TRI-001` | 合格、受限、暂缓和不适合名单 |
| `UNT-TRN-001` | 新兵基础训练与武器安全 | `MIL-ORG-002`,`MIL-EQP-001` | 完成基础训练的人员批次 |
| `UNT-SPC-001` | 驾驶、通信、工兵、医疗与维修专业训练 | `UNT-TRN-001`及对应装备 | 专业岗位资格 |
| `UNT-EQP-001` | 编制装备表、型号配发与缺装记录 | `MIL-ORG-004`,`QLT-TRC-001` | 每支部队实际装备和缺口 |
| `UNT-FRM-001` | 指挥岗位、分队关系与正式编成 | `UNT-EQP-001`,`MIL-ORG-003` | 具有稳定 ID 和番号的部队 |
| `UNT-RDY-001` | 编成检验、协同训练与任务准备 | `UNT-FRM-001`,`MIL-TACTIC-001` | 部队准备度来自实际训练和补给 |
| `UNT-RPL-001` | 伤亡补充、轮换整补与重建 | `UNT-RDY-001`,`MED-NET-001` | 人员装备补充和经验保留规则 |
| `UNT-DEM-001` | 复员、转隶与装备归还 | `UNT-RPL-001`,`POP-MIG-001` | 人员回到人口账、装备回到库存/维修 |

## 3. 首批十二支实体部队

沿用 `MIL-UNIT-001` 至 `MIL-UNIT-012` 的完整通用番号。每支必须保存人员、编制、装备型号与数量、训练、战术、补给、医疗、通信、维修、驻地、任务和经历；番号不代表自动满编。
