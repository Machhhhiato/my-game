# 方向十一：交通工具与车辆迭代

## 1. 方向结果

本方向形成玩家能直接感受到的运输里程碑：人力推车、自行车、摩托车、轻型卡车、中型卡车、重型卡车和专业作业车辆。每代改善必须通过载量、速度、续航、通过性、可靠性、驾驶需求和维护负担的实际结果体现。

## 3. 车辆里程碑

```text
人力推车
  → 自行车
    → 摩托车
      → 轻型卡车
        → 中型卡车
          → 重型卡车
```

拖拉机和工程车辆从已成立的动力、底盘和传动平台分支产生，不重新从零研发全部零件。

## 4. 型号与生产

- 每个平台至少形成一个正式民用型号；军用变体在军事方向引用同一底盘能力后另行定型；
- 后续代际必须改变玩家可感知的运输结果，不以`二级卡车`命名；
- 发动机、变速器、车桥、轮胎/行走件和电气附件作为聚合总成；
- 旧型号保留在库存和线路上，可继续生产、改型、拆件或回收；
- 车型换线影响工装、熟练度和备件，不自动升级现有车辆。

## 5. 第 730 日验证

- 推车、自行车、摩托车和轻/中型卡车形成连续可见的运输跨越；
- 至少一种专业车辆投入农业或工程实际运行；
- 车辆有正式型号、批次、油耗、故障、维修和备件记录；
- 中重型车辆受道路、桥梁、燃料和工场真实约束；
- 条件提前满足时可提前定型任何平台。
