# M1第三阶段旧建筑住用改造科技事实修正

## 1. 尺度裁决

`SET-HOU-001`保留为一项旧建筑住用改造科技。结构与居住条件鉴定负责决定哪些部分可以利用，住用改造把合格部分变成基础集体住处；两者共同形成“从旧建筑到可入住设施”的一个玩家里程碑，拆开后前一项只有报告而没有独立用途。

## 2. 候选结构

- 候选名称：旧建筑住用改造；
- 直接前置：`SET-SUR-001-B`；
- 行动：可修复建筑鉴定行动；
- 记录：可修复建筑鉴定记录；
- 工程：旧建筑住用改造工程；
- 设施：修复式集体住处。

本项让旧建筑中结构和基本居住条件合格的部分可以转为集体住处。屋顶仍在不代表建筑合格；不安全、无法疏散或无法满足基础卫生条件的部分继续封闭。它不提供后续住区供水、排污、暖通或完整住宅卫生升级。

## 3. 前置与解锁修正

居住边界划定已经依赖地表危险勘察，因此本项只保留`SET-SUR-001-B`。正式树只登记鉴定行动和最终设施，漏掉鉴定记录以及把合格旧建筑转为住处的实体工程；候选结构补齐二者，但不把内部步骤拆成独立科技。
