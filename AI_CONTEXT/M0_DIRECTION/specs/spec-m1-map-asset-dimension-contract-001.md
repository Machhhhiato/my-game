# 地图视觉资产尺寸与占地合同

> 本合同的RGBA母版、安全框、透明边界检查与确定性派生流程继续适用于设施详情图、科技图和事件图。把详细设施图直接作为地图占地、远中近显示槽位和1格/4格/7格设施等级的部分已被`SPEC-M1-STRATEGIC-ATLAS-MAP-ARCHITECTURE-001`取代。

## 1. 这份合同解决什么问题

过去的地图资产把四件不同的事混在了一起：原图有多少像素、透明画布里真正画了多大、设施在世界中占几个格、玩家屏幕上看到多大。以后四者必须分别登记，任何一个字段缺失都不得接入产品。

| 层级 | 决定内容 | 不得代替 |
|---|---|---|
| 源画布 | 美术母版的像素与宽高比 | 不决定设施占地 |
| 可见边界 | 非透明像素范围与构图安全区 | 不决定点击范围 |
| 逻辑占地 | `occupiedCellIds`与标准六角格并集 | 不决定贴图原始尺寸 |
| 显示槽位 | 不同语义缩放下的屏幕上限与细节层级 | 不改变逻辑占地 |

## 2. 位图与程序图形边界

- 设施、聚居地阶段、车辆、装备、产品、科技插图、事件插图和少量地形细节可以使用RGBA位图。
- 六角格、道路、铁路、供水、输电、补给线、选中轮廓、候选范围、面板、按钮、进度条和正式文字必须由Canvas、SVG或CSS生成。
- 连续地形是跨格底图与程序叠层，不为每个六角格生成一张独立地形贴图。
- 位图允许为辨识度略越过格线，但命中、选址、扩建与阻塞判断只读取逻辑占地。

## 3. 地图设施母版合同

当前校准族统一使用以下母版，不再让单格设施、工厂和联合厂区各自猜尺寸：

| 字段 | 冻结值 |
|---|---|
| 母版画布 | 1536×1024，横向3:2 |
| 色彩与透明 | 8位RGBA；背景完全透明 |
| 相机 | 约55度三分之四俯视，朝向固定 |
| 光照 | 左上方柔和中性日光 |
| 安全框 | x=122…1414，y=61…942 |
| 安全边距 | 左右各8%，上6%，下8% |
| 地图锚点 | 安全框底边中心，像素(768,942)，归一化(0.5,0.9199) |
| 构图 | 主体完整、不得触边；外投影不得越出安全框 |
| 标准派生 | 768×512与384×256，只做等比缩放，不拉伸、不二次裁切 |
| 文件名 | `{family}-{subject}-{revision}-{width}x{height}.png` |

图像生成结果先保留为`masters/`原始证据，再经过确定性的安全框归一化进入`normalized-1536/`。只有归一化版本可以生成运行候选；原始生成图不得直接被运行时引用。

## 4. 标准格、设施占地与插图

地图只有一种标准六角格。三件校准资产分别验证三种占地，不建立大号建筑格：

| 资产 | 逻辑占地 | 画面职责 |
|---|---:|---|
| 取水泵站 | 1格 | 检查小设施在中近景是否可辨、远景是否应退化为功能标记 |
| 标准工厂 | 4个相邻格 | 检查贴图是否覆盖占地并集而不冒充一个放大六角格 |
| 联合厂区 | 中心格加六个相邻格，共7格 | 检查厂区扩建、外缘连续轮廓、内部格线弱化与周边路线遮挡 |

选中多格设施时，系统沿全部占用格的外边缘绘制连续轮廓；公共内边只保留很弱的规则提示。贴图尺寸不参与占地计算，点击热区也不得读取透明像素边界。

## 5. 语义缩放合同

缩放不是把同一张图无限放大。每一档先决定玩家此刻需要辨认什么，再决定是否显示位图。

| 缩放档 | 标准格屏幕宽度 | 位图策略 | 标签策略 |
|---|---:|---|---|
| 区域远景 | 约34px | 单格设施退化为20—24px功能标记；多格厂区只保留简化轮廓与状态标记 | 只显示聚居地、战区和关键瓶颈 |
| 地点中景 | 约58px | 显示设施位图；取水泵站约76×51px、标准工厂约158×105px、联合厂区约220×147px | 显示名称、运行状态与一项关键缺口 |
| 作业近景 | 约92px | 允许显示高分辨率位图；取水泵站上限122×81px、标准工厂250×167px、联合厂区350×233px | 增加线路、扩建边界、维护与占地提示 |

这些像素是1920×1080主规格下的显示槽位上限，不是图片文件尺寸。1366×768最低适配按可用地图宽度等比收缩，高DPI只提高采样密度，不改变CSS显示尺寸。

## 6. 地图模式与遮挡门

同一批资产必须在默认、勘察、工程、物流和军事五种地图模式中复核：

- 默认模式：格线基本隐藏，设施与地形共同可读；
- 勘察模式：调查边界和未知区域优先，设施不能盖住调查状态；
- 工程模式：候选、禁止、占地并集、道路与管线优先；
- 物流模式：道路、铁路、仓储、补给和瓶颈优先；
- 军事模式：控制、部队、前线和补给优先，民用设施退为次级信息。

任何模式出现下列情况即退回：路线被建筑完全遮断、锚点漂离占地、贴图触碰裁切边、标签压住状态、单格设施在远景仍占据大片画面、多格设施重新被画成一个放大六角形。

## 7. 分辨率验收

每一资产族至少保留三组实际截图证据：

1. 1920×1080，设备像素比1；
2. 1366×768，设备像素比1；
3. 1920×1080或等效CSS尺寸，设备像素比2。

每组都要覆盖远、中、近三档，至少切换工程与物流两种高信息密度模式，并同时放置1格、4格和7格设施。通过标准是可辨、不中断路线、占地不误读、透明边缘无色边、缩放切换无尺寸跳变。

## 8. 当前校准结论

- 三张生成母版均为1536×1024 RGBA，格式和视角一致；
- 原始生成图的非透明边界有触及画布边缘的情况，证明“提示词要求留边”不能替代机器检查；
- 归一化版本已被确定性地收进统一安全框，三张图的最外可见像素均不越过x=122…1414、y=61…942；
- 已生成768×512运行候选与384×256实验页样本；
- 当前只证明尺寸合同和校准流程可行，不代表三张资产已成为正式产品美术，也不授权写入产品资产目录。
