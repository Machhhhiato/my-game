# SPEC-M0-DESCRIPTION-001 · M0 工程与科技描述结构、风格与总规格冻结

## 1. 本规格决定什么

本规格只决定工程、科研、设备、阶段报告、维修和制度类文字怎样组织。玩家必须先看懂当前对象、作用、需求、时间、阻断和结果，之后才阅读技术说明与世界内文字。

本任务不写具体负责人的完整故事，不写最终科技正文，不修改已经接受的机制、数字和结果，也不修改游戏代码。只有本规格逐项被用户接受，并最终整体接受后，才可以把 `overall_spec_frozen` 标为 true。

## 2. 已接受输入与不能改动的事实

- 科研完成只解锁图纸、方法、工程或制造条件，不直接生成设施、设备、产量、库存或地图情报。
- 实体能力必须经过制造或修复、运输、部署、标定、配人、供能和维护中实际需要的环节，才对指定阶段生效。
- 第一座前哨首次阶段报告固定说明新事实、工程影响、当前缺口、预计时间、完成结果和下一步；没有真实选择时不暂停工程。
- 第二座复制与重复建设的普通进展进入短日志；只有新事实、真实选择、阻断和验收完成才主动提示。
- 工程页面显示基础方案时间、当前方案时间和缩短原因；科技页面只能显示部署后的预计影响，不能把预计效果伪装成已经生效。
- 所有人员、物资、工作量、地点、设备状态、暂停原因和恢复条件都引用已接受的真实状态，不新增“文案专用”变量或效果。
- 来源附件只提供通用规则：技术本身可信，荒诞主要来自制度怎样解释结果；不复制或仿写小说原文、章节与专有名词。

## 5. 第一项修订依据：两个真实科研写法

### 5.1 《群星》案例：动力外骨骼

用户在 `M0-S003-U043` 指出，上一轮把资料页里的“工程学、工业技术、T1、基础花费”误当成了《群星》科研候选卡表面的常驻文字。真实科研选择界面的卡片重点是科技名、直接效果或解锁和简短原文；成本、分类及其他附加信息主要由数字、颜色和小图标承担，完整正文在鼠标悬停后出现。

参考 2026 年 4.3 版本科研界面截图，玩家直接扫读的结构更接近：

```text
[科技图像]  科技名称                         [成本/分类图标]
             直接效果或解锁
             一句不超过两行的原文短表述

鼠标放到科技名称或简短表述：显示完整说明正文
鼠标放到小图标：显示准确成本或领域
```

来源：[Paradox 论坛中的 2026 年科研界面截图](https://forumcontent.paradoxplaza.com/public/1456239/20260217093146_1.jpg)。本项目借用的是信息层级，不复制《群星》的美术和具体布局。

### 5.2 用户附件案例：工蜂-7工业外骨骼

以下是用户附件第 446 至 449 行中的完整范例，不是小说原文：

> 工蜂-7通过表面肌电信号预测使用者动作，可将单人持续搬运能力提高至四百公斤。膝关节和脊柱位置安装有压力传感器，可在肌肉拉伤前发出三级预警。
>
> 在生产冲刺模式下，系统会关闭疼痛、震颤和关节损伤提示，以免频繁警报干扰流水线节拍。
>
> 制造商表示，预警并不能阻止损伤，只会提前影响产量。

它是一段完整的科技说明：先给可信技术、明确参数和正常用途，再写制度怎样使用它，最后用一句没有解释的冷结尾改变整段含义。

### 5.4 `M0-S003-U043` 后的修订卡片逻辑

用户认可“短卡加完整正文”的组合方向，但要求按真实科研卡的信息层级微调。当前提案为：

| 状态 | 玩家看到什么 | 不显示什么 |
|---|---|---|
| 默认卡片 | 科技图像、科技名称、一至三条直接效果或解锁、一句不超过两行的简短表述、成本与领域小图标 | 不常驻显示“工程学、工业技术、T1、基础花费”等文字标签；不显示底层阻断、暂停、恢复和状态表；不常驻整篇正文 |
| 悬停成本或分类图标 | 该图标对应的准确说明，例如“科研工作量：24”“分类：工程制造” | 不展开整份科技正文，不让玩家猜图标含义 |
| 悬停或聚焦科技名称与简短表述 | 直接显示附件式完整科技正文：可信技术与参数、实际用途、制度性问题和冷结尾 | 效果行只说明玩法结果，不负责弹小说正文；不重复底层调度字段 |

用于本轮复核的示例卡是“恢复精密制造”：

```text
默认卡片
恢复精密制造
解锁工程：精密工坊恢复
复原精密机床的加工参数、量具校准流程与试制标准。
[科研工作量图标] [工程制造图标]

悬停名称或简短表述
避难所档案保存了精密机床的加工参数、量具校准流程与试制标准。研究组将把分散记录整理成可执行工艺，使工程队能够恢复那座已经布线、但停机多年的旧工坊。

档案管理处确认资料保存完整。缺失的只有最后三次设备改造记录、全部维护日志，以及所有曾经实际操作过这些设备的人。
```

该卡仍只是第一项复核稿。整卡点击如何与“选择研究”、触屏和手柄交互兼容，可在玩家展示形式确定后补充，不在这里提前制造复杂按钮。
