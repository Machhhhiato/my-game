# M1第四阶段生产批次追溯科技事实修正

## 1. 尺度裁决

`QLT-TRC-001`保留为一项生产批次追溯科技。批次编号、生产履历和单件序列履历共同把产品问题追到同批原料、工序和设备；它为质量隔离与召回提供直接玩法反馈，不是单纯行政手续。

## 2. 候选结构

- 候选名称：生产批次追溯；
- 直接前置：`LOG-WHS-001`、`QLT-UNI-001`；
- 标准：产品批次编号；
- 记录：生产履历；
- 记录：序列履历；
- 状态：可追溯产品批次。

本项让产品故障可以追到同批原料、生产日期、工序和设备，受影响批次能够单独隔离，其余批次不必一并停用。它不自动判定故障原因，不保证记录内容真实，也不取代后续质量检验。

## 3. 解锁修正

正式树把“产品批次”误写成产品，把“生产履历标准”误写成记录，且缺少批次编号标准。候选结构把批次恢复为可追溯状态，分列编号标准、生产履历和序列履历。
