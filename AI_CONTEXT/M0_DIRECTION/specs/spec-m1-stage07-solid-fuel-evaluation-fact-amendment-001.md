# SPEC-M1-STAGE07-SOLID-FUEL-EVALUATION-FACT-AMENDMENT-001

## 结论

`RSC-COL-001` 保留并改名为“固体燃料评价”。本项只评价煤等固体矿物燃料样品的用途与风险，不再同时承担资源勘查、矿场建设、矿物开采和矿山安全。

- 前置：地质踏勘；基础实验室运行
- 行动：固体燃料评价行动
- 标准：固体燃料样品评价标准
- 记录：固体燃料样品档案
- 记录：固体燃料评价记录
- 状态：固体燃料用途与风险等级
- 科研点：候选35点

科研不自动生成矿物燃料批次、燃料矿场或任何燃料实例。水分、灰分、挥发分、发热表现、结渣和污染风险必须由实际评价行动写入记录；候选用途不等于具体锅炉或窑炉已经接受该燃料。

删除`RSC-FE-001`铁矿物评价前置，新增`SCI-LAB-001`基础实验室运行。删除`RSC-COL-001 → RSC-CLS-001`：矿山关闭应承接实际矿场、矿山安全和环境记录。后续固体矿物燃料分级、洗选与锅炉适配路线保留对本项的合理依赖。
