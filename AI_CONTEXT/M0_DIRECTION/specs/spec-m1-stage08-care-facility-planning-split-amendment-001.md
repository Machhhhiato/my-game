# SPEC-M1-STAGE08-CARE-FACILITY-PLANNING-SPLIT-AMENDMENT-001

## 结论

`SET-PUB-001-B` 拆为“母婴设施规划”和“长期照护规划”，原ID降为迁移别名。孕产与新生儿照护设施、长期照护设施服务人群和空间要求不同，不再共用“照护设施”汇总对象。

### `SET-PUB-001-B-A` 母婴设施规划

- 前置：妊娠出生登记；街区布局规划
- 记录：母婴照护设施规划图
- 标准：母婴照护设施设计标准
- 工程：孕产与新生儿照护设施建设工程
- 设施：孕产与新生儿照护设施
- 科研点：候选20点

### `SET-PUB-001-B-B` 长期照护规划

- 前置：健康状态追踪；街区布局规划
- 记录：长期照护设施规划图
- 标准：长期照护设施设计标准
- 工程：长期照护设施建设工程
- 设施：长期照护设施
- 科研点：候选20点

两项科研都不自动生成图纸实例、工程、完工设施、床位、岗位或服务能力。母婴设施规划不提供产科医疗能力；长期照护规划不完成照护等级评估、机构转介或入住资格判断。
