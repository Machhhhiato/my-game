# M1固定一秒一日、两小时挂机与基础现代生产力终局节奏

## 1. 第一规则

世界公历正常逐日、逐月、逐年推进，基础速度固定为：

```text
1世界日 = 1秒实际运行时间
```

月份继续使用真实的28、29、30或31日，不设置首月特殊速度，不把若干世界月硬映射为某段现实时间。

过去所称的“两年终点”只保留为旧内容筛选来源。正式名称统一为**基础二十一世纪生产力终局**。它不绑定第24个月、第730日、现实第2小时或任何强制最短时间。

## 2. 固定时钟换算

| 世界时间 | 实际运行时间 |
|---|---:|
| 1日 | 1秒 |
| 28日 | 28秒 |
| 30日 | 30秒 |
| 31日 | 31秒 |
| 365日 | 6分05秒 |
| 2年约730日 | 约12分10秒 |
| 前5分钟 | 300个世界日，约9.9个月 |
| 后续2小时挂机 | 7,200个世界日，约19.7年 |
| 前5分钟加2小时挂机 | 7,500个世界日，约20.5年 |

这次修改把现实等待压缩为上一版的五分之一，但两小时挂机与旧版十小时挂机都推进约7,200个世界日。因此，世界内的终局资源累计、工程容量和科研容量不应再机械缩小五倍；需要改变的是现实播放速度、反馈密度和离线结算性能。

## 3. 标准体验节奏

### 3.1 前5分钟

前5分钟用于建立约一千人的可挂机小循环：

- 二十八人行动队接触一个已有地点、人口和残缺设施的聚居点；
- 完成接触、核验、最低服务恢复、职责划分和统合；
- 水、重复食品来源、关键供能、卫生、维修、住处医疗、机动人力和挂机队列能够接续运行；
- 一次性库存、免费人口和无来源修复不能冒充正循环。

在一秒一日下，这一过程对应约300个世界日、接近十个世界月。它不再被称为首月教程，但仍属于开局第一个快速正循环。

### 3.2 后续约2小时挂机

前5分钟完成基本授权后，标准平衡方案在后续约2小时挂机中推进到基础现代生产力终局：

| 实际累计运行阶段 | 主要能力推进 |
|---:|---|
| 00:00—00:05 | 千人级水、食物、供能、卫生和维修小循环 |
| 00:05—00:25 | 稳定作坊、农业、仓储、住处和基础研究 |
| 00:25—00:55 | 建材、金属、道路、通信、贸易和多地点统合 |
| 00:55—01:25 | 标准工厂、车辆、区域能源、公共服务、正式型号和维护网 |
| 01:25—02:05左右 | 工业母机、枪械弹药、教育科研、医疗、财政和跨聚居点运行证据闭合 |

阶段时间只用于体验验收，不是科技或工程的解锁时刻。优化路线可以提前，战争、事故、短缺、错误分配或可选发展会延后。

## 4. 终局仍由真实能力证据触发

终局至少要求以下事实共同成立：

1. 关键资源能够持续生产、运输、储存和结算；
2. 主线科技完成科研点、样品、试验、设施和工程反向前置；
3. 主线工程实际支付工程工时、材料、设备、运输和施工条件并通过验收；
4. 主要产品能够量产、检查、入库、维护和获得备件；
5. 人口、岗位、住房、食品、水、能源、卫生、医疗、教育、行政和治安共同承载当前规模；
6. 多聚居点之间存在可运行的物流、贸易、财政、外交和应急关系；
7. 基础军队、枪械、弹药、训练、补给和维修形成闭环；
8. 关键设施留下连续运行、故障、维护和恢复证据。

到达某个世界日期或累计运行两小时不能替代这些证据。

## 5. 资源、科研与工程的统一结算不变

```text
当月可提供量 = 基础月产率 × 有效容量 × 效率 × 月份占比
当月实际交付量 = min(当月可提供量, 输入, 路线, 目标, 授权)
项目进度 = 上月进度 + 当月实际交付量
```

一秒一日只改变同一世界日需要等待的现实秒数，不改变一个世界月能够生产多少资源、提供多少科研点或完成多少工程工时。

终局节奏继续由以下对象形成：

- 科技科研点、样品、试验和证明条件；
- 工程工时、材料、设备、运输、施工面和验收；
- 工厂扩建、生产线爬坡、换线和型号改进；
- 原料、能源、运力、合格率、库存覆盖和维护备件；
- 人口统合、培训、组织覆盖和公共服务执行量。

禁止增加科研专属秒倒计时、工程隐藏减速倍率、免费离线收益、到点赠送或日期门。

## 6. 数值重算边界

R6的25,285点旧主线科研量与74项旧主线工程继续只作为终局范围及相对难度输入，不能直接证明两小时可达。

由于本次“现实时间 ÷ 5”和“每世界日现实耗时 ÷ 5”同步发生，世界内可用月数与R2大致保持同一量级。数值重算应沿用R2的约二十年世界尺度，但必须重新验证：

- 约20.5年的逐月人口与年龄队列；
- 有效科研人员、设施、样品和累计科研流量；
- 工程队、施工设备、材料和运输能力；
- 工厂扩建、生产线爬坡、能源与关键库存；
- 维护积压、备件覆盖、公共服务和军队消费；
- 标准路线在前5分钟后约2小时闭合终局，且不存在日期门。

不允许因为现实目标从十小时降到两小时，就把所有科研点、工程工时和资源需求简单除以五。

## 7. 人口与年龄

标准终局附近约经过20.5个世界年：

- 出生、死亡、迁出、流民、兼并和协议统合继续进入同一人口总账；
- 年龄按世界公历正常推进；
- 早期出生人口可能在终局前成年并接受培训；
- 达到劳动年龄不等于自动成为可调度人力，仍受健康、教育、照护和岗位限制；
- 八万至十万人继续作为终局生产体系的参考承载规模，不是固定日期奖励或强制胜利线。

## 8. 验收

1. 时钟严格为一世界日一秒，月份保持真实日数；
2. 前5分钟参考种子可以形成千人小循环；
3. 标准路线在其后约1.8至2.2小时挂机区间闭合基础现代生产力终局；
4. 优化路线允许提前，受损路线允许延后；
5. 终局由资源、科研、工程、生产、维护、人口和制度证据触发；
6. 前台与离线使用相同世界日、月结算和随机种子规则；
7. 高频推进下月结算、事件、日志、存档和离线补算不存在重复或遗漏；
8. 科技正文R7仍停在`SET-SUR-001-B`，时间修订不得解锁下一项正文。

## 9. 当前实现差异

当前M0实现仍为20秒一世界日，与目标一秒一日相差20倍。本轮只冻结第一层方向，不直接修改产品代码、存档、测试或构建。后续第四层实施必须同时修改时钟常量、严格存档验证、离线补算、月末结算批处理、事件密度和性能测试，不能只改显示数字。
