# 方向十：化工、药剂与工业耗材

## 1. 方向结果

本方向把遗产药剂和零散配制推进为能够识别原料、控制反应、检验批次、处理危险物并稳定生产基础酸碱、肥料、清洁消毒品、润滑材料、聚合物和工业药剂的化工体系。

## 3. 产品聚合

- 基础酸碱盐与通用试剂；
- 清洁、洗涤和消毒品；
- 肥料、营养液和土壤改良剂；
- 燃料处理剂、润滑油、润滑脂和冷却液；
- 橡胶密封、软管、绝缘与基础塑料；
- 涂料、胶黏剂、密封剂和防腐材料；
- 工业爆破材料、底火与发射药前置批次；
- 化工专用防护与处置耗材。

## 4. 维护与风险

- 每批保存原料、配方、工艺、检验、包装、有效期和去向；
- 危险化学品按相容性分区，不能用一个通用库存隐藏风险；
- 反应温度、压力、通风、腐蚀和静电保护进入设施状态；
- 试剂和耗材会过期、吸湿、污染或失效；
- 含能材料只有在真实军工或矿山需求、隔离设施和安保成立时生产。

## 5. 第 730 日验证

- 水务、农业、医疗、机械和建材均能取得可追溯的基础化工耗材；
- 至少一类工程聚合物实现从配制到成品与寿命验证；
- 危险物批次能召回、隔离和处置；
- 军工含能材料不会因武器科技完成凭空出现；
- 所有节点无日期门。
