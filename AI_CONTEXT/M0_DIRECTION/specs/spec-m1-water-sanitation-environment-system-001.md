# 水源、供水、污水、固废与环境闭环

## 1. 对象边界与运行链

`水源资源 → 取水 → 原水输送 → 净化消毒 → 清水储存 → 分区配水 → 使用 → 污水收集 → 处理/回用/排放`；固废沿`分类收集 → 转运 → 回收/堆肥/危险隔离/最终处置`运行。地表水勘测、地下水勘探、旧管线定位与旧供水系统测绘继续是四项独立科技。

水源、原水、饮用水、中水和污水是不同地点化资源状态；泵、管、罐和处理模块是产品；取水站、水厂、管网和污水设施是实体。

## 5. 统一月结算与第2年存在事实

`可供水量 = min(水源安全量, 取水容量, 处理容量, 储配与管网容量) × 人员设备状态 − 漏损`；污水量从实际用水与生产排放派生，固废从人口和生产批次派生。未联网地点不共享水；停电影响泵站、处理、加药和污水提升。

第2年至少存在主水源、备用/应急水源、合格水厂、清水储配、分区管网、污水收集处理、固废收运处置、水质与环境监测，以及可启动退出的法令政策。本轮不填水量、管长、井深、药耗、污水率和设施数量。

旧数据修正：管网和区域水务不是组织；饮用水、中水和污泥不是记录；应急旁路是工程/行动；水源保护是法令与地点状态，不是无条件科技加成。
