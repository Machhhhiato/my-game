# 第 730 日产品、零件与养护目录

## 1. 目录目的

本目录把`具备生产能力`翻译成玩家能直接感受到的产物。

玩家看到的是泵、机床、自行车、卡车、枪械、装甲车辆等**产品家族、里程碑代际和有意义的型号迭代**，不是枪管、曲轴和每种螺钉组成的零件海洋。

第 730 日仍是平衡检查点，不是解锁门。玩家提前满足真实前置时，可以提前生产目录中的后期产品；没有材料、设备、人员和维护能力时，研究完成也不能凭空获得成品。

## 2. 借鉴《钢铁雄心 IV》后的抽象规则

本项目只借鉴装备整合策略，不复制其战争范围和数值：

1. **产品先按装备家族归类。** 例如`枪械`是一个家族，不让玩家分别生产枪管、枪机和枪托。
2. **家族内部同时保留代际和型号。** 代际表示重大技术台阶，例如`推车 → 自行车 → 摩托车 → 轻型卡车 → 中型卡车 → 重型卡车`；型号表示同一家族、同一代际内经过试验和生产反馈形成的可感知改进。
3. **改进体现在少数可感知指标。** 车辆主要显示载量、速度、通过性、续航、可靠性和养护负担；武器主要显示火力、防护、机动、可靠性、弹药和养护负担。
4. **同型号修订、同代换型和跨代换线的损失不同。** 同型号改进保留最多生产熟练度，同代新型号次之，跨代升级损失更多，但都明显少于改成无关产品；具体比例以后由第四层数值任务确定。
5. **旧代、旧型号不会因新科技自动消失。** 它们继续存在于库存、部队和聚居点，可以继续生产、逐步替换、改装、拆件或回收。
6. **可靠性与养护决定实际可用量。** 低可靠性、缺少零件、恶劣路线和超期使用会增加停机与损失；维修班组只能在有备件、工具和时间时恢复设备。
7. **型号必须产生爽点，但不扩张成型号墙。** 同一家族可以形成`载量优先、速度优先、可靠性优先、节省材料`等型号；只有性能、用途、成本或维护发生玩家能感受到的变化时才建立新型号，微小工艺修订留在当前型号内部。

## 3. 产品家族、代际与型号

产品采用三层结构：

```text
产品家族：枪械
  ├─ 技术代际：标准枪械
  │    ├─ <正式定型代号>：初始量产标准
  │    ├─ <正式改型代号>：精度、可靠性或火力得到明显提升
  │    └─ <用途改型代号>：在重量、成本或恶劣环境适应上形成明确取舍
  └─ 技术代际：改进枪械
       └─ <新一代正式定型代号>
```

- **产品家族**决定共同用途、库存入口、维护体系和主要生产设施；
- **技术代际**来自重要科研与工程突破，改变能力上限；
- **型号**来自设计、试制、检验、量产经验和实际使用反馈，把同一代技术做得更强或更适合某种任务；
- 型号可以由系统按规则命名，也允许玩家重命名，但内部使用稳定 ID，不以显示名驱动逻辑；
- 同一产品家族的多个型号可以同时存在于库存、生产线和使用单位中；
- 部队、聚居点或设施可以只要求`枪械`、`轻型卡车`等家族，由补给规则按质量优先级分配型号，不要求玩家逐件发放；
- 玩家可以为精锐部队、关键运输线或高风险设施设置最低型号或换装优先级。

### 3.1 型号如何变强

每个产品家族只选择 2—6 个最能体现用途的指标。型号升级必须让至少一个指标出现可感知变化：

| 产品家族 | 主要型号指标 |
|---|---|
| 枪械 | 火力、有效距离、可靠性、重量、生产成本、养护负担 |
| 弹药 | 威力、可靠性、储存寿命、材料成本、生产安全 |
| 卡车 | 载量、道路速度、越野速度、续航、可靠性、养护负担 |
| 机床 | 加工尺寸、精度、加工速度、材料适应、可靠性、校准负担 |
| 泵站设备 | 流量、扬程、能耗、污染耐受、可靠性、维护间隔 |
| 坦克 | 火力、防护、道路/越野速度、续航、可靠性、生产与养护负担 |

科研突破可以带来整体更强的新一代型号，不要求每次升级都强制一个负面交换；但在同代改型中，追求更高火力、载量、速度或防护通常会增加材料、能耗、生产难度或养护负担。玩家既能享受明确的数值提升，也要决定是否值得换线和换装。

### 3.2 拟真型号与代号

每一代正式投产产品都必须拥有世界内真实使用的型号或代号。`第一型`、`第二型`、`改进型`只允许作为第一层设计占位，不能直接成为最终玩家名称。

型号应像现实工业和军队装备一样，由研制、定型和使用机构赋予，而不是由系统拼接`枪械 II +5`：

- 每个政体或主要生产体系拥有自己的命名规则，可以使用用途缩写、项目序号、定型年份、工厂/设计机构传统或正式绰号；
- 同一代的重大改型可以使用字母、批次或用途后缀，微小修订仍留在维护与生产记录中；
- 外部势力、贸易装备和缴获装备保留其原有代号，不自动改成本方编号；
- 玩家可以接受系统生成的正式定型代号，也可以在定型时改名；显示名与稳定内部 ID 必须分离；
- 代号中的年份只记录实际定型时间，不构成研究或生产日期门；
- 代号必须在生产线、库存、部队装备、维修记录、缴获清单和战后报告中保持一致。

以下仅是命名结构示意，不是冻结的最终玩家文字：

| 产品家族 | 拟真代号结构示意 |
|---|---|
| 枪械 | `用途缩写—序号`，重大改型追加字母后缀 |
| 卡车 | `载重等级/用途缩写—系列号`，改进批次追加后缀 |
| 坦克 | `重量等级缩写—项目序号`，定型后可增加正式绰号 |
| 机床 | `加工类别—最大规格—系列号` |
| 泵站设备 | `用途—额定能力—系列号` |

### 3.3 型号优势如何被玩家感受到

型号的爽点来自实际运行结果，不来自型号卡直接宣布比对方强：

- 枪械的火力、射程和可靠性通过交战距离、压制效果、持续作战、故障和弹药消耗体现；
- 坦克的火力、防护、机动和可靠性通过突破是否成功、承受命中、车辆损失、掉队和维修时间体现；
- 卡车的载量、速度和可靠性通过真实运输批次、补给到达时间、路线损耗和停机比例体现；
- 战后或任务报告只陈述已经发生的事实，例如某型号在泥泞行军中掉队较少、某型枪械在长时间交火后故障增加，不能在战前给出无来源的敌我完整数值对照；
- 缴获、拆解、试用和长期交战可以逐步形成对外部型号的可信认识，但认识本身不是爽点，实际结果才是。

### 3.4 型号产生与换装

新型号需要至少一种真实来源：

1. 新科研或材料突破；
2. 试制与检验发现；
3. 生产线积累的制造经验；
4. 使用、故障、维修或战斗反馈；
5. 对外贸易、缴获装备或技术交流。

形成新型号后，玩家决定继续生产旧型号、逐步换线、立即换线、改装旧库存或只装备少数优先单位。新型号不会自动替换全部库存，也不会让旧型号数值同步变强。

## 4. 产品记录的最小结构

每个玩家可生产产品只保存和展示：

- 产品家族；
- 当前代际/里程碑；
- 具体型号、设计来源和投产版本；
- 生产状态：新造、组装、再制造或仅能维修；
- 主要用途和使用地点；
- 2—6 个真正改变使用方式的性能指标；
- 所需材料、通用零件包和专用耗材；
- 养护等级、维护周期、可靠性和停机数量；
- 新造、库存、已部署、待修、报废和回收数量；
- 当前生产线熟练度、同型号修订/同代换型/跨代换线影响；
- 正式代号、定型来源和实际使用结果记录。

不得把厂牌、口径、零件编号或每次微小工艺修订都变成玩家必须管理的独立库存；但性能发生可感知改变的正式型号必须独立保存产量、库存、部署、可靠性和换装状态。

## 5. 零件的适度聚合

第 730 日只保留以下通用零件/耗材池：

| 零件或耗材池 | 覆盖对象 | 玩家理解 |
|---|---|---|
| 通用机械件 | 轴、齿轮、轴承/衬套、弹簧、紧固与常用传动件 | 大多数机器都需要的机械备件 |
| 泵阀与流体件 | 泵、阀、管接、软管和流体控制组件 | 水务、燃料、化工、医疗和农业共用 |
| 密封过滤与润滑件 | 密封、滤材、滤芯、润滑和防腐耗材 | 决定机器能否长期运转 |
| 电气与仪表件 | 线缆、开关、保护、传感、仪表和常用控制件 | 发电、车辆、通信和生产线共用 |
| 动力与传动总成 | 发动机/电机、变速与主要传动组件的聚合库存 | 车辆和重型设备的大修核心，不拆成几十种零件 |
| 轮胎与行走件 | 轮胎、轮组、履带/等价行走组件 | 自行车、车辆、农机和装甲装备共用类别 |
| 刀具工装与量具 | 刀具、模具、夹具、量具和校准件 | 决定能不能继续生产合格产品 |
| 产品专用备件包 | 枪械、无线电、医疗设备、发电设备等家族专用备件 | 只按产品家族登记，不展开内部零件 |

原材料如钢、铜、铅、玻璃、木材、橡胶/替代材料、燃料和化学品仍按材料库存管理，不伪装成零件。

## 6. 养护的统一层级

| 养护层级 | 工作内容 | 需要什么 | 结果 |
|---|---|---|---|
| 日常保养 | 清洁、润滑、紧固、补液、检查和小调整 | 使用人员、少量耗材 | 延缓可靠性下降 |
| 定期维护 | 更换磨损件、校准、排故和预防性停机 | 维修人员、通用件、专用备件包 | 恢复正常可靠性 |
| 大修 | 拆检、总成更换、结构修复和重新验收 | 专业工场、动力总成/关键件、量具 | 让重度损耗设备恢复服役 |
| 再制造 | 以旧设备为基体重建并升级到当前标准 | 母机、材料、工装、完整检验 | 形成可重新入库的产品 |

玩家不逐台安排日常保养；玩家决定维护标准、备件储备、维修设施、班组、优先级和是否批准大修/再制造。

## 7. 第 730 日可生产的产品与中间品

表中的`完整生产`表示可以依靠已建立的本地体系重复生产；`组装/再制造`表示允许使用遗产或贸易取得的战略总成，但本地能够完成主体制造、组装、检验和长期维修；`条件路线`表示不是普通路线强制终点，但前置满足时可以提前实现。

### 7.6 军事与安全装备

在当前两年普通路线中，枪械、弹药、工兵和基础保障是终点必备能力；装甲汽车是可选工业路线。轻型坦克只有在动力总成、履带行走、装甲材料、武器、运输和专业维修全部提前满足时才可试制；中型和重型坦克不作为第 730 日普通路线必备项。若将中型或重型坦克改为两年必备，必须同时上调人口、冶金、发动机、燃料、道路桥梁和军工产能终点，不能只在科技树上添加名称。

## 8. 终点库存与养护界面只需要回答的问题

玩家对任一产品家族只需要看到：

1. 当前能生产到哪一代；
2. 每周期能生产多少，瓶颈是什么；
3. 库存、部署、待修和报废分别多少；
4. 主要性能相对上一代改善了什么；
5. 需要哪几类聚合零件和耗材；
6. 当前可靠性、维护覆盖和预计停机风险；
7. 换代会损失多少生产熟练度、旧设备如何处理；
8. 哪些地点或部队正在使用它。
9. 当前型号在运输、生产、作业或战斗中已经表现出什么实际结果。

不要求玩家为一辆卡车逐个更换轮胎，也不要求为一支枪逐个选择零件。零件短缺通过家族备件包、维修队负荷、停机比例和可靠性体现。

## 9. 与科技树和工程的连接

每个产品家族按以下方式连接科技和工程：

```text
识别/维修旧产品
  → 建立聚合零件与养护标准
  → 完成第一代可生产产品
  → 建立稳定生产线和检验
  → 通过试制与反馈形成同代改进型号
  → 提升关键性能形成下一代里程碑
  → 扩产、跨地点复制、旧代改装或回收
```

- 科技解锁产品代际、生产方法和养护标准；
- 工程建设真实生产线、维修工场、试验场、仓储和运输条件；
- 生产线制造实体产品并积累熟练度；
- 使用对象消耗产品寿命、耗材和备件；
- 维修与再制造把损耗设备重新送回库存；
- 正式型号只在玩家感受到性能、成本、可靠性或用途变化时建立；微小改良留在生产标准内部。

## 10. 下一步

以本目录为结果层，下一轮先为以下六个最强里程碑产品族倒写准确科技与工程：

1. 取水设备：手动取水 → 动力泵站 → 多点供水机组；
2. 通用机床：手工作台 → 动力机床 → 标准精密机床组；
3. 道路运输：推车 → 自行车 → 摩托车 → 轻型/中型/重型卡车；
4. 农业动力：手工具 → 动力配套农具 → 通用拖拉机；
5. 发电配电：临时发电 → 标准机组 → 并联微电网；
6. 军事装备：遗产混装枪械 → 标准枪械 → 装甲汽车 → 轻型/中型/重型坦克产品族。

每条倒推都只建立玩家能感受到的里程碑，不把内部零件和型号展开成科技节点。
