# SPEC-M1-STAGE07-SALT-MINERAL-EVALUATION-FACT-AMENDMENT-001

## 结论

`RAW-IND-001-C` 保留并改名为“盐矿物评价”。确认氯化钠富集程度、区分其他盐类与标记污染超限样品，共同形成一项盐源评价能力，不按每种盐拆分。

- 前置：资源区划定；基础实验室运行
- 行动：盐矿物评价行动
- 标准：盐矿物分类与污染隔离标准
- 记录：盐样成分与污染记录
- 状态：盐源类别与污染状态
- 科研点：候选30点

科研不发现或开采盐矿，不产生盐样盐批次，不把所有盐视为氯化钠，不生产工业盐食用盐，也不作食用安全判定。污染状态不能因盐类身份确认而解除。

工业盐精制新增并保留本项依赖；基础建材、耐火材料、熔炼炉、浇注、玻璃原料和区域资源台账删除强制依赖。
