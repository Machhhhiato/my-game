# M1第四阶段砂石骨料生产科技事实修正

## 1. 尺度裁决

`RAW-QUA-001`保留为一项砂石骨料生产科技。露天开采、破碎、筛分和级配共同把原始岩石、砂与砾石转为道路、砌筑和混凝土可分别领用的骨料产品族；这些工序属于同一生产线。

## 2. 候选结构

- 候选名称：砂石骨料生产；
- 直接前置：`RAW-GEO-001-C`、`MCH-HND-001`；
- 工程：采石场开拓工程；
- 设施：采石场；
- 产品：分级砂石骨料；
- 标准：骨料级配标准。

本项让适合露天开采的岩石、砂和砾石按粒径与用途分成稳定批次，道路垫层、砌筑和混凝土用料不再混作一种石料。它不生产水泥或混凝土，不证明所有候选区都能安全连续开采，也不消除破碎筛分中的损耗。

## 3. 前置与解锁修正

正式树重复列出地质链三项前置，候选结构只保留末端资源区划，并增加早期开采工具前置。正式树还漏掉采石场开拓工程和骨料级配标准，候选结构补齐二者，并把产品名收束为分级砂石骨料。
