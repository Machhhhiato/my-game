# 边界

- 修复遗产机床提供首批加工能力；新造机床之间不互设知识前置。
- 滚动轴承生产依赖公差、热处理、质量检验与实际加工能力，但不机械绑定某一新机型号。
- 源合计165点，当前候选280点；后续重复轴承节点删除后再做全链净额结算。
