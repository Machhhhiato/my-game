# 方向六：采矿与基础原料

## 1. 方向结果

本方向把危险废墟拆取和零散采集推进为可测量、可分级、可持续开采并能向冶金、建材、化工和能源稳定供料的原料体系。

## 3. 产品家族

- 分级回收金属料；
- 可复用工程构件；
- 砂、砾石与分级骨料；
- 铁矿及其他金属矿精矿；
- 石灰石、黏土、盐和工业矿物；
- 固体燃料矿物；
- 尾料与待处理危险废物。

矿物按决定下游工艺的品位和用途分级，不为每个化验数值建立独立库存。

## 4. 维护与风险

- 原料产出依赖真实矿点、可达路线、岗位、工具/机械、能源和安全系统；
- 储量是估计值，会随勘探修正，不是无限资源标签；
- 边坡、支护、通风、排水和粉尘控制缺失会降低产量并造成实际事故；
- 尾矿、污水和危险废物必须有去向；
- 设备维护、刀具磨损和运输瓶颈会限制矿场持续产出。

## 5. 第 730 日验证

- 废料回收和至少一处原生资源点同时运行；
- 建材、冶金或化工至少两条下游能持续取得合格原料；
- 选矿批次有品位、损耗和尾料记录；
- 一次停采、排水或安全异常能够被处理并复产；
- 资源节点没有日期门。
