# M1 农业生产、初级加工与食品供应闭环

## 1. 第一规则：农业不是食品工厂，也不是一个“食物点”

农业必须沿真实链条运行：

```text
土地、水源与气候条件
  → 种源或繁殖群
  → 农业投入品、劳动力与设备
  → 作物或动物生长过程
  → 收获、挤奶、集蛋、起捕或出栏
  → 分级、干燥、屠宰、冷却和初级加工
  → 食品加工、仓储、运输
  → 人口消费、种源保留、饲料、贸易和储备
  → 废弃物、粪肥和副产物回到土壤、饲料、能源或处置链
```

- 农田、温室、禽舍、畜舍和养殖水体是生产设施，不占制造工厂容量。
- 食品加工厂只处理已经收获或取得的农产品，不能凭食品加工能力生成农产品。
- 科技只开放方法、生产单位、设施、产品、工程、法令或政策资格，不直接增加食物。
- 玩家管理生产类型、投入优先级、储备用途和跨地点配置，不管理每块田、每头牲畜或每次喂养。
- 两年是主线设计尺度和科研难度参考，不是科技日期门；真实前置满足时，任何后期农业科技都可提前研究。

## 2. 四层对象必须分开

| 对象 | 本系统含义 | 玩家主要操作 |
|---|---|---|
| 农业容量类别 | 可以承载相容生产线的土地、温室或养殖容量 | 建设、恢复、扩张、维护和分配投入 |
| 农业生产线 | 在一个生产周期内形成一种明确农产品 | 选择种植/养殖方向和优先级 |
| 农产品 | 可以入库、运输、加工、消费、留种或交易的明确物品 | 分配用途与库存下限 |
| 食品加工线 | 把一种或多种农产品转成一种明确食品 | 分配工厂容量与包装投入 |

同一地块可以轮作，但同一生产周期只有一个主产物生产线；副产物单独进入农业有机副产物库存。不同农场可以生产同一种产品，并在批次中保留产地、品种、日期、质量和污染风险，不为每个产地建立新产品 ID。

## 9. 五项常设法令与五项限期政策

### 9.1 常设法令

| 法令 ID | 完整法令 | 核心约束 |
|---|---|---|
| M1-AGR-LAW-001 | 农用土地、灌溉水与土壤保护法 | 农地用途、污染、侵蚀、灌排责任和恢复义务 |
| M1-AGR-LAW-002 | 种源、繁殖材料与种畜禽质量法 | 来源、检验、隔离、标记、销售/分发和灾备种源 |
| M1-AGR-LAW-003 | 肥料、植保剂、兽药与农业投入品安全法 | 合格批次、用量、人员防护、残留、停药期和废弃物 |
| M1-AGR-LAW-004 | 动物卫生、养殖、运输与屠宰法 | 疫病报告、隔离、福利底线、运输、屠宰和死亡处置 |
| M1-AGR-LAW-005 | 农产品批次、食品安全与召回法 | 产地、批次、检验、储运、加工、召回和责任追溯 |

现有`食品安全、储备与紧急配给法`继续约束营养底线、战略储备和紧急配给，不重复建立第二项同义法令。

### 9.2 限期政策

| 政策 ID | 完整政策 | 适用条件 | 代价与退出 |
|---|---|---|---|
| M1-AGR-POLICY-001 | 主粮与种源优先保障政策 | 主粮或下一季种源低于安全线 | 挤压油料、经济作物或当期消费；库存恢复后退出 |
| M1-AGR-POLICY-002 | 干旱期农业用水优先次序政策 | 灌溉水显著不足 | 与居民、工业和生态用水产生取舍；水情恢复后退出 |
| M1-AGR-POLICY-003 | 土地恢复与轮作休整政策 | 肥力、盐碱、侵蚀或病虫压力恶化 | 当期可播面积下降；土地指标恢复后退出 |
| M1-AGR-POLICY-004 | 种禽种畜与养殖群重建政策 | 疫病、战争或灾害导致繁殖群严重损失 | 增加饲料、检疫和进口/调拨压力；繁殖群恢复后退出 |
| M1-AGR-POLICY-005 | 应急设施农业与鲜食供应政策 | 露地减产或鲜食营养持续不足 | 增加能源、水、材料和维护负担；露地供应恢复后退出 |

政策不能无条件增加产量；它们只改变水、土地、种源、人员、能源、运输和库存的分配优先级。

## 10. 统一月结算

农业复用统一资源内核，不建立一套互不相干的农业专用货币：

```text
有效农业能力
= 可用生产容量
× 合格人员与组织效率
× 种源/繁殖群满足率
× 水、肥料或饲料满足率
× 农机与设施可用率
× 土壤/动物健康状态
× 地点可达性
× 当月生长、天气与生物阶段

实际入库
= 完成收获或取得的批次数量
× 收获与初加工效率
× 质量合格率
- 田间、加工、运输与仓储损耗
```

- 月结算记录投入、在产品、生长/繁殖进度、风险和损耗；只有完成收获、集蛋、挤奶、出栏或起捕才增加产品库存。
- 农业生物周期属于真实生产过程，不是科研日期门；本规格不提前填写各作物月数和各动物生长周期。
- 人口食品需求从真实人口按年龄、健康和劳动负荷派生，并统一换算为能量、蛋白质、脂肪和鲜食微量营养四类需求；具体产品批次提供这些营养，不把所有食物压成一个可互换数字。
- 食品首先从实物库存扣减，再形成营养满足、短缺和浪费结果；科技、状态和政策不能凭空补足缺口。
- 种源留用、人口消费、动物饲料、加工、贸易和储备是同一产品库存上的不同用途分配，合计不得超过可用库存。

## 11. 八项第2年农业状态

| 状态 ID | 完整状态 | 形成证据 | 失效表现 |
|---|---|---|---|
| M1-AGR-STATE-001 | 关键种源能够留种、复验和异地保存 | 种源批次、发芽率、繁育和异地备份连续成立 | 下一季只能消耗不可再生遗产库存 |
| M1-AGR-STATE-002 | 农地、水源与肥力维持可生产 | 土壤、水、轮作、肥料、侵蚀和污染记录成立 | 产量下降、盐碱/污染扩大或土地退出生产 |
| M1-AGR-STATE-003 | 主粮生产与储存链持续运行 | 谷物/块根从种源到收获、加工、入库完成闭环 | 只有采集、贸易或旧库存，没有可重复生产 |
| M1-AGR-STATE-004 | 蛋白、脂肪与鲜食来源具有替代性 | 豆类、油料、蔬菜、蛋禽畜或水产至少形成互补来源 | 热量尚足但蛋白、脂肪或微量营养持续不足 |
| M1-AGR-STATE-005 | 动物养殖与疫病风险受到控制 | 繁殖群、饲料、兽医、隔离、死亡和出栏记录成立 | 疫病、异常死亡或繁殖群崩溃未被发现和处置 |
| M1-AGR-STATE-006 | 收获后损耗与冷链风险可见且受控 | 称重、分级、干燥、温度、虫害和报废记录成立 | 名义产量很高但可消费库存持续偏低 |
| M1-AGR-STATE-007 | 农产品到食品批次可以追溯和召回 | 产地、投入、检验、加工、仓储和去向相互关联 | 污染或疫病发生后无法确定影响范围 |
| M1-AGR-STATE-008 | 食品储备能够轮换并承受局部中断 | 库存下限、期限、异地储备、运输和调拨记录成立 | 储备腐败、单点中断或临时减产立即造成断供 |

`食品安全`不等于100%自给。国内农业、贸易、援助和旧库存都可参与供应，但种源、主粮应急能力、批次追溯和最低储备不能完全依赖一个不可控外部来源。

## 12. 第2年最低存在事实

普通第2年终点至少应具有：

1. 谷物或块根中至少一种稳定主粮生产线；
2. 蔬菜以及豆类、油料、蛋禽畜或水产中的互补营养来源；
3. 关键种源经过一次完整的播种、收获、留种和复验闭环；
4. 正式农田、灌排、种源库、农产品收集分级、干燥储粮和投入品管理设施；
5. 与人口规模相匹配的农机作业、维修、运输和仓储能力；
6. 若存在规模养殖，则必须同时存在繁殖群、饲料、检疫、兽医、死亡处置和合格屠宰/乳品处理；
7. 十三项食品与饲料加工产品中，实际采用的路线均有独立生产线、投入、批次和库存；
8. 五项农业法令已颁布并有执行记录，限期政策能够启动和退出；
9. 八项状态由真实实体、人员、产品与记录形成；
10. 至少完成一次从人口需求、生产、加工、运输、储存到消费/储备的月结算核对。

本轮只固定终点结构，不确定各作物面积、单产、养殖数量、农机数量、设施数量、建设月份和食品自给率。

## 13. 对现有 R4 与工厂目录的修正要求

1. `谷物`、`蔬果`不得继续作为`记录`类型，必须替换为本规格的明确农产品。
2. `试验苗圃`不得作为记录，必须是设施或生产容量对象。
3. `农业拖拉机及通用农具平台`不得作为记录，必须形成具体农业装备产品、作业能力和维护关系。
4. `蛋白食品初级加工线`不得作为产品；生产线与禽畜胴体、水产品、食用豆类、冷却肉类和罐藏蛋白食品分别登记。
5. `保存食品产品`不得作为万能产品；发酵、腌制、罐藏、低温和本规格列出的具体食品分别登记。
6. 原规格10个总结科技节点继续只作为来源导航，不得出现在实际科技树；R4 的32项原子节点与本规格19项新增节点共同作为展示与数据对象。

## 14. 下一步边界

方向通过后依次执行：

1. 把19项新科技、多个独立解锁对象和真实前置加入 R5 完整科技树；
2. 用20项农产品和13项食品/饲料产品修订工厂、库存与终点关系表；
3. 再依据约8万、10万和15万人口情景反推土地、劳动力、水、农机、仓储、养殖和贸易缺口；
4. 最后为科技赋科研点，为生产能力赋月份、数量、损耗与维护数值。

本规格不修改游戏产品代码、数据、测试或构建，不提交、不推送，不进入 `M0-L4-403`。
