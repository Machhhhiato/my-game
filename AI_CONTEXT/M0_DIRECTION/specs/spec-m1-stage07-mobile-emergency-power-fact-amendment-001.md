# SPEC-M1-STAGE07-MOBILE-EMERGENCY-POWER-FACT-AMENDMENT-001

## 结论

`ENE-EMG-001` 保留并改名为“移动应急供电”。移动机组、固定快速接入口和关键负载恢复共同形成一个完整应急供电里程碑，不拆分。

- 前置：`ENE-GEN-001` 内燃机组定型
- 产品：`YD-A1`型移动应急发电机组，基于`QF-A1`标准小型机组平台
- 工程：应急电源快速接入工程
- 标准：移动应急供电接入与恢复标准
- 行动：应急供电行动

移动底盘、电缆连接器、接地和保护、燃料启动、关键负载资料、停放运输与人员均为实体条件。科研不自动生产机组、建设接口或恢复供电；技术接入不能决定政策优先级，也不能突破额定容量或保护条件。

删除发电机组修复的重复直连和站级蓄电储能的无关依赖。中型机组保持独立产品路线。
