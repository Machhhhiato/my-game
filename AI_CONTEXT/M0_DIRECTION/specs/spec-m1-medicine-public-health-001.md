# 方向十四：医疗、药品与公共卫生

## 1. 方向结果

本方向把应急救护和遗产药品使用推进为具有分诊、诊断、手术、感染控制、药品制备、康复、孕产照护和多节点转诊的公共医疗体系。

## 3. 产品聚合

- 急救与后送装备；
- 清洁消毒与个人防护耗材；
- 基础检验试剂和采样耗材；
- 手术器械、敷料和无菌包；
- 基础药品产品族；
- 康复辅助器具；
- 孕产与新生儿照护装备。

药品必须按有效成分、剂量、用途和批次区分；不把所有医疗物资压成一个抽象资源。

## 4. 维护与风险

- 医疗服务依赖岗位、洁净水、能源、耗材、药品和设备校准；
- 过期、污染或来源不明药品不能因库存数字存在而安全使用；
- 治疗结果可以是康复、长期受限或死亡，不保证正向结局；
- 疫情措施改变人口流动、岗位和公共服务，不能只改一个感染率；
- 医疗设备停机或缺耗材时按实际能力降级。

## 5. 第 730 日验证

- 多地点伤病能够分诊、后送、诊断、治疗和随访；
- 基础药品与耗材至少一部分本地复产，仍可对外部依赖做账；
- 产育服务与自然人口模型真实接通；
- 一次感染风险得到检测、追踪和处置；
- 高级医疗不受日期门控制。
