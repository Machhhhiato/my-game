# 聚居点、住房、公共工程与消防闭环

## 1. 对象边界

土地与建筑容量、具体工程、建材产品、公共设施、住房服务和聚居点状态分别登记。人口不能因“住房科技”完成自动获得住处；建筑必须有地块、设计、材料、施工、验收、供水排污、能源、消防和维护。

## 4. 法令、政策、状态与结算

| 类型 | ID 范围 | 独立对象 |
|---|---|---|
| 法令 5项 | M1-SET-LAW-001—005 | 土地用途与公共通道；建筑设计施工验收；住房最低卫生安全；消防疏散；危房拆除与建筑废物 |
| 政策 5项 | M1-SET-POLICY-001—005 | 紧急安置；住房修复优先；拥挤缓解；消防整治；灾后重建，均有范围、资源代价和退出 |
| 状态 8项 | M1-SET-STATE-001—008 | 居民有可用住处；住房卫生安全；公共服务可达；道路排水连续；消防覆盖；夜间公共空间可用；危房受控；扩建不破坏工业农业与环境容量 |

`可服务人口 = min(住房容量, 供水排污容量, 能源容量, 道路消防容量, 公共服务容量) × 设施状态`。人口增长、流民和兼并人口进入同一住房需求账；没有实际住房不得用“安置完成”状态消除拥挤。

第2年至少具备正式住宅、临时安置、道路排水、消防、公共照明、学校/医疗/行政基本设施、维修和危房处理。本轮不填建筑数量、面积、密度、工期和人均住房。

旧类型修正：学校、诊疗点、照护点、公共登记点是设施；消防间隔和公共通道是规划规则/地点关系；昼夜运行是组织规程；住房容量与生活质量是状态，不是产品。
