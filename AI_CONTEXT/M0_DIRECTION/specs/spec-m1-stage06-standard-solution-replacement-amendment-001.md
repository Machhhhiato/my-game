# SPEC-M1-STAGE06-STANDARD-SOLUTION-REPLACEMENT-AMENDMENT-001

## 结论

`CHM-ACD-001-D` 删除“通用工业试剂制备”汇总身份，复用稳定ID建立“标准溶液配制”。本项只把仓库中已有且身份明确的化学品配成浓度可核验的小批工作溶液，不合成任何缺失试剂。

- 前置：化学品安全鉴别；技术文件规范
- 行动：标准溶液配制行动
- 标准：标准溶液浓度与标识规则
- 记录：标准溶液配制记录
- 行动实际产出：标准溶液批次
- 科研点：候选35点；原90点剩余部分进入整树重估池

原料身份和纯度限制、危险属性、量具误差与稳定性均会传递到实际批次；稀释或混合不会提高纯度。科研不自动生成溶液，也不代替任何具体化学品生产路线。

`MAT-REA-001`后续改为试剂级纯度、相容包装、稳定性验证和正式批次放行，并将“试剂级”作为具体化学品批次状态；它承接本项、量具校准和批次检验，不再重复生成抽象“通用试剂”。
