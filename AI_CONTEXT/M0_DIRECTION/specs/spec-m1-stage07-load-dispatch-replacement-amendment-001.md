# SPEC-M1-STAGE07-LOAD-DISPATCH-REPLACEMENT-AMENDMENT-001

## 结论

`NRG-DSP-001`删除燃料调度与应急储备身份，收窄为“电力负载调度”。本项只依据实际计量和已经登记的优先序执行负载切除与恢复，不制定负载优先级。

- 前置：低压配电设计
- 组织：电力负载调度
- 行动：负载切除与恢复行动
- 标准：负载切除与恢复规程
- 记录：电力负载调度记录
- 状态：负载供电状态
- 科研点：候选40点；原55点剩余15点进入整树重估池

实际电源、可控回路、计量、玩家或法律政策登记的优先序、保护、通信和值班均为实体条件；储能或备用电源可选。科技不管理燃料库存、不生产电力、不建设电源或储能，也不保证缺口消失。

删除三项可再生站址评估和节点储能强制前置。远程计量后继保留；区域燃料供应节点的依赖与身份留待其单项审查。原第二行因补造治理事实并越过政策边界而删除。
