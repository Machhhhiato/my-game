# 战前巨企文明、巨企战争与新生人格底线

## 1. 本次补充解决什么问题

既有世界已经确定气候失控、工程病原体“锈斑瘟疫”和轨道动能轰炸共同造成文明崩溃，但尚未明确是谁把这些能力推向失控，也没有给旧时代考古科技提供统一的社会背景。

本规格补上政治与产业原因：战争前的世界已经进入赛博朋克式巨企文明。巨企不只经营商品，还控制劳动身份、医疗、住房、数据、义体、人格副本和离开工作区所需的交通。公共政府仍然存在，但大量国家已成为巨企的客户、担保人、代理战场或失去执行能力的名义机构。

这不是把三重灾难替换成“巨企战争”，而是建立同一条因果链：巨企战争是历史原因，气候失控、工程病原体和轨道动能轰炸是它最终采用的毁灭手段。

## 2. 巨企战争怎样走到文明毁灭

巨企掌握跨地区的资源、技术、基础设施和武装力量，国家与公共机构已经无力稳定约束它们。巨企战争也不是一次突然爆发的总决战，而是商业竞争、产业封锁和代理冲突不断越过公共边界，最后升级为全面战争：

1. 对资源、市场和关键技术的争夺先破坏全球合作与公共治理。
2. 气候工程和资源开发被用于打击竞争地区，最终推动气候失控。
3. 工程病原体被投入战争和封锁，最终产生并扩散“锈斑瘟疫”。
4. 轨道基础设施军事化，轨道动能轰炸摧毁城市和工业网络。
5. 各方都以为毁灭对手就能保住自身，最后却共同摧毁了现代文明赖以存在的环境与生产体系。

暂不锁定具体巨企名称、战争次数、精确年代和每一场战役。这些内容必须在后续势力史或事件设计中单独确认，不能由科技正文临时补造。

## 3. 旧世界最重要的基础对照

旧世界不是因为技术落后而毁灭。恰恰相反，它拥有远超新生避难所的技术，却在长期巨企统治中把人的价值压缩成成本、权限、合同和可替换资产。

巨企的无人性不是某一台设备如何工作，也不是每项科技都自带邪恶用途，而是社会已经接受一个前提：只要生产仍在继续，人的记忆、身体、寿命、身份和退出权都可以被拿来优化。

记忆清除只是这个基础设定下的一种典型可能。它真正可怕的地方，不需要由临时补造的清除方法、克隆流程或人格设备解释，而在于巨企能够借此阻止劳动者保留经历、形成连续人生并抵达承诺兑现的那一天。技术细节只有在未来拥有独立科技设定和考古证据时才补充，本规格不预先确定。

主题对照由此成立：

- 旧世界拥有更高的生产力，却越来越不承认人是目的。
- 新生避难所拥有极低的生产力，却从一开始承认人不是耗材。
- 玩家恢复的是旧世界的能力，同时不断决定哪些旧世界的关系绝不能一同恢复。

## 4. 黑色幽默应从什么角度出发

黑色幽默不从“技术怎样伤害人”的说明出发，而从“如此巨大的伤害为什么已经成为一件正常工作”出发。

正确取材角度是：

- 技术使一种原本难以长期维持的非人待遇变得稳定、便宜和可重复。
- 巨企由此持续获利，受害者失去的不是一次记忆，而是连续人生、退出能力和抵达未来的机会。
- 人事、工资、保险、运输、培训、维修等普通岗位仍按章工作；文案只露出其中一个平静、合理、甚至服务周到的侧面。
- 残酷感来自巨大的人类代价与日常程序之间的落差，不来自作者直接说“巨企很邪恶”，也不来自补写血腥技术细节。

以记忆清除为例，法院保管期限只说明记忆被处置过，后果仍停留在一次案件。巨企劳动制度则可以让一个人永远无法积累工龄、确认自己已经工作多久、等到返乡或意识到承诺从未准备兑现。黑色幽默应观察这套制度留下的人事、退休、返乡或新人培训事实，而不是解释记忆到底怎样被清除。

科技正文只说明已经确定的中性能力。考古发现负责证明旧世界确实存在相应用途。黑色幽默侧面只露出一个正常运转的旧世界事实，让玩家自行意识到：系统没有出错，正是系统从头到尾都把人当成了东西。

## 5. 新生避难所为什么是“当人的”

新生政权不是资源充足的乌托邦，也不会自动消灭配给、紧急征用、危险劳动和政治冲突。但它必须从建立之初保留一条不可交换的人格底线：

1. 任何具有自我意识的人格，不论原生、克隆、复制、恢复或运行在何种身体中，都先被视为人，而不是设备实例或合同附件。
2. 身体、记忆和人格不能成为雇主所有的生产资产；医疗性记忆干预必须有真实同意、明确目的和可追溯记录。
3. 劳动合同必须存在真实的到期、退出与结算；不得通过技术干预消除工龄、债权、伤害与责任。
4. 人格副本不能因为另一个版本仍然存在就被当作冗余文件处置；其权利冲突必须由新社会公开解决。
5. 生存危机可以迫使社会做出残酷选择，但不能先把一部分人改称为资产、耗材或未达到人格标准的工具，再让选择看起来容易。

旧世界的核心问题不是科技太先进，而是技术、资本和身份制度共同取消了人说“不”和真正离开的能力。新生避难所的区别也不在于拒绝所有旧技术，而在于恢复技术时拒绝恢复这套人身所有权。

## 6. 与既有硬设定的关系

- 保留`LORE.md`既有三重毁灭机制，不在本任务直接改写产品世界文件。
- 本规格提供三重毁灭背后的社会和战争因果，后续由职责正确的世界设定任务决定怎样写回`LORE.md`。
- 保留玩家从28人避难所小群体起步、依靠考古恢复技术和吸纳人口的现有方向。
- 后续科技、工程和事件可以通过巨企遗址逐步发现旧世界，而不是在开场说明中一次性讲完全部背景。
- 新社会仍需面对劳动、资源、居住、合同和权力冲突；“当人”是制度底线，不是对现实矛盾的删除。

## 7. 当前冻结与未冻结

已冻结的核心方向：

- 战前世界具有赛博朋克式巨企社会结构。
- 巨企战争是三重灾难走向文明毁灭的政治与产业原因。
- 巨企曾利用人的记忆、身份与退出权维持无法自然结束的剥削关系；具体技术机制尚未冻结。
- 新生避难所恢复旧技术，但拒绝把人、身体、记忆和人格副本视作可重置生产耗材。

仍待后续单独设计：

- 巨企名称、标识、产业领域和相互关系。
- 巨企战争的具体阶段、年代、地区和关键事件。
- 记忆重置劳动设施的确切地点、人物与可玩事件。
- 新生社会处理人格副本、医疗记忆干预和紧急状态的具体法律选项。
