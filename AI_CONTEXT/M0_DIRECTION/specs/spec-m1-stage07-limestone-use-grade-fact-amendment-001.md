# SPEC-M1-STAGE07-LIMESTONE-USE-GRADE-FACT-AMENDMENT-001

## 结论

`RAW-IND-001-A` 保留并改名为“石灰石用途分级”。成分、杂质与物理性质共同决定石灰石可进入的候选用途，是一项可复用的工业矿物评价能力，不按用途拆分。

- 前置：资源区划定；基础实验室运行
- 行动：石灰石用途评价行动
- 标准：石灰石用途分级标准
- 记录：石灰石成分与物性记录
- 状态：石灰石用途等级
- 科研点：候选30点

科研不发现矿区，不产生样品、矿石或合格批次，也不证明储量和可采性，不负责破碎、煅烧、玻璃熔制或建材生产。

基础建材和玻璃原料分级保留依赖；耐火材料只在特定路线读取实际输入，熔炼炉、浇注、区域资源台账和建筑骨料删除强制依赖。
