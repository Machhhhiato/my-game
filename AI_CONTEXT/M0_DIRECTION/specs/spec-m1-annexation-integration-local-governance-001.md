# 方向二十一：兼并、统合与地方治理

## 1. 方向结果

本方向把一次政治或军事控制推进为人口、地点、设施、库存、权利、公共服务、预算和中央权限真实接入的统合过程。

## 3. 边界

- 地方只有有限执行自治，没有独立外交、军队、货币、战略资源或退出权；
- 统合不会把人口瞬移到总部，也不会立刻清除制度与文化差异；
- 战后接管需要额外安保、救援、登记和修复成本；
- 进度取决于实际人员、服务、路线、关系和履约，不是固定日期；
- 失败可以形成抵触、空账、服务断裂或冲突，但不能凭空生成叛乱。
