# 外交、兼并、地方统合与政治合法性闭环

## 1. 对象边界

本系统不生产“外交点”。形成8类能力：安全接触、常设联络、情报档案、互助救援、贸易通行、争端调停、保护/从属关系、主权兼并与地方统合。

独立外交治理对象14项：势力档案、接触事件、外交代表、联络渠道、谈判议程、协议文本、互助义务、通行权、护运责任、保护关系、停火边界、主权移交书、地方权限表、统合计划。均保存对象、范围、期限、义务、履行和争议，不把关系值代替条约事实。

设施10类：外事联络处、接触隔离点、外交接待处、翻译档案室、边境/路线交接站、协议登记处、联合协调中心、地方接管办、申诉复核处、政治与公共意见调查站。组织5种：中央外交、外部情报档案、条约履约、地方接管统合、申诉监督与合法性评估。

## 3. 制度、状态与结算

法令5项：外交代表条约登记、边境通行、战争停火保护关系、主权接管地方权限、地方申诉监督。政策5项：紧急互助、外交接触强化、停火观察、地方过渡接管、统合服务加速。状态8项：势力事实可信、联络连续、协议可履约、边境通行可控、争端可处理、接管资产人口可核对、地方服务权利接入、中央合法性有证据。

关系结果从协议履行、贸易援助、伤亡损害、权利服务、地方负担和用权记录派生，不靠一次选择永久加减。兼并人口、资产、军警、财政、债务和公共服务必须分别并表；地方没有独立外交、军队、货币、战略资源或退出权。

第2年至少具备安全接触、常设联络、协议登记、互助/贸易通行、争端处理、主权接管和地方申诉接口。本轮不填关系值、谈判概率、统合月数、抵抗率和外交行动点。

旧类型修正：势力关系不是产品，协议不是状态，保护关系不是一句文本，地方统合不能由科技直接完成，合法性不是单一宣传值。
