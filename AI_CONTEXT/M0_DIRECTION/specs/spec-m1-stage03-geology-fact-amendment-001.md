# M1第三阶段地质勘察科技事实修正

## 1. 原问题

R6让`RAW-GEO-001-A/B/C`同时依赖地表危险勘察和居住边界划定，并重复解锁“矿点候选”。居住边界不是资源踏勘的技术前置；地质踏勘、露头编录和资源区划也不应在同一时间产生同一个结论。

## 2. 临时递进结构

### `RAW-GEO-001-A`

- 候选名称：地质踏勘；
- 直接前置：`SET-SUR-001-A`；
- 行动：地质踏勘行动；
- 记录：地质踏勘记录；
- 记录：地质异常点。

本项只识别岩性变化、矿化迹象、地形与地下水等值得继续核查的异常，不形成可开发矿点或储量结论。

### `RAW-GEO-001-B`

- 候选名称：露头编录；
- 直接前置：`RAW-GEO-001-A`；
- 记录：露头编录；
- 记录：岩性与矿化线索。

本项把可见岩层、结构、风化和矿化迹象按同一规则记录，使不同地点的露头可以比较；不划定资源区。

### `RAW-GEO-001-C`

- 候选名称：资源区划定；
- 直接前置：`RAW-GEO-001-B`；
- 行动：资源候选区划定行动；
- 记录：资源候选区划定记录；
- 记录：资源候选区。

本项综合踏勘与露头线索，圈定值得钻探、采样或进一步验证的候选范围；不证明储量、品位或可采性。

## 3. 终局裁决

整树复审必须比较：保留三项递进科技；合并地质踏勘与露头编录、保留资源区划定；或把露头编录下沉为地质踏勘的记录标准。若玩家在A与B之间没有独立决策或里程碑，裁决`MERGE`或`DEMOTE`。

## 4. 废墟材料回收的前置修正

`RAW-SCR-001`保留为独立的废料分级回收科技。它把废墟中可回收的金属、建材、电气材料和化学材料按材质、用途与危险性分流，并把危险废料留在隔离边界内；它不完成后续加工、精炼或再制造。

- 候选名称：废料分级回收；
- 直接前置：`SET-SUR-001-A`；
- 设施：分级回收场；
- 产品：废料批次；
- 工程：危险废料隔离工程。

居住边界划定不构成材料辨识与危险隔离的技术前置，因此移除`SET-SUR-001-B`。后续整树复审仍须核对它与退役设备回收的边界，但前者处理废墟混合材料，后者处理已知设备资产，当前不标记重复。
