# M1第四阶段基础实验室运行科技事实修正

## 1. 尺度裁决

`SCI-LAB-001`保留为一项基础实验室运行科技。实验项目、样品编号、条件记录、失败保留和重复验证共同把零散试验变为可以由他人复现的正式研究；它与化学品安全鉴别的专用实验室边界不同。

## 2. 候选结构

- 候选名称：基础实验室运行；
- 直接前置：`QLT-UNI-001`、`SCI-ARC-001`；
- 设施：基础研究实验室；
- 记录：正式实验项目；
- 标准：实验记录与样品编号；
- 行动：重复验证行动；
- 记录：重复验证记录。

本项让实验条件、样品、失败和重复结果留在同一项目中，另一组人员可以按记录复验并比较结果。它不保证第一次结论正确，不替代专用实验设备，也不把文献记载直接当作本地实验结果。

## 3. 解锁修正

正式树只登记正式实验项目，遗漏运行科技直接建立的实验室设施、记录标准与重复验证行动。候选结构补齐四项，并保持与遗产档案管理、技术文件规范的前置关系。
