# 方向十九：外交与势力关系

## 1. 方向结果

本方向把偶然接触推进为具有代表身份、情报可信度、承诺、义务、争端和可追溯执行结果的外交关系。外交不会只改变友好度数字。

## 3. 边界

- 每个外部势力必须是真实地图实体；流民批次除外；
- 关系来自行为、履约、损失、宣传和内部意见，不是单一好感度；
- 军力改变谈判条件但不自动使对方服从；
- 协议只有在人员、货物、路线、驻防、信息或义务实际改变后才算生效；
- 外交科技没有日期门。
