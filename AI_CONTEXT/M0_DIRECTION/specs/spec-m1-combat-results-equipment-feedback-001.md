# 方向三十一：作战结果与装备反馈

## 1. 方向结果

本方向让战斗、护运、警戒和演习产生可追溯结果，使型号、战术和编制改进来自真实表现，而不是科技卡直接比较数值。

## 2. 科技节点

| 稳定 ID | 完整结构名称 | 直接前置 | 明确结果 |
|---|---|---|---|
| `CBT-LOG-001` | 接敌时间线、命令与位置记录 | `MIL-ORG-003`,`ELC-REC-001` | 可复盘的行动时间线 |
| `CBT-EQP-001` | 装备故障、弹药与燃料消耗记录 | `CBT-LOG-001`,`QLT-TRC-001` | 按型号统计真实可用率与消耗 |
| `CBT-CAS-001` | 伤亡、救治、失联与人员恢复记录 | `CBT-LOG-001`,`MED-TRI-001` | 人员损失进入人口与部队账 |
| `CBT-TAC-001` | 战术进入、退出与失败条件复盘 | `CBT-LOG-001`,`MIL-TACTIC-001` | 区分战术、训练、地形和指挥问题 |
| `CBT-LOGI-001` | 补给中断、维修延迟与掉队分析 | `CBT-EQP-001`,`LOG-SEC-001` | 区分装备性能与保障失败 |
| `CBT-AAR-001` | 战后报告、证据可信度与改进建议 | `CBT-CAS-001`,`CBT-TAC-001`,`CBT-LOGI-001` | 形成编制、战术、训练或型号研究候选 |
| `CBT-VAL-001` | 演习复验与改进效果确认 | `CBT-AAR-001`,`MOD-TST-001` | 新方案必须在演习/实战中验证变化 |

## 3. 玩家反馈

报告陈述交战距离、压制、突破、命中承受、故障、掉队、损失、弹药/燃料消耗、维修和补给连续性。只有缴获、拆解、试用或长期交战形成足够情报后，才提高对外部型号的认识；不显示全知敌我对照表。
