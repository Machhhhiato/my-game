# M1 现代集团军装备产品与部队类型完整目录

## 1. 本目录解决什么问题

当前完整科技树已经有枪械、弹药、班组自动武器、迫击炮、野战火炮、反装甲武器、低空防御武器、军用车辆和轻中重型坦克等19个正式装备型号，但第2年工厂目录只接入了枪械、弹药和工兵套装，不能支持一支合成军队的装备检查。

本目录回答两个问题：

1. 一个现代集团军为了战斗、机动、侦察、指挥、补给、救治和持续作战，需要哪些玩家可生产产品；
2. 这些产品分别组成哪些部队类型，缺少哪一类装备时，哪种部队不能成立或只能降级运行。

现代集团军在这里是**装备与编制完整性上限**，不是第2年必须实际组建的部队规模。当前标准人口提案约十万人、现役约一千五百人，只足以校准若干营连级基础部队；真实集团军需要后续人口、军官、训练、装备、燃料、运输和保障共同扩张。

时间仍不是解锁门。真实前置提前满足时，长期装备可以提前研究、定型和生产。

## 2. 军事产品尺度

- 枪械、班组自动武器、迫击炮、火炮、反装甲武器、防空系统、车辆、坦克、雷达、无人机和直升机是具有独立战术作用与里程碑的产品，分别生产和库存。
- 钢盔、防弹防护、负载携行和个人野外用品合成`单兵防护与负载携行套装`，不拆成十余条生产线。
- 工兵手工具、检测器材和常用作业附件合成工兵装备套装；但装甲工程车、野战桥梁装备和障碍开辟装备会改变部队任务范围，继续独立。
- 枪械弹药、迫击炮弹药、炮兵弹药、火箭炮弹药、坦克弹药、反装甲制导弹药和防空制导弹药分别库存，因为它们服务不同武器体系，短缺后果不能互相替代。
- 一种装备型号不永久独占一座物理工厂；它占用相容的军事、车辆、电气、机械、民用或医疗工厂生产线。相容厂址可以并行装线或换线。
- 科研只开放设计和生产资格；真实装备必须试制、定型、建线、生产、检验和入库。

这些是可用于编成营、团、旅、师或集团军直属单位的**部队类型**，不是十五支自动生成的实体部队。

## 4. 五十一项军事生产产品

`两年基础`表示普通第2年终点应具备或明确补齐的基础生产能力；`条件路线`表示前置满足即可提前出现，但不强制普通路线实现；`现代完整线`是现代集团军完整性目录，不设日期门。

本节固定产品身份、用途和拟真代号结构。R4 已有19项名称继续沿用现有候选；其余新名称是第一层拟真代号草案，用于避免`步兵装备二`之类空名，不自动冻结为最终玩家文字。第三层正式命名和用户逐字接受后，才能成为最终显示字符串；稳定产品 ID 不随改名变化。

## 6. 生产分类关系

军事产品不全部由`军事工厂`制造：

| 工厂类别 | 主要军事产品 |
|---|---|
| 军事工厂 | 枪械、自动武器、迫击炮、火炮、反装甲、防空武器及各类弹药 |
| 车辆厂 | 军用摩托车、卡车、装甲车辆、坦克、抢修车、工程车和救护车 |
| 电气仪表通信设备厂 | 电台、指挥所设备、观察设备、无人机、雷达、电子战与移动电源 |
| 机械制造厂 | 火炮结构、工兵装备、桥梁道路装备、维修装备和军需保障设备 |
| 民用工厂 | 单兵防护携行、野战军需包装、帐篷与生活保障内部件 |
| 医疗工业厂 | 野战医疗、无菌耗材、呼吸支持和救护车医疗模块 |
| 航空工业长期类别 | 直升机、航空发动机、旋翼传动、飞控与航空专用维护设备 |

同一最终产品可以要求多个工厂类别提供部件，但只能有一个最终装配生产线和一个产品库存 ID。例如步兵战车由车辆厂总装，军事工厂提供武器模块，电气工厂提供通信与观瞄；玩家库存仍只有具体步兵战车型号。

## 7. 部队组建门

任一部队类型都必须同时满足：

1. 已采用对应编制；
2. 有真实人员、军官和专业岗位；
3. 主装备、弹药、通信、医疗、运输和维修达到编制最低比例；
4. 有训练场、教官、训练记录和协同检验；
5. 有驻地、仓储、燃料、弹药库和补给来源；
6. 有该装备对应的维护、抢修和报废去向；
7. 形成后生成实体部队，而不是只增加一个“已解锁兵种”。

集团军实体还必须拥有能够指挥多个下级部队的参谋机构、通信骨干、军需运输、维修救援、卫生后送和预备队。只有坦克和步兵数量达到标准，不能自动命名为集团军。

## 8. 对当前科技树的修订结论

### 8.1 已有产品继续保留

R4 中 `MIL-EQP-001` 至 `MIL-EQP-019` 的19个正式装备型号继续作为产品来源，其中只有枪械、弹药和工兵套装已进入当前408项两年主线终点；其余已有产品需要按基础、条件或现代完整线重新接回工厂与部队类型。

### 8.2 必须新增或明确拆出的产品

当前至少缺少：精确射手武器、重型迫击炮、自行火炮、多管火箭炮、各武器体系独立弹药、反装甲制导武器、机动近程防空、装甲输送车、步兵战车、装甲工程车、野战救护车、指挥所设备、两级侦察无人机、地面监视雷达、电子战设备、三类保障装备和两类直升机。

这些缺口必须逐项建立科技、设计、试制、定型、工程、生产和维护关系；不得只在部队装备表里凭空引用产品名称。
