# 方向二十八：装备型号、改型与换代

## 1. 统一型号制度

每个装备家族独立使用`类别代号—主序号`；首个正式投产型号为`—01`。不改变代际的重大修订增加中文改型后缀；形成里程碑跨越时进入`—02`。代号始终与完整产品类型并列。

```text
试制样品（不进入正式库存）
  → 首投型号：类别—01
    → 同代改型：类别—01甲 / 类别—01乙
      → 下一代型号：类别—02
```

年份只有在世界内真实定型年份存在时才可加入，不作为日期门。

## 2. 改型科技节点

| 稳定 ID | 完整结构名称 | 直接前置 | 明确结果 |
|---|---|---|---|
| `MOD-FDB-001` | 生产、训练与实战使用反馈归档 | `QLT-TRC-001`,`SCI-REV-001` | 按型号汇总故障、损耗、维护与任务结果 |
| `MOD-ANA-001` | 故障根因、使用错误与设计缺陷区分 | `MOD-FDB-001`,`RPR-DIA-001` | 确认问题属于生产、训练、补给、维护或设计 |
| `MOD-TST-001` | 对照样机、极限工况与寿命验证 | `MOD-ANA-001`,`QLT-SMP-001` | 形成可比较的同任务试验结果 |
| `MOD-CHG-001` | 工程变更、受影响范围与重新定型 | `MOD-TST-001`,`QLT-CHG-001` | 决定小修订、同代改型或跨代换型 |
| `MOD-LIN-001` | 生产线改装、工装更换与熟练度迁移 | `MOD-CHG-001`,`MCH-JIG-001` | 新型号可实际生产并记录换线损失 |
| `MOD-FLD-001` | 分批换装、训练转换与新旧库存并存 | `MOD-LIN-001`,`MIL-ORG-004` | 部队按实际库存换装，不自动全军升级 |
| `MOD-RTR-001` | 旧型号改装、降级使用与后备转用 | `MOD-FLD-001`,`RPR-REM-001` | 旧装备可改装、转守备、拆件或封存 |
| `MOD-RCY-001` | 退役拆解、材料回收与危险品处置 | `MOD-RTR-001`,`RAW-SCR-001` | 退役装备转为可追溯材料与废物批次 |
