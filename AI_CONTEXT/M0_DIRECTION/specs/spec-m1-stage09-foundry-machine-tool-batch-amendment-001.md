## 3. 明确边界

- `MAT-ALU-001`保留再生铝精炼身份；后续重复的`MET-NFR-001-B`合并删除并改接有效下游。
- `MAT-PLT-001`不再独立存在；厚度、板形、平直度、表面质量和检验并入标准板材生产。
- `MCH-LAT-001`有意聚合车削、铣削、钻削和磨削四类基础能力，但只开放一个工场类型，不产生固定数量设施。
- `MET-FUR-001-A`只覆盖耐火黏土路线，不新增硅质耐材评价，也不代表全部特种耐材已经恢复。
- `MET-FUR-001-B`只覆盖普通小规模铸铁与常用有色金属炉型；炼钢、高温合金和专用气氛炉另需对应技术。
- `MET-FUR-001-C`只开放浇注放行、停浇、标准、记录与状态，删除“浇注安全”伪产品。

## 4. 型号与产品

- `ADC12`再生铝合金锭：成分、含气与夹渣范围合格后由实际精炼与铸锭行动生产；它只代表压铸用再生铝合金，不是万能铝材。
- `N-3`牌黏土耐火砖、`NN-30`牌耐火泥：分别承担普通小型炉的主体炉衬与砖缝局部封补。
- `XR-A1`型小型熔炼炉：科研开放图纸、工程和设施类型，工程完成后才形成实例。

## 5. 后续改接

- 删除`MAT-ALU-001 → MAT-ACD-001`和`MAT-PLT-001 → MAT-FRG-001`无因果边。
- 铸造节点按真实需要承接炉型、浇注安全、模具和质量控制，不再把三项共同前置误作三条铸造线。
- 产品设计只有在需要机加工知识时才保留`MCH-LAT-001`科技前置；一般生产读取实际工场能力。
