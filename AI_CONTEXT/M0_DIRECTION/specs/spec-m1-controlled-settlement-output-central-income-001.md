# 方向二十二：受控聚居点产出与中央收入

## 1. 方向结果

本方向把“殖民地提供固定收益”改为可核查的地方生产、当地优先需求、合同/税费、运输损耗、驻防与行政成本以及中央实际入库。

## 3. 结算公式

```text
地方总产出
- 当地人口正常需求
- 当地设施维护与复产
- 合同约定的地方公共服务
= 可支配余量

中央实际收入
= 合同 / 税费 / 上缴批次
- 装卸、运输与途中损耗
- 驻防、行政、基础设施和救援成本
```

## 4. 边界

- 任何收入都对应具体产品、服务或结算凭证；
- 地方缺口不会被固定收益隐藏；
- 中央可以过度提取，但后果通过人口、维护、产能、抵触和治理事实出现；
- 地方产出和中央入库分开记录；
- 无日期门。
