# M1第三阶段蒸汽热网循环科技事实修正

## 1. 尺度裁决

`ENE-STM-001`保留为一项蒸汽热网循环科技。蒸汽输送、用户换热、凝结水回收和热网平衡共同形成一套闭合的工业热力网络；拆开后单独的热网或回水都不能形成稳定供热里程碑。

## 2. 候选结构

- 候选名称：蒸汽热网循环；
- 直接前置：`NRG-HTR-001`、`MAT-PIP-001`、`IME-VLV-001`；
- 工程：工业蒸汽热网工程；
- 设施：换热泵站；
- 工程：凝结水回收工程。

本项让蒸汽从热源送到不同工业用户，经换热后把凝结水送回，并按各支路的压力、温度和需求保持分配。它不产生蒸汽，不建成锅炉或窑炉，也不等于热网已经在具体地点完工。

## 3. 前置与解锁修正

正式树只依赖发电机组修复，缺少连续工业热源、承压管道与工业阀门，无法支撑蒸汽热网。候选结构改为承接工业热力、压力管材和阀门能力。正式树还把“工业蒸汽热网”登记为产品；热网是地点化基础设施，应改为工程。

此外，`ENE-SOL-001`把本项列作回收光伏组件与并网的直接前置，没有技术因果。整树复审应在太阳能节点移除此边，但不因此改变本项正文。
