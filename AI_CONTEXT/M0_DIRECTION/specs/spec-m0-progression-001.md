# SPEC-M0-PROGRESSION-001 · M0 科研、高级资产与前哨复制

## 1. 本规格要决定什么

本规格把关键科研、普通科研自动推进、精密制造中心、勘测无人机、第一座工业废墟回收前哨和第二座自动复制连成一条真实能力链。

本规格不制作完整科技树、其他前哨类型、能源系统、战争、舰队或不可解释的自动 AI，也不授权修改游戏代码。

## 2. 已确认边界

- 玩家可以集中人力和物资突破一个关键目标，普通科研允许按领域倾向自动推进；两者都必须使用真实科研人力，不生成免费科研点。
- 科研只在白昼推进。2/4/6 人仍是科研最低、标准、加速档；P0 至 P3、安全线、物资预留、暂停和恢复沿用 `SPEC-M0-OPS-001`。
- 科技完成只解锁设计、工程或制造能力，不能直接生成设施、资产、产量或地图情报。
- 开局没有精密制造中心、勘测无人机、远程前哨和废墟回收标准工程包。
- 精密制造中心不能要求精密部件作为自身建造前置；首批工程构件和合金料来自已确认的有限旧设备库、总部拆解区与现场材料。
- 勘测无人机必须进入已经接受的方向线索、范围确认、路线确认、现场确认流程，不能一键揭示地点全部资料。
- M0 没有通用电网，也不增加能源或燃料库存。无人机自带电源不能顺带解锁夜班、卡车、叉车或连续生产。
- 第一座工业废墟回收前哨由玩家完整主导；第二座同类前哨在玩家批准地点、优先级与投入上限后自动复制，但仍消耗真实人力、物资、白昼和运输。
- 标准工程包是图纸、工序、适用范围和验收经验，不是库存，也不是抽象速度加成。

## 4. 第一项修订提案：一条真实科研工作线，两种选题方式

### 4.1 M0 只有一处基础科研工作区

总部开局有一处使用旧资料、旧仪器和手工工具的基础科研工作区。它能研究，但不能制造精密部件，也不代表总部已有能源。

M0 同一时间只推进一个科研项目。科研使用真实的 2/4/6 人档，只在白昼产生项目进度；少于 2 人时暂停。进度保存在具体项目上，不形成可以存储、转移或一次灌入别处的“科研点”。

未来如果建成第二处真实科研设施并投入另一批人员，可以再讨论并行科研；M0 不凭界面上的第二个队列免费产生第二份科研能力。

删除“发展人力池”这个说法。没有可执行科研时，已分配的科研人员仍留在基础科研工作区待命，不产生科研进度；玩家可以把他们调到其他具体岗位。

### 4.2 第一种：指定目标或手动排队

玩家可以在科研树上点击任意已经显示的远期科技。系统沿依赖关系向前展开，把尚未完成的必要前置和最终目标放入一条完整可见的队列：

- 已经完成的前置直接划去；
- 已经有部分进度的项目保留进度；
- 多个目标共用的前置只排一次；
- 互不依赖的项目可以由玩家换序；
- 有依赖关系的项目不能移到其前置之前，界面直接说明原因；
- 互斥分支、重大路线和不可逆选择停在选择点，不能由系统代选；
- 设施、资产或现场条件只显示为实际阻塞，不能被伪装成科研步骤自动完成。

玩家也可以不点远期目标，直接逐项添加和预排科研项目。无论由目标展开还是手动排列，玩家看到的都是同一条指定队列。

### 4.3 第二种：按领域顺序自动推进

M0 先只显示当前确实存在普通项目的三个领域：

- 制造与材料；
- 勘测与地图；
- 工程与后勤。

玩家把参与自动科研的领域排成严格顺序：

| 设置 | 自动科研怎样处理 |
|---|---|
| 第一、第二、第三 | 按界面从上到下的顺序进入下一阶段和补普通科技 |
| 不参与自动 | 不进入自动轮次；玩家仍可在该领域手动指定目标 |

不使用并列优先，也不再使用“优先、正常、维持、暂停”四档。玩家直接拖动领域顺序，系统没有隐藏的同级判断。未来农业、能源或防务真正拥有项目后再显示对应领域，不在 M0 放空分类。

### 4.4 “下一阶段”由明确科技判断

所有领域共用可比较的阶段编号 `0、1、2……`，但每个领域可以显示自己的阶段名称。每个领域都在科研树上标出对应编号的阶段入口科技；完成这个入口科技，才算该领域进入对应阶段。

- 阶段不按完成科技数量、百分比或隐藏评分判断；
- 进入下一阶段只前进一级，不会把第一领域自动研究到科技树末端；
- 阶段入口所需的确定前置可以自动加入；
- 可选普通科技不影响阶段判定；
- 互斥前置和不可逆路线仍等待玩家选择。

某个领域达到当前内容的最高阶段时，显示“已到当前上限”，不再参与更高阶段的轮次；以后解锁新阶段后再自动加入。每个普通科技也必须标明所属阶段，避免手动提前突破后遗漏旧阶段的普通科技。

阶段的具体名称、入口科技和项目工作量交 `M0-L1-105` 纸面演算；本项先冻结阶段必须由公开节点判断。

### 4.5 自动轮次：先突破，再追平，最后补普通科技

系统查看所有参与自动科研且仍有更高阶段的领域，以其中最低阶段的下一个阶段作为本轮共同目标：

1. 只处理尚未达到本轮目标的领域，并按第一、第二、第三的顺序完成确定前置和阶段入口；
2. 所有参与领域达到本轮目标后，再从第一领域开始，补完所属阶段不高于本轮目标且允许自动研究的普通科技；
3. 同一领域有多个普通科技时，按领域内公开顺序执行；玩家可以调整互不依赖项目的先后，也可以标记“不自动研究”；
4. 每完成一个项目就重新检查一次全部前置；只有完整扫描后再无可执行项目，才报告本轮阻塞；
5. 本轮所有可自动研究内容完成后，再计算下一轮目标。

如果某个领域已经被玩家手动推进到更高阶段，自动轮次先跳过它，让其他领域追上；所有参与领域追平后，它才再次第一个进入新阶段。这样第一领域总是先获得新阶段能力，但不会在其他领域完全不动时连续领先很多阶段。玩家如果要集中冲击更远的关键科技，使用第一种指定目标方式。

普通科技只包括已经公开、没有互斥选择、没有被玩家标记为“不自动研究”的项目。如果被排除的项目后来成为阶段必要前置，系统直接显示冲突，不会绕过。

某个参与领域被路线选择、跨领域前置或实际条件阻塞时，系统显示原因，并先完成其他领域不超过本轮目标的可执行内容；随后重新扫描。仍不能让全部参与领域达到本轮目标时，不得开始更高阶段。玩家解除条件或把该领域改为不参与自动后，系统才重新计算本轮。

### 4.6 两种选题方式怎样接续

- 指定目标和手动队列排在领域自动队列之前，但不会与自动队列同时运行；
- 玩家加入指定目标时，可以选择立即切换，或完成当前自动项目后切换；已有项目进度不清空；
- 指定队列清空后，如果领域自动开启，就保留原来的本轮目标和执行位置，但按当前科技树重新生成并去重尚未完成的内容，不能恢复已经过时的旧队列；
- 指定路线因自身条件受阻时，默认停住并说明原因；玩家可以手动调整队列，或开启“受阻时临时自动”。临时自动不会取消指定目标；条件恢复后，完成当前自动科技就回到指定目标；
- 玩家调整领域顺序时，当前科技默认做完，尚未开始的内容立即按新顺序重排；玩家也可以选择立即切换。加入或移出自动领域会重新计算本轮目标，但已有完成和项目进度全部保留；
- 整条科研工作线因安全线和全局 P0 至 P3 规则暂停时，两种选题方式都停止，不能靠切换领域绕过；
- 领域第一、第二、第三只决定研究什么；科研工作线的 P0 至 P3、物资供应和 2/4/6 人分别决定能否推进和推进速度。

界面显示当前项目来自“指定队列”还是“领域自动”、完整队列、当前自动轮次、领域阶段、实际投入人数、预留物资、剩余工作以及每次自动选择原因。

### 4.7 M0 的实际例子

三个领域都处于阶段 0，玩家排列为制造与材料第一、勘测与地图第二、工程与后勤第三。自动顺序为：

`制造 0→1 → 勘测 0→1 → 工程 0→1 → 按制造、勘测、工程的顺序补阶段 1 普通科技 → 制造 1→2……`

玩家随后点击远期科技“恢复精密制造”。系统把确定的必要前置和目标放到指定队列前方；领域自动停在原轮次。目标完成只解锁精密制造中心建设条件，不会直接生成制造中心或精密部件；指定队列清空后，领域自动从原位置继续。

具体阶段名称、科技节点、工作量、所需白昼和试验物资交 `M0-L1-105` 纸面演算；本项只冻结控制方式、队列展开、自动轮次和玩家接管边界。
