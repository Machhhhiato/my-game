# M1第四阶段浅层岩芯钻探科技事实修正

## 1. 尺度裁决

`RSC-DRL-001`保留为一项浅层岩芯钻探科技。钻孔位置、岩芯编录和矿体连续性验证共同把地表候选区提升为有地下证据的资源判断；它应位于正式矿场开拓之前，而不是与采矿结果倒置。

## 2. 候选结构

- 候选名称：浅层岩芯钻探；
- 直接前置：`RAW-GEO-001-C`、`MCH-HND-001`；
- 行动：浅层钻探行动；
- 产品：岩芯样品；
- 记录：岩芯档案；
- 状态：资源可信度。

本项让候选区地下的岩层、矿化厚度和中断位置由连续岩芯留下证据，地表异常是否向下延伸可以被重新判断。它不计算可采储量，不证明开采经济性，也不建成矿场。

## 3. 前置与跨节点修正

正式树只依赖地质踏勘，跳过露头编录与资源区划；候选结构改为承接资源区划末端，并增加早期钻探工具前置。正式树还漏掉岩芯样品产品，候选结构补齐。

本项应成为`RAW-MIN-001`的直接前置。此前浅层矿井候选暂以资源区划为前置；发现本节点后，修正为`RSC-DRL-001`与`MCH-HND-001`，避免在地下连续性未经验证时直接开拓矿场。
