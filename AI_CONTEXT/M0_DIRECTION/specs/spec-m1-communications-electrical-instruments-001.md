# 方向十三：通信、电气与仪器

## 1. 方向结果

本方向把口头传令和遗产电器使用推进为可维修电气元件、可校准仪器、有线/无线通信、工业控制和跨聚居点信息网络。

## 3. 产品与代际

- 仪表：修复式仪表 → 标准工业仪表 → 联网记录仪表；
- 有线通信：临时线路 → 聚居点电话网 → 区域通信骨干；
- 无线电：修复式固定台 → 便携/车载标准台 → 中继网络；
- 控制系统：继电控制 → 基础可编程控制 → 多设备监控与记录；
- 计算设备：单机恢复 → 本地数据服务 → 多节点冗余服务。

芯片、电阻和电容不按每个型号单独生产；当本地微电子制造尚未恢复时，可以依赖分级遗产元件、贸易或回收，但必须记录库存和替代风险。

## 4. 第 730 日验证

- 关键水务、能源、机床或化工设备至少一条接入仪表与安全联锁；
- 有线与无线通信形成互补；
- 数据可以备份、校验并在断电后恢复；
- 多聚居点主通信中断后存在真实备用方式；
- 不把遗产计算设备存在等同于本地电子产业完全恢复。
