# 决策

| 稳定ID | 候选名称 | 结论 |
|---|---|---|
| `MIL-EXT-015` | 反装甲导弹定型 | 制导传感、推进、战斗部及整弹试验链缺失，后移 |
| `MIL-EXT-037` | 指挥所设备定型 | 交付YZ-A1设备组，缺少核心模块时按降级能力使用 |
| `MIL-EXT-038` | 昼间侦察器材 | 收窄为ZG-A1被动昼间观察组，移出夜视热成像和激光测距 |
| `MIL-EXT-042` | 电子战设备定型 | 宽带射频和信号处理链缺失，后移 |
| `MIL-EXT-049` | 移动应急供电 | 与ENE-EMG-001及YD-A1产品完全重复，合并删除 |
