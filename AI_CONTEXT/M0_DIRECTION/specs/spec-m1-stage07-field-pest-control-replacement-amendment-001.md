# SPEC-M1-STAGE07-FIELD-PEST-CONTROL-REPLACEMENT-AMENDMENT-001

## 结论

`FOD-PRO-001`删除肥料生产身份，收窄替换为“田间病虫防治”。监测、风险分级、处置阈值和安全施用共同形成一个完整植保方法，不拆分。

- 前置：`FOD-FLD-001` 露地耕作组织
- 行动：田间病虫监测；田间病虫防治
- 记录：监测记录；植保剂施用记录
- 状态：田间病虫风险等级；采收安全间隔
- 标准：田间病虫处置阈值
- 科研点：候选40点；原50点剩余10点进入整树重估池

本项不生产植保剂、肥料或农业投入品；肥料、营养液和土壤改良剂交给`CHM-FRT-001-A/B/C`。科研不自动监测、防治或产生合格农产品，使用化学植保剂时必须记录用量、防护、漂移和采收间隔。

饲草、豆类、谷物磨制、区域食品组织、水产和兽医节点删除本项通用前置，不机械重接；投入品安全法律可读取本项记录但不是科研产出。
