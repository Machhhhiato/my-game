# SPEC-M1-STAGE07-SAWN-TIMBER-PRESERVATION-SPLIT-AMENDMENT-001

## 结论

`RSC-SAW-001` 拆为“锯材生产”与“木材防腐”，原ID降为迁移别名。锯解、干燥和分级共同决定普通锯材能否交付，保留为一项；防腐只服务于潮湿、露天或接地等长期暴露用途，另成一项。

### `RSC-SAW-001-A` 锯材生产

- 前置：森林经营规划；手工具修磨
- 设施：锯材场
- 行动：锯材生产行动
- 产品：`MC-A`型分级锯材
- 标准：锯材干燥与分级标准
- 行动：木材含水率与质量检验行动
- 记录：锯材检验记录
- 科研点：候选20点

### `RSC-SAW-001-B` 木材防腐

- 前置：锯材生产；化学品安全鉴别
- 设施：木材防腐工位
- 行动：木材防腐处理行动
- 产品：`MC-F1`型防腐锯材
- 标准：木材防腐处理与验收标准
- 记录：木材防腐批次记录
- 科研点：候选15点

科研不自动建设锯材场或防腐工位，不自动取得原木、防腐材料或产品库存。普通建筑、木器和周转容器只需承接锯材生产；长期露天、接地或潮湿用途才承接木材防腐。若后续建立林区采伐节点，正式链条应为“森林经营规划→实际采伐与原木产出→锯材生产”。
