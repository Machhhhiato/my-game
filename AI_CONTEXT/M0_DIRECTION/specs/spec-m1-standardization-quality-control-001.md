# 方向十七：标准化、检验与质量控制

## 1. 方向结果

本方向把“能做出一件”推进为“不同人员、设备、批次和地点能够按同一要求重复生产、发现问题、隔离批次并安全改型”。

## 3. 型号关系

- 小修订：不改变正式型号，更新批次和技术文件版本；
- 同代改型：保留产品家族和代际，形成新的正式改型后缀；
- 跨代换型：关键性能、用途、生产或维护发生里程碑跨越，形成新型号；
- 任何改型都必须重新完成受影响的试制、检验、工装和维护验证；
- 旧型号、旧批次和旧备件不因新型号定型而消失。

## 4. 第 730 日验证

- 关键材料、车辆、机床、药品和军工产品均有批次追溯；
- 至少一次问题批次完成隔离或召回；
- 至少一个产品完成正式改型并保留新旧库存关系；
- 第二工场能按同一标准生产并独立验收；
- 标准不形成日期门。
