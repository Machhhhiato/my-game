# 两年恢复终点与生产能力倒推稿

## 1. 最终截止日期的准确含义

本轮平衡设计的**最终目标截面**为：

> **开局第 730 日结算结束，即离开避难所后约 24 个月。**

第 730 日用于统一讨论工作量、人口承载、科研难度、工程并行度、事件密度和纸面验收，不是日期解锁门，也不是强制胜负日。

- 玩家在第 730 日前完成全部真实能力证明，系统立即承认已经达到该生产阶段，可以继续研究和建设后续能力。
- 玩家到第 730 日仍有缺口，系统列出具体缺失的人员、知识、设施、原料、能源、路线、标准或维护能力，战役可以继续。
- 任何科技都不得因为`通常在第二年完成`而等待指定日期；日期只用于反推其合理工作量。
- 本文件中的第 90、180、360、540、640 和 730 日均是纸面检查点，不是硬阶段门。

## 2. 什么才算恢复了一项生产能力

一项能力只有同时形成以下七段证据，才算在第 730 日成立：

1. **输入**：能够持续取得原料、燃料、零件、人员和必要知识；
2. **工艺**：有可重复执行的流程、配方、图纸、公差或操作规程；
3. **设施**：有真实地点、设备、供能、安全条件和排污/废物处理；
4. **产出**：不是唯一原型，而是能形成满足实际需求的小批量或连续产出；
5. **检验**：有量具、抽检、失效隔离、批次记录和责任追溯；
6. **交付**：产物能够入库、运输、安装或发放到真实使用对象；
7. **复产**：设备停机、易损件耗尽或人员换班后，能够依靠本地维修、备件和训练恢复运行。

只有旧库存、只修好一台遗产设备、只完成实验室样品、只拿到外部图纸或只在界面点亮科技，都不算恢复生产能力。

标准平衡路线的最终验收窗口暂定为第 641—730 日。所有终点能力应在这个窗口内至少完成一次`生产 → 检验 → 使用 → 维护/补充`闭环；提前路线可以在更早的任意连续运行窗口完成同样证明并立即被承认，不必等待第 641 日。

## 3. 第 730 日必须具备的生产能力

### P01 能源、燃料与基础电气

终点能力：

- 本地发电、配电、储能和负荷调度能同时维持居民基本服务与关键工业负载；
- 能处理至少一种稳定本地燃料或能源来源，并保留另一条应急供能路线；
- 能维修发电机、电动机、泵、低压配电、常用线缆、开关和保护装置；
- 能制造或翻修常用机械、电气易损件；复杂功率电子和芯片可以继续依赖遗产库存或贸易。

直接前置：燃料/能源资源点、材料与机加工、绝缘与润滑材料、量具、受训电工、备件账目和消防制度。

### P02 水务、卫生与基础环境工程

终点能力：

- 形成`取水 → 净化 → 储水 → 配水 → 污水/废物处理 → 检测`闭环；
- 总部和主要聚居点都有可维护的供水、排污、公共清洁与污染隔离能力；
- 能本地生产或稳定取得常用管件、阀门、泵维修件、过滤介质和消毒品；
- 水质、故障、污染源和服务缺口可追溯。

直接前置：水文与污染勘察、建材、泵阀制造/维修、基础化工、检验实验室、公共账目和工务队。

### P03 农业、食品加工与储备

终点能力：

- 稳定种源、土壤与肥力管理、灌溉、病虫害控制和适度机械化能够支撑多聚居点人口；
- 形成至少一条`农业生产 → 初加工 → 保藏/冷藏 → 仓储 → 跨点运输 → 配给/交易`链；
- 能生产或维护常用农具、简单农业设备、食品容器和仓储设施；
- 饥荒风险来自可解释的产量、储备、运输和人口变化，而不是抽象倒计时。

直接前置：水务、肥料/农业化学品、机械维修、能源、道路仓储、检疫和人口需求账本。

### P04 建筑、矿物材料与耐久住处

终点能力：

- 能重复生产石灰/水泥类胶结料、骨料、砖石或等价构件、常用玻璃和处理木材；
- 能建设并维修住房、仓库、工棚、诊所、学校、道路小型构造物和工业基础；
- 有材料配比、承载、安全、消防和验收标准；
- 新接纳人口的住处和公共设施扩张不再只依赖清空遗址。

直接前置：矿源与采运、窑炉和热能、破碎筛分、工务测量、运输、劳动保护和施工组织。

### P05 金属、标准材料与热处理

终点能力：

- 能稳定取得并加工结构钢、工具/弹簧等所需的合格钢材，以及铜、铅等关键有色材料的回收或供应；
- 具备铸造、锻造/成形、焊接、热处理、表面保护和材料检验；
- 能按标准规格提供板、棒、管、线、紧固件毛坯和枪械/机械所需材料；
- 不要求两年内重建完整大型联合钢铁工业或原生铝全流程，但不能只靠无法补充的废料库存。

直接前置：矿产/废料分级、燃料与电力、耐火材料、炉窑、基础化学、材料实验和运输。

### P06 母机、量具与通用制造

终点能力：

- 具备可维护的车、铣、钻、磨、锯、冲压/压力加工、焊接和热处理组合；
- 能恢复或制造刀具、夹具、量具、轴承/衬套、密封、弹簧、紧固件、齿轮和常用标准件中的可行部分；
- 能小批量制造泵阀、农机件、车辆维修件、简单生产设备、枪械零件和工务设备；
- 建立图纸版本、公差、工序、检验、不合格品和维修档案。

直接前置：P01 能源、P05 材料、P07 化工辅料、技术教育、计量基准和稳定工场。

### P07 基础化工、肥料与工业耗材

终点能力：

- 能稳定生产或通过贸易取得水处理、清洁消毒、酸碱处理、肥料/农业投入、燃料处理、润滑、防腐、胶黏和基础实验所需的一组关键化学品；
- 能支持发射药、底火等军工化学品的本地安全小批量生产；外部供应可以补充产量和原料，但不能替代本阶段要求的本地弹药生产能力；
- 有纯度、配方、批次、安全、通风、消防、废液和污染处置制度；
- 不要求两年内恢复完整石油化工谱系、全套合成材料或全谱制药。

直接前置：资源与原料勘察、容器和玻璃、能源/热力、检验、受训化学人员、危险品仓储和环境治理。

### P08 运输装备、道路与区域物流

终点能力：

- 形成总部与主要资源、农业、工业和外部贸易节点之间的计划运输网；
- 能维修道路、桥渡、车辆、轮胎/等价行走件、制动、动力和常用运输装备；
- 至少能翻修和小批量改装通用货运、农业或工务车辆，不要求完整现代汽车量产线；
- 仓储、装卸、路线风险、护运、燃料、维修和备件均进入真实结算。

直接前置：P04 建材、P05 材料、P06 制造、P01 燃料/电力、通信、路线勘察和护运力量。

### P09 通信、仪表与有限计算

终点能力：

- 建立覆盖主要节点的无线电和有线/中继通信，以及调度、预警和故障备用方案；
- 能维修常用仪表、传感器、电源、无线电、计算设备和控制设备；
- 能生产线缆、机箱、连接件、简单模拟/机电仪表并组装遗产电子元件；
- 计算与自动化可以依赖回收芯片和设备，但必须有备份、数据迁移、离线规程和人工降级能力；不要求半导体晶圆制造。

直接前置：P01 电力、P05/P06 材料制造、计量、技术教育、档案与跨点维护队。

### P10 医疗、公共卫生与基础医用物资

终点能力：

- 能持续提供饮水卫生、检疫、创伤处理、产育照护、常见感染处理和基本诊疗；
- 能本地生产或稳定取得敷料、消毒品、基础玻璃/容器、简易器械、氧气/呼吸支持耗材和一组关键药品；
- 有冷链、无菌/清洁操作、批次、有效期、不良反应和转诊制度；
- 不要求两年内恢复完整现代制药工业、复杂生物制品、先进影像或全科室医院体系。

直接前置：P02 水务卫生、P07 化工、P09 仪表、冷链、受训人员、人口健康档案和物流。

### P11 枪械、弹药与军用保障

终点能力：

- 建立一种标准步枪/卡宾枪及对应弹药的试制、小批量生产、检验、入库、维修和补充链；
- 库存旧枪允许继续使用，但其口径、零件和弹药负担必须单独记录；
- 枪械具备合格材料、枪管/机匣加工、热处理、公差、耐压/寿命测试和维修件；
- 弹药具备壳体/弹头材料、发射药、底火、称量装配、抽检、实射、分区储存和批次追溯；
- 军队具备训练、通信、医疗、工兵、运输和补给，不把枪支数量直接等同于战斗力。

直接前置：P05 材料、P06 母机量具、P07 化工、P08 物流、P09 通信、P10 医疗，以及兵员训练和安全试验场。

枪管、机匣、底火等只用于后台验证材料和工艺是否真实存在，不成为玩家侧独立产品或零件库存。玩家侧按`枪械`、`弹药`和家族备件包管理。

### P12 维修、回收、标准与复制能力

终点能力：

- 每条关键生产链都有维护周期、易损件、库存下限、停机规程和责任岗位；
- 废金属、弹壳、机油、溶剂、包装、零部件和报废设备有回收、再用、再制造或安全处置路线；
- 关键图纸、配方、标准、培训和检验方法能够复制到至少两个地点或两支班组；
- 任何一名核心专家离开都不会让整个体系永久失传。

直接前置：技术学校、公共档案、计量检验、跨点物流、备件预算和事故复盘制度。

## 4. 不属于第 730 日强制终点的能力

以下能力可以因玩家获得特殊遗产、人才或贸易而提前研究和试验，但不作为普通路线第 730 日的必备生产能力：

- 半导体晶圆制造和先进芯片完整供应链；
- 全谱现代制药、生物制品和大型综合医院设备制造；
- 大型联合钢铁、原生铝、电解铜等完整高产能体系；
- 完整现代汽车工业、航空发动机、民航与大型船舶工业；
- 坦克、重炮、军用航空、远洋海军、导弹与总体战工业；
- 核工业、卫星、精密光刻、先进复合材料和全球化消费电子工业。

这些排除项防止把`基础 21 世纪生产方式`误解成在两年内复刻灾前全球产业总量。它们没有日期禁令；条件真实满足时仍可提前推进。

## 5. 支撑生产的组织能力

上述十二条生产链还必须由以下共同能力承载：

- **人口与劳动力**：登记年龄、健康、技能、照护和岗位；新人口完成检疫、安置、训练与服务接入后才能形成稳定劳动；
- **教育与科研**：档案、实验、学徒、技术学校、标准机构和跨班组传承；
- **行政与财政**：真实库存、成本、预算、合同、税费、申诉、安全责任和中央—聚居点权责；
- **外交与贸易**：知识、稀缺材料、设备、药品和芯片可通过真实协议与路线补足，但会产生价格、义务和中断风险；
- **安全与军队**：保护人口、设施、路线和仓储，承担守备、护运、救援和有限作战；
- **公共服务**：住房、供水、食物、医疗、卫生与照护不达标时，人口不能被当作无成本工业投入。

## 6. 从第 730 日向开局倒推

### 第 730 日：基础现代生产体系成立

必须证明：P01—P12 均达到本文件定义的能力终点；至少一个外部贸易链、一个受控聚居点中央收入链和一支可持续基础部队完成真实结算。

因为最终验收要求复产和维护，所以不能到第 729 日才首次开机。

### 第 640 日前：全部终点生产链进入验证运行

倒推要求：

- P01—P12 的终点设施、人员、输入路线和检验方法必须基本就位；
- 进入约 90 日的连续生产、使用、故障、补料、维护和复产观察；
- 暴露的瓶颈只能通过真实扩产、替代材料、贸易、训练或流程修订解决；
- 枪械弹药、医疗品、食品、能源和水务均必须经历批次/周期验证。

### 第 540 日前：小批量制造和跨聚居点供应形成

倒推要求：

- P04—P07 的材料、机床和化工已经从实验/修复转入稳定小批量；
- P03、P08、P10、P11 能使用这些本地产物运行，不再只依赖一次性遗产库存；
- 至少两条跨聚居点生产链和一条稳定贸易合同已经开始多次交付；
- 技术学校、检验、图纸和维护班组开始复制，不由单个专家垄断。

### 第 360 日前：母机、材料、能源和基础化工骨架闭合

倒推要求：

- 可用能源覆盖主要工场，关键设备有稳定负荷和安全停机；
- 形成材料识别、炉窑/热处理、机加工、焊接、量具和基础实验能力；
- 建材、水处理、肥料/消毒、润滑/防腐等至少形成可运行路线；
- 农业、住处、水务、仓储和医疗能够支撑持续吸纳人口；
- 第一批外部聚居点、资源点和路线进入贸易、保护或统合关系。

### 第 180 日前：人口、地点、资源和组织底座扩展

倒推要求：

- 总部已能持续接纳流民，不因住处、水、食物、卫生和登记立即失稳；
- 完成主要水源、农业地、燃料/能源点、矿物/废料点和外部路线的初步确认；
- 建立基础账目、仓储、交通通信、护运和公共卫生；
- 形成第一批学徒、工务、农业、医疗、警戒和行政班组；
- 至少一个外部实体可以持续接触，知识与物资交换开始成为真实选择。

### 第 90 日前：M0 立足闭环

沿用 M0 已冻结目标：28 人离开避难所后建立供水、食物、维护、科研、探索、精密工坊和首批前哨的可玩闭环。此时重点不是拥有现代工业，而是取得继续扩张所需的安全地表基地、第一批候选地点、档案知识和维护能力。

### 第 1 日：继承条件

开局只继承避难所人口、档案、内部设备、有限库存和已知技能。避难所电力、设备、知识与库存不能自动视为地表区域生产能力；任何终点能力都必须重新取得外部地点、供应、运输、运行与维护证明。

## 7. 倒推得到的关键施工顺序

日期不决定能否施工，但依赖关系决定通常的工作顺序：

```text
人口生存与登记
  → 水、食物、住房、卫生可扩张
  → 资源点、路线、外部聚居点可持续接触
  → 本地能源、建材、金属和基础化工
  → 母机、量具、标准件和检验
  → 农业机械、泵阀、车辆、仪表、医疗品和枪械弹药
  → 跨聚居点专业分工、贸易、税费/上缴和军队保障
  → 连续运行、维护复产与跨地点复制
  → 基础 21 世纪生产体系成立
```

玩家可以通过遗产设备、外部贸易或兼并跳过某些`发现和试制`工作，但不能跳过人口承载、输入供应、运行、检验、维护和复产。

## 8. 对科研树的直接约束

两年科技树不再从旧目录顺序正向堆满，而从 P01—P12 的终点证据倒推：

1. 每项终点能力先生成一个 C3 主干突破；
2. 为该突破列出必须存在的工程、输入、人员、标准和运行证明；
3. 再向前拆出 C2 的可复制小批量、C1 的可运行路线和 C0 的识别/维护能力；
4. 只有能够连接某项生产、公共服务、外交、人口或军事结果的科技才进入两年可见窗口；
5. 旧 R5 一千项目录继续作为内容素材和长期架构，不自动等于两年战役的实际科技清单；
6. 任何节点都不用日期作前置，科研工作量由它离终点证据的距离、实验复杂度、跨领域条件和工程反向前置决定。
