# 方向十五：民用产品与生活水平

## 1. 方向结果

本方向把“人口获得最低生存物资”推进为可重复生产、维修、分配并真实改善家庭生活的衣物、家具、炊具、卫生用品、照明、家用电器和公共生活产品。

## 3. 生活水平反馈

生活水平不使用单一幸福加成。它由实际住房、衣物、卫生、照明、温度、食品保存、照护和可支配时间共同表现，并反馈到健康、劳动、家庭形成、教育和迁居选择。

## 4. 产品迭代

- 衣物：修补与再利用 → 标准尺码基础衣物 → 工作/气候/照护专用服装；
- 家具：临时拼装 → 标准家具 → 模块化住区家具；
- 照明：便携低功率照明 → 固定安全照明 → 分区节能照明；
- 家用设备：修复式单件 → 标准型号 → 可维护高效型号。

## 5. 第 730 日验证

- 民用品不是抽象消费品数字，至少六类产品有生产、库存、使用和维修；
- 新人口接纳会真实增加生活用品需求；
- 家用设备增加电力和维修负担；
- 产品改善通过健康、照护和时间结果体现；
- 无日期门。
