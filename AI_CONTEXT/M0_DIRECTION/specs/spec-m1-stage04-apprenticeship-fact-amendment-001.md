# M1第四阶段学徒岗位训练科技事实修正

## 1. 尺度裁决

`SOC-APR-001`保留为一项学徒岗位训练科技。学徒关系、合格导师、真实岗位工时、技能记录和结业实作共同把新劳动力转为能够独立工作的熟练人员；它产生长期人力增长，是玩家可感知的组织里程碑。

## 2. 候选结构

- 候选名称：学徒岗位训练；
- 直接前置：`POP-AGE-001`、`SOC-LIT-001`；
- 组织：学徒训练计划；
- 记录：学徒关系；
- 标准：导师资格；
- 记录：岗位训练工时与技能；
- 行动：结业实作考核；
- 记录：岗位结业资格。

本项让学徒在合格导师和真实岗位下积累可核对的工时与技能，只有通过实作考核者才进入独立岗位。它不凭时间自动生成熟练工，不把导师身份当作所有行业通用资格，也不替代后续复训与资格暂停制度。

## 3. 前置与解锁修正

正式树只依赖年龄资格，缺少基础识字与数理能力。候选结构增加`SOC-LIT-001`。正式输出漏掉学徒训练组织、工时技能记录与结业资格，并把结业考核误写成产品；候选结构恢复为组织、标准、行动和记录。
