# 方向九：机床、工具与工业母机

## 1. 方向结果

本方向把手工修配和遗产机床使用推进为能够测量、加工、制造工装、复制基础机床并生产可互换零件的工业母机体系。

## 3. 已接受正文

### `MCH-RES-001` · 恢复精密制造

- 直接效果：`解锁工程：精密工坊恢复。`
- 完整正文：`统一的精度标准让复杂零件能够稳定复制，机器从此不再是少数工匠手中无法复刻的孤品。`
- 评价行：`“精密制造最伟大的进步，是终于能把工人的经验从工人身上剥离出来。”——生产恢复委员会`

以上三项已经接受，最终总树必须逐字保留。

## 4. 产品与代际

- 通用手工具：修复式工具 → 标准化新制工具 → 专用高寿命工具；
- 通用机床：遗产机床恢复 → 自制基础机床 → 基础数控机床；
- 量具与检具：修复量具 → 标准量规 → 跨工场校准体系；
- 工装：单件夹具 → 批量专用工装 → 可复制模块化工装。

## 5. 第 730 日验证

- 能自行制造和复验基础机床、刀具、量具与工装；
- 互换零件至少在两个批次和两个装配地点成立；
- 数控能力依赖真实电气控制与维护，不因研究自动出现；
- 新母机能够参与下一台母机制造，形成受检验的自复制闭环。
