# M1第四阶段住区公用接入科技拆分修正

## 1. 原节点不能作为一项科技

`SET-SVC-001`把供水接入、污水接入和固体废弃物收集合并为一个研究对象。三者使用不同的上游系统、工程接口、故障后果和后续维护，任何一项都不能由另外两项替代；这不是一个真实的单项科技，而是住区公用系统方向总结。事实门先退回，再由本修正案拆成三项候选。

## 2. `SET-SVC-001-A` 住区供水接入

- 类型：设计；
- 直接前置：`SET-HOU-001`、`WTR-STO-001`；
- 记录：住区供水接入施工图；
- 工程：住区供水接入工程；
- 标准：住区供水接口。

本项把清水配水端接到住宅用水点，明确入户管径、阀门、计量和防回流边界。它不取水、不净化原水，也不建成整个清水储配系统。

## 3. `SET-SVC-001-B` 住区排污接入

- 类型：设计；
- 直接前置：`SET-HOU-001`、`WTR-SEW-001`；
- 记录：住区排污接入施工图；
- 工程：住区排污接入工程；
- 标准：住区排污接口。

本项把住宅排水端接到污水收集系统，明确生活污水去向、检查口和防倒灌边界。它不处理污水，不把雨水与污水自动合并，也不建成整个污水处理系统。

## 4. `SET-SVC-001-C` 住区固废收集

- 类型：设计；
- 直接前置：`SET-CMP-001`、`SET-HOU-001`；
- 设施：住区废弃物收集点；
- 工程：住区固废收集工程；
- 标准：住区固废投放接口。

本项为住宅与临时营地设置可到达、可清运并与生活区保持卫生间隔的固废收集点。它不完成回收、堆肥、危险废物处理或最终处置。

## 5. 跨节点修正

`WTR-SEW-001`当前依赖原`SET-SVC-001`，与拆分后的排污接入形成倒置。整树复审应让污水收集与卫生处理先形成主系统，再由`SET-SVC-001-B`把住宅排水接入。后续依赖原节点的街区和公用设施科技，应按实际需要分别依赖A、B或C，不再依赖汇总节点。

原输出“聚居点基础卫生工程”是三种系统的汇总结果，不作为独立解锁；“废弃物接入”也不是产品，改为地点化收集设施、工程和接口标准。
