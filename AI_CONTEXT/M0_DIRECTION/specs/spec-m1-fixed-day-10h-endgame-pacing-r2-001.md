# M1固定五秒一日、十小时挂机与基础现代生产力终局节奏

> 2026-08-28再次修订：用户把基础时钟从五秒一日改为一秒一日，把终局挂机目标从约十小时改为约两小时。本文件只保留R2证据；现行规则见`SPEC-M1-FIXED-DAY-2H-ENDGAME-PACING-R3-001`。

## 1. 第一规则：日历照常走，终局不再等于第24个月

世界公历按正常日、月、年连续推进，基础速度固定为：

```text
1世界日 = 5秒实际运行时间
```

不得为了让终局落在某个现实小时数而拉长或压缩某一个月，也不得再使用“首月二十分钟、后续月份各六十一分钟”之类的分段时钟映射。

过去所称的“普通两年终点”，从本规格起统一解释为**基础二十一世纪生产力终局能力包**。它来自此前约两年恢复内容的讨论与筛选，但不再表示：

- 游戏日期必须是第24个月；
- 第730日自动完成主线；
- 第24个月之前不能研究后期科技；
- 第24个月必须拥有八万或十万人；
- 世界史只经过两年。

玩家看到的是正常公历与真实累计结果，不显示“为了平衡而延长的两年”。内部旧字段如`yearTwoMainline`可暂时保留为迁移别名，但新数据、规则和玩家文字应改称`endgameMainline`或“基础现代生产力主线”。

## 2. 固定时钟的直接换算

采用真实公历月长时：

| 世界时间 | 实际运行时间 |
|---|---:|
| 1日 | 5秒 |
| 28日 | 2分20秒 |
| 30日 | 2分30秒 |
| 31日 | 2分35秒 |
| 365日 | 30分25秒 |
| 2年约730日 | 约1小时50秒 |
| 前20分钟 | 240个世界日，约7.9个月 |
| 10小时挂机 | 7,200个世界日，约19.7年 |
| 前20分钟加约10小时挂机 | 7,440个世界日，约20.4年 |

因此，标准路线终局会在大约二十个世界年附近出现，这是固定五秒一日与约十小时挂机自然产生的结果，不再把公历伪装成两年。

以上只是换算，不是日期门。玩家准备充分、分配更好时可以更早闭合；事故、战争、短缺、可选路线和低效率会延后。

## 3. 游玩节奏目标

### 3.1 前20分钟

前20分钟仍要建立约一千人的可挂机小循环，但它不再被称作“第一个月”：

- 二十八人是离开避难所的初始行动队；
- 玩家接触并统合一个已有地点、人口和残缺设施的聚居点；
- 水、重复食品来源、关键供能、卫生、维修、住处医疗、机动人力和挂机队列必须能够接续运行；
- 一次性存粮、免费人口和无来源自动修复不得冒充正循环；
- 达成参考时，世界公历大约已经推进240日，具体日期取决于开局日期。

### 3.2 后续挂机

前20分钟完成基本授权和队列后，标准平衡方案的**后续挂机时间约为10小时**。这里的10小时是目标带，不是倒计时奖励：

| 实际累计运行阶段 | 主要体验任务 |
|---:|---|
| 00:00—00:20 | 建立千人级水、食物、供能、卫生和维修小循环 |
| 00:20—02:00 | 从临时修复扩为稳定作坊、农业、仓储、住处与基础研究 |
| 02:00—04:30 | 建材、金属、道路、通信、贸易和多地点统合开始互相供给 |
| 04:30—07:30 | 标准工厂、车辆、区域能源、公共服务、正式型号与维护网形成 |
| 07:30—10:20左右 | 补齐工业母机、枪械弹药、教育科研、医疗、财政与跨聚居点运行证据 |

阶段表只用于检查体验密度，不把科技、工程、人口或事件绑定到具体小时。

## 4. 终局由能力证据决定

基础现代生产力终局只有在对应证据同时成立时出现。至少包括：

1. 关键资源能够持续生产、运输、储存和结算，而不是只剩一次性库存；
2. 主线科技已经通过科研点、样品、试验、设施和工程反向前置完成；
3. 主线工程已经真实消耗材料、设备、运力和工程工时并通过验收；
4. 主要产品能够量产、形成库存、执行质量检查并获得维修与备件支持；
5. 人口、岗位、住房、食物、水、能源、卫生、医疗、教育、行政和治安能够共同承载当前规模；
6. 多聚居点之间存在可运行的贸易、财政、外交、物流和应急关系；
7. 基础军队、枪械、弹药、训练、补给和维修形成闭环；
8. 终局所依赖的设施连续运行并留下维护、故障和恢复证据。

公历到达某年某月、累计挂机达到10小时或完成一个“终局科技”都不能单独触发终局。

## 5. 用工作量拉开十小时，不改月份速度

节奏控制只允许通过真实账户与项目要求完成：

```text
当月可提供量 = 基础月产率 × 有效容量 × 效率 × 月份占比
当月实际交付量 = min(当月可提供量, 输入, 路线, 目标, 授权)
项目进度 = 上月进度 + 当月实际交付量
```

允许调整的对象：

- 单项科技需要的科研点、样品批次、试验次数和证明条件；
- 单项工程需要的工程工时、材料、设备、运输、施工面和验收阶段；
- 工厂扩建、产线爬坡、产品批次、备件储备和维护积压；
- 人口统合、培训、组织覆盖与公共服务所需的真实执行量；
- 终局前必须持续运行的月数和库存覆盖，而不是瞬时拥有。

禁止采用：

- 把某个月单独拉长；
- 科研专属现实秒倒计时；
- 工程隐藏减速倍率；
- “在线慢、离线快”的额外收益算法；
- 到点免费补资源、人口、科技或工程；
- 为阻止提前完成而设置日期门。

## 6. 科研、工程和资源如何重算

### 6.1 科研

R6的25,285点基础现代生产力主线科研量暂时只保留为**旧相对难度基线**，不得继续宣称它能在第24个月或某个现实小时完成。正式重算必须采用标准人口、科研岗位、设施形成时间和输入可用率逐月模拟：

```text
科研缩放基数 = 标准路线目标区间内可实际投入的累计科研流量 / 25,285
新科技成本 = 旧科技成本 × 科研缩放基数 × 层级修正 × 证据修正
```

缩放不能只把全部科技乘同一个常数。现场调查和基础方法仍应较快；工业母机、复杂材料、区域电网、车辆、军品和跨领域标准要由真实设施、样品、试验与工程前置拉开。

### 6.2 工程

七十四项旧主线工程只保留范围身份，不保留“第24个月完成”的数量曲线。每个工程逐项重新给出：

- 可并行施工面；
- 人员和设备容量；
- 工程工时；
- 建材、构件和运输需求；
- 试运行与验收期；
- 完工后的运营岗位、维护和备件责任。

小修、接入和作坊允许在早期密集完成；区域水务、电网、道路、标准工厂和多地点统合必须由多个实体工程累积形成。

### 6.3 资源与生产

终局节奏不能只靠提高科研点。资源侧必须同时重新核算：

- 工厂和设施建设所需的一次性资本品；
- 生产过程的原料、能源、运力和合格率；
- 扩建、换线、型号改进和产线爬坡；
- 维修备件、燃料、药品、弹药和关键库存覆盖；
- 公共服务、军队和新增人口带来的持续消费。

玩家应因为产能扩大、短板补齐和维护稳定而接近终局，而不是只等待一个总进度条。

## 7. 人口模型的强制修正

固定五秒一日后，标准终局附近已过去约二十个世界年，因此旧“两年人口”假设不能直接复用：

- 新生儿仍先增加食物、住房、医疗、教育和照护需求；
- 年龄队列按真实世界日期推进；
- 只有实际达到劳动年龄、满足健康与培训条件的人才能进入可调度人力；
- 早期出生人口在终局前可能成年，不能继续写死“本阶段不会成为劳动力”；
- 流民、兼并、协议统合、出生、死亡、迁出和年龄转换全部进入同一人口总账；
- 八万至十万人继续作为基础现代生产体系的参考承载规模，但不再是第24个月目标，必须通过新二十年人口曲线重新证明。

## 8. 数值验收带

正式平衡模拟至少检查三类路线：

| 路线 | 验收目标 |
|---|---|
| 标准参考路线 | 前20分钟形成千人小循环；随后约10小时挂机闭合终局能力 |
| 优化路线 | 因更好的选址、分配、贸易和前置组织而提前；系统不得用日期门阻止 |
| 受损路线 | 战争、事故、资源错配或可选研究造成真实延后，并能指出具体短板 |

标准参考种子的终局建议落在前20分钟之后9至11小时的挂机区间。这个区间是平衡验收，不是玩家界面上的倒计时或强制最短时间。

数值模拟必须同时输出：逐月人口与年龄队列、有效科研容量、科研投入、工程队与设备容量、关键材料和能源、工厂扩建、维护积压、主线完成度与终局缺口。只证明总科研点够用不能通过。

## 9. 当前实现差异与边界

当前M0实现常量仍是20秒一日，尚不符合本规格的5秒一日；本轮只冻结第一层方向，不直接修改游戏代码、存档、测试或构建。后续第四层实施必须同时处理时钟常量、严格存档校验、离线补算、月末结算次数和性能回归，不能只改一个显示数字。

科技正文R7逐项闸门保持独立：当前仍只允许处理`SET-SUR-001-B`，本规格不构成跳过或解锁下一项科技正文的理由。
