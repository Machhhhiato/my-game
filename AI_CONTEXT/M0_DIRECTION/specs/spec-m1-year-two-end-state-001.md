# M1 第2年终点实体、法令政策与状态合同

> 当前状态：本版已完成逐项独立性审计，但原24类工厂、34类设施、14项法令、12项政策和18项状态中存在聚合或类型错误，不再作为可直接录入的原子终点目录。工厂部分进一步发现把工厂、生产线和产品混为同层，已由 `SPEC-M1-FACTORY-CLASS-PRODUCTION-LINE-001` 取代；其他去向、效果和关联见 `M1_YEAR_TWO_ENDPOINT_INDEPENDENCE_RELATION_AUDIT_001.md`。

## 1. 第一规则：本轮只定义终点，不设计如何抵达

本轮回答的唯一问题是：当共同体已经达到两年基础现代生产力终点时，世界中应当存在哪些工厂、设施、法令、政策、组织与可验证状态。

本文件不安排建设月份，不写科研顺序，不分配月度工程点，不计算产量爬坡，不倒推 C3—C0 过程，也不把第 24 月做成日期门。以后无论玩家在第 18 月、第 24 月或更晚达到相同事实，都使用同一终点合同验收。

方向汇总只存在于本规格和验收页面，不进入实际科技树，不伪装成科技节点。

## 2. 五类对象必须分开

| 对象 | 准确定义 | 科研完成后的结果 | 第2年终点怎样成立 |
|---|---|---|---|
| 工厂 | 持续把原料和中间品转换为可入库产品的生产设施 | 只开放生产线设计、工艺和建设资格 | 至少有实际地点、设备、岗位、输入、产出、检验和维护记录 |
| 设施 | 持续提供能源、水务、仓储、医疗、教育、通信等服务的实体资产 | 只开放建设、修复或配置资格 | 已建成或修复验收，且有人员、负载、维护与服务对象 |
| 法令 | 长期有效、面向所有适用对象的权利义务与行政规则 | 科技或制度设计只开放颁布资格 | 已由中央颁布，保存适用范围、执行机关、权利义务和修订状态 |
| 政策 | 为处理具体缺口、风险或冲突而实施的有限期行政选择 | 只开放政策选项 | 玩家决定范围和期限后生效，结束后保留执行记录但不继续产生效果 |
| 状态 | 由人口、实体、库存、服务和运行证据计算出的世界事实 | 不能由科研直接解锁 | 满足全部证据时系统形成；任一关键证据失效时降级或消失 |

`记录`不是法令，`计划`不是工厂，`生产线设计`不是已建生产线，`组织方法`不是已存在组织，`配给登记`也不是配给政策本身。

## 3. 当前两年主线可用结果

- 两年必要主线包含 408 项科技、20,125 基础研发点。
- 它们在 R4 完整树中开放 1,026 项结果：146 项产品、41 项工程、28 项设施、262 项行动、513 项记录、9 项组织、10 项编制、11 项训练、4 项协议和 2 项被标作有限期政策的对象。
- 其余 227 项科技及其 531 项结果属于普通两年主线之外；玩家若提前满足前置仍可获得，但不进入本终点的强制清单。
- 1,026 项是原子结果，不等于需要在终点页面显示 1,026 个并列目标。本文件把它们按实际共址、共用设备和共同运行责任归纳为终点实体，但不把归纳结果反写为总结科技。

## 7. 第2年应当可选择的有限期政策

法令提供授权边界，政策只在具体问题存在时由玩家启用。第2年不要求所有政策同时生效；要求这些选项已经可用，并且当前生效项与真实缺口一致。

| ID | 政策选项 | 适用情形 | 结束条件 |
|---|---|---|---|
| Y2-POL-01 | 外来人口接纳强度政策 | 流民批次超过住房、检疫或供给能力 | 批次处理完成或承载缺口解除 |
| Y2-POL-02 | 紧急食品配给政策 | 储备、运输或产量不足 | 食品安全库存与运输恢复 |
| Y2-POL-03 | 关键负载优先供能政策 | 发电、燃料或配电能力短缺 | 供需重新平衡 |
| Y2-POL-04 | 饮水污染与分区供水政策 | 水源污染、管网事故或处理能力不足 | 水质复验与管网恢复 |
| Y2-POL-05 | 公共卫生强化与临时隔离政策 | 疫情、外来批次风险或医疗挤兑 | 传播风险和医疗负荷降至正常范围 |
| Y2-POL-06 | 重建材料优先分配政策 | 住房、工业、水务、道路工程争夺水泥、钢材和玻璃 | 指定关键工程完成或材料短缺解除 |
| Y2-POL-07 | 关键工业投入保障政策 | 燃料、化学品、备件或技术人员不足导致关键产线停摆 | 目标产线恢复稳定运行 |
| Y2-POL-08 | 库存下限与战略储备补充政策 | 食品、燃料、医用品、备件或弹药低于安全线 | 目标库存恢复并完成复核 |
| Y2-POL-09 | 聚居点迁居与服务减压政策 | 地点人口超过水、住房、医疗或治理承载 | 迁居完成且接收地服务接入 |

当前 R4 中`批次配给记录`和`配给关系登记`被标为有限期政策，但它们实际都是记录。终点合同将真正的政策对象定义为`Y2-POL-02 紧急食品配给政策`；批次配给记录和配给关系登记改作政策执行证据，不再冒充政策本身。

## 8. 第2年应当形成的世界状态

状态使用统一五档：`未形成`、`局部成立`、`稳定运行`、`承压运行`、`失效`。第2年终点要求以下状态至少达到`稳定运行`；允许因事件短期进入`承压运行`，但必须能显示原因、影响对象和恢复条件。

| ID | 状态 | 达到“稳定运行”的必要证据 |
|---|---|---|
| Y2-STA-01 | 多聚居点中央共同体成立 | 4—8 个主要节点保留地点人口、设施与库存，同时进入中央人口、服务、预算和调度体系 |
| Y2-STA-02 | 人口与人力账守恒 | 总人口、地点、来源、出生死亡、居留、民用岗位、科研和现役人员可相互核对，无重复占岗 |
| Y2-STA-03 | 外来人口连续统合 | 多批流民或并入人口完成接触、检疫、安置、登记、居留和服务接入 |
| Y2-STA-04 | 基本生活服务覆盖 | 食物、水、住房、卫生、医疗、照护和教育覆盖当前人口，缺口能按地点显示 |
| Y2-STA-05 | 水务与环境闭环 | 取水、净化、储水、配水、污水、废物、检测和抢修持续运行 |
| Y2-STA-06 | 食品安全与储备闭环 | 农业、初加工、保藏、仓储、运输和配给/交易至少完成一个完整周期 |
| Y2-STA-07 | 能源与关键负载稳定 | 主力与应急能源均可用，居民基本服务和关键工业负载有分区、计量和故障隔离 |
| Y2-STA-08 | 耐久住区可扩张 | 新人口能够通过真实建材、工程和公共接口获得耐久住处，不只清空遗址 |
| Y2-STA-09 | 基础材料可复产 | 钢材、水泥、玻璃、标准构件和基础化工完成原料到复产的完整周期 |
| Y2-STA-10 | 通用制造能够自我复制 | 机床、量具、刀具、标准件、泵阀和电动机能够相互支撑生产与维修 |
| Y2-STA-11 | 区域物流持续运行 | 道路、仓储、装卸、车辆、燃料、路线风险、护运和维修进入计划运输网 |
| Y2-STA-12 | 通信与离线数据连续 | 主要节点有有线/无线通信、备用路线、技术档案和离线恢复能力 |
| Y2-STA-13 | 基础医疗与公共卫生连续 | 分诊、创伤、感染、产育、基础器械、敷料、氧气和转诊均有人员与补给 |
| Y2-STA-14 | 质量与责任可追溯 | 关键产品有标准、批次、抽检、不合格隔离、召回、纠正和责任记录 |

“已研究发电科技”“拥有一张配电图”“仓库里有旧枪”都不能直接令相应状态成立。状态只读取实际实体与运行证据。

## 9. 第2年终点不要求的对象

- 大型联合钢铁、完整现代汽车、先进芯片、全谱制药和大型综合医院设备制造；
- 远洋海军、现代空军、完整导弹体系；
- 中型坦克、重型坦克和完整装甲兵体系；
- 完整消费电子、家电和化纤工业；
- 所有 635 项科技与 1,557 项结果全部完成或全部实体化。

这些对象可以提前出现，但不能反过来抬高普通两年终点，也不能要求玩家等待第2年后才研究。

## 10. 终点验收只看四层

1. **资格层**：相关科技和设计已经完成，只说明可以建设、生产、颁布、组建或执行；
2. **实体层**：工厂、设施、组织、协议和部队已经真实生成；
3. **运行层**：有人员、输入、能源、维护、产出、服务和故障状态；
4. **状态层**：系统依据连续证据形成第2年世界状态。

任一强制终点只有资格层而没有实体层，不算达到；只有实体但没有运行记录，也不算达到。
