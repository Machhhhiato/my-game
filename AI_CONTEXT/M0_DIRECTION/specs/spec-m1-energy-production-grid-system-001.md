# M1 能源来源、燃料、发电、热力与区域电网闭环

## 1. 第一规则：燃料、电力、热力和发电设备不是同一个对象

能源必须沿真实链条成立：

```text
能源资源或外部燃料
  → 开采、回收、净化、制备或贸易
  → 合格燃料库存与储运
  → 发电站、锅炉、窑炉或车辆消耗
  → 电力/蒸汽/热水形成地点化流量
  → 变配电、热力管网、计量与调度
  → 居民、农业、水务、医疗、通信、交通和工业负载
  → 损耗、排放、废热、检修与事故处置
```

- 燃料是可储存、运输和交易的实物产品。
- 电力与热力是带地点、时段、容量和网络约束的服务流，不能作为全国无损共享库存。
- 蓄电池组是设备；储电量、健康度和充放电功率是设备状态，不是另一种产品。
- 发电科技不会直接增加电量。电站、人员、燃料/自然资源、设备、线路、维护和调度同时成立才供能。
- 两年只用于主线与科研难度设计，不构成科技日期门；真实前置满足即可提前完成后期能源科技。

| M1-ENE-POLICY-001 | 关键负载优先供能政策 | 发电、燃料或线路容量不足 | 居民舒适与非关键工业限供；供需恢复后退出 |
| M1-ENE-POLICY-002 | 发电燃料专项配给政策 | 燃料同时短缺于运输、发电和工业 | 挤占车辆或工业燃料；储备恢复后退出 |
| M1-ENE-POLICY-003 | 计划停电与集中检修政策 | 设备、线路或锅炉需要大修 | 形成短期停供；检修验收后退出 |
| M1-ENE-POLICY-004 | 孤岛运行与黑启动应急政策 | 区域电网崩溃或节点分离 | 舍弃普通负载并消耗应急储备；主网恢复后退出 |
| M1-ENE-POLICY-005 | 临时用能压减与替代能源政策 | 连续供能缺口无法由调度解决 | 降低生产与生活水平并增加替代路线成本；缺口消除后退出 |

## 8. 统一月结算

能源继续使用统一资源内核，但必须保留所有基础设施服务共同需要的两个维度：`容量上限`与`月度流量`。

```text
可调度发电流量
= 各发电容量
× 设备可用率
× 人员与维护状态
× 燃料/水力/风光资源满足率
× 当月运行率
- 厂用电与转换损失

某节点可供电量
= 本地发电
+ 网络可达的输入
+ 储能放电
- 输配电损耗
- 储能充电

实际服务负载
= min(节点供给量, 网络输送容量, 负载需求量)
```

- 发电能力使用容量上限，实际电量使用月度流量；同一套结构也用于水务、运输、通信和工业产能，不另造能源货币。
- 每座电站按真实效率消耗燃料库存；没有燃料时，燃油机组不会因存在容量而发电。
- 风、光、水按地点和当月资源形成可用率；储能只能转移已有电量并承担损耗。
- 未由线路连通的聚居点不能共享电力；跨地点燃料调拨仍需车辆、道路、仓储和护运。
- 工业蒸汽与集中热力沿独立热网结算容量、流量和损耗，不能直接把电网覆盖当成热力覆盖。
- 负载结果进入农业、水务、医疗、通信、工业、住房和交通等系统；停电不是抽象满意度扣分，而是具体设备停机、产品损失和服务中断。

## 10. 第2年最低存在事实

普通第2年终点至少应具有：

1. 一种可以稳定补充的主力能源路线；
2. 一种性质不同的补充来源和一条移动或固定应急供电路线；
3. 覆盖主要聚居点、医疗、水务、通信和关键工业的中低压配电系统；
4. 发电、变配电、燃料、锅炉和储能均有值班、计量、检修、备件与事故记录；
5. 至少一个节点能够通过储能或应急机组完成关键负载恢复；
6. 需要工业蒸汽的食品、化工、医疗或材料生产具有真实热源和安全停炉条件；
7. 四项新增法令已颁布，五项政策能够按缺口启动并退出；
8. 八项状态均由实体和运行证据形成，而不是科技直接赋值。

本轮不确定装机容量、峰值负载、发电量、燃料库存天数、线路长度、电压等级细分、机组数量和建设月份。

## 11. 对现有 R4 数据的修正要求

1. `工业热力连续供给`不是产品，应改为设施服务状态和运行记录。
2. `聚居点能源调度台账`不是组织，应拆成调度机构、调度规程和运行台账。
3. `聚居点低压配电网`与`区域微电网`不是组织，应为地点化设施/网络对象。
4. `移动应急电源`、`小型可再生发电单元`和`聚合蓄电池组`不得继续作为记录，必须是具体设备产品或设施。
5. 小型水力、风力和太阳能现场适配科技只证明站址与接入方法；完整生产设备需要本规格新增的具体设备科技。
6. 原规格10个总结科技节点只作来源导航；R4 的28项原子节点与本规格18项新增节点共同作为实际展示对象。
