# M1科技正文完成后整树游戏设计复审

## 一、结论

R6源树539项已经全部完成逐项事实审查和正文审查。正文阶段形成的拆分、合并、删除、下沉和后移候选又经过一次整树复审；确定性问题已经落回相关阶段稿与事实问题账，不再保留“等整树结束再判断”的悬空结论。

最终形成519项科研候选：当前两年终局有效471项、后移48项。当前有效合计29,085科研点，后移合计12,005科研点，全部候选合计41,090科研点。被合并、删除或下沉的R6源身份共67项；逐项拆分净增加44项，恢复既有漏装里程碑3项，因此数量关系为：

`539 − 67 + 44 + 3 = 519`

旧版521项与40,935点总账已撤销。旧数量把已经并入反装甲导弹的`MIL-EXT-016`误列为独立后移候选，又把已经并入标准板材生产的`MAT-PLT-001`误列为当前候选；旧点数还掩盖了拆分池和未来重估字段。本文件只采用从当前阶段稿逐项复算得到的新总账。

R6源树43,380点与最终候选41,090点的差额为2,290点。该差额来自删除、合并、下沉与逐项重估后的净变化，不是未分配字段：

`43,380 − 2,290 = 41,090`

所有519项候选现在都有唯一整数科研点。拆分池已经按实际复杂度写死：住区供水、排污、固废为30/30/25；蒸馏、过滤、结晶为25/15/20；固体生物燃料、沼气为45/75；工业锅炉、窑炉为65/50；污水收集、初级处理为35/45；受控栽培为20/25/30。矿石破碎分级保留45点，原85点中40点回重估池。

“后移”只表示该节点不属于当前两年能力闭合路线，不是现实时间卡点。只要玩家提前取得全部技术、实体、产业和试验条件，后移科技仍可提前研发。

## 三、正文审查结论

### 事实门

- 每项先判断是否应作为独立科技存在，再判断名称、前置、实体条件、直接效果、实际产出和科技与工程、生产、制度运行之间的边界。
- 事实门未通过的节点不保留正文；后移节点只保留未来条件、未来结果和当前不开放边界。
- 科研不自动建设设施、完成工程、生产产品、组建部队、生成调查结论或改变地点状态。
- 玩家可见科技名称最多七个汉字，只含汉字，不以短标题掩盖实际仍然混合的多项能力。

### 文风门

- 当前有效科技正文写玩家在研究完成后获得的稳定能力变化，不把正文写成施工步骤、培训说明、审计报告、效果字段复述或通用免责声明。
- 完全严肃科技只保留一段正文。第二行只允许承担已经通过资格审查和因果审查的笑话或黑色幽默；本轮机器复核未发现无意义第二行。
- 黑色幽默只用于适合呈现战前社会遗产后果的科技，不把政策、法令、医疗保护或风险识别科技写成由本科技制造伤害。
- 第一阶段已按revision24重新审查；`ELC-SAF-001`删除抽象产品“基础电气备件”，改为实际备件条件以及故障定位、隔离、检修和复测能力。

## 五、资源链终局边界

当前两年终局不为以下物料擅自增加未经R7逐项审查的本地生产科技：纯碱、锌、锡、电工钢片、漆包铜绕组线、绕组浸渍绝缘料、高铝原料及结合料。

这些物料当前只可来自遗产库存回收、遗产设备拆取并检验、外部贸易或已有明确生产节点的实际合格批次。玻璃、H62黄铜、CuSn10锡青铜、Y90S-4电动机和高铝耐材继续标记为`CONDITIONAL_PRODUCTION`，不得宣称本地全链闭合，也不得把贸易与遗产供应写成永久可靠。

当前结构钢路线只读取`MET-IRN-001 废钢炼钢`和实际合格钢坯。铁矿评价、选矿和储量核算不能直接生成Q235B钢材；铁矿炼铁在炉料、还原、精炼与炉气处理路线逐项通过审查以前整体后移。
