# 完整 Demo 正式资产需求清单

## 1. 总原则

正式资产不按“页面截图”整张生成。空间结构、道路、铁路、管线、边界、六角格、选择轮廓、图表、进度、按钮、文字与状态标记必须由程序绘制；位图只承担地形细节、设施主体、产品装备和事件画面。

每张资产在进入产品前必须同时登记：稳定资产 ID、类型、母版画布、透明内容边界、安全框、底部锚点、地图占地或显示槽位、允许缩放范围、遮挡优先级、光照方向、颜色版本、来源与验收截图。

## 2. 程序生成资产

| 类别 | 生成方式 | 必须状态 |
|---|---|---|
| 标准六角格与格坐标 | Canvas 或 SVG | 默认隐藏、空间裁决时显示 |
| 区域边界与多格并集轮廓 | Canvas 或 SVG | 正常、选中、冲突、禁建 |
| 公路、铁路、输电、供水、通信 | Canvas 或 SVG | 规划、施工、运行、受损、断开 |
| 地图地点标记 | SVG 图标系统 | 普通、重点、风险、选中、不可用 |
| 部队标号与行动箭头 | SVG | 友方、未知、敌对、补给受限 |
| UI 面板与控件 | CSS 与 SVG | 默认、悬停、选中、禁用、警告 |
| 图表与进度 | Canvas 或 CSS | 不以位图固化数字 |

## 3. 地图位图资产

### 3.1 地形纹理

- 类型：裸地、草地、林地、耕地、湿地、碎石、废墟、污染地、河岸和积雪。
- 母版：`1024×1024`无缝纹理，RGBA 或无透明 RGB；至少四个无明显重复方向的变化。
- 使用：只提供细节与材质，地形类型和通行规则仍由格数据决定。
- 验收：50%、100%、200%缩放无接缝；连续铺设八乘八后不出现明显图章重复。

### 3.2 地点与设施主体

- 母版统一：`1536×1024` RGBA。
- 安全框：`x=122…1414`、`y=61…942`。
- 锚点：底边中心；阴影单独图层或由渲染器生成。
- 首批类别：避难所入口、临时聚居地、标准聚居区、农区中心、矿区、取水设施、发电设施、变电站、仓库、标准工厂、联合工业区、医院、学校、行政中心、警察驻地、军营、机场、发射场与空间港。
- 每类至少提供：正常、在建、受损、停运四个状态；大型设施另有扩建阶段。
- 地图远尺度不直接绘制完整设施位图，只显示地点标记、占地和状态。

### 3.3 工程阶段资产

- 标准建筑至少提供场址准备、基础施工、主体结构、设备安装、联调投产五个地图状态；道路、铁路和管线使用对应的线路阶段状态。
- 阶段资产沿用同一地点锚点与逻辑占地，切换阶段不得造成建筑跳位、缩放或覆盖范围改变。
- 阶段变化必须来自实际工程状态，不能把五张贴图做成玩家可随意切换的装饰皮肤。
- 工程面板不需要施工现场大图；工程资产预算优先投入地图阶段贴图。

## 4. 系统页面位图资产

| 页面 | 资产 | 建议槽位 | 备注 |
|---|---|---:|---|
| 科研 | 技术主题插图 | 960×540 | 不在图内写名称、效果或数字 |
| 工程 | 工程现场阶段图 | 1280×720 | 勘察、基础、主体、安装、建成五阶段 |
| 生产 | 产品插图 | 768×768 | 单一产品透明背景，不把多个产物拼成礼包 |
| 治理 | 制度类别徽记 | SVG 优先 | 不制作人物宣传海报替代制度状态 |
| 军事 | 装备与兵种剪影 | 1024×1024 | 统一视角、比例和光照，不内嵌型号字 |
| 事件 | 世界内场景画面 | 1280×720 | 必须对应具体地点、人物、因果与选择 |

## 5. 军事首批资产

- 单兵与班组：步枪、班组自动武器、轻型迫击炮、通信器材、战斗救护器材。
- 运输与保障：中型卡车、野战维修车、救护车、工兵器材、野战通信车。
- 部队类型标志：守备、轻步兵、侦察、工兵、指挥通信、运输保障、维修回收、野战医疗。
- 每项装备只做一个基础视觉母版，型号迭代通过细节、附件、涂装和状态变化表达，不在一张图内并排比较数值。
- 地图单位另做象征性小队组合：轻步兵为三至五名小人和轻武器，运输保障为小人与卡车，装甲单位为车辆和少量伴随人员。它们代表整支部队，不按真实人数或建筑比例绘制。
- 地图单位需要行军、驻防、警戒、交战、受损和撤退状态；远尺度使用同一对象的简化兵种符号，不生成第二套军事地图资产。

## 7. 批量生成门禁

1. 先用每个资产族一至三个校准件验证构图、透明边缘、锚点、缩放、背景和遮挡。
2. 校准件必须在真实产品渲染器的1920×1080、1366×768和保护性窄屏截图中通过。
3. 未通过的校准件保留为失败证据，不覆盖旧文件，不进入批量生成提示。
4. 只有资产族合同通过后才批量生成；批量结果逐张机器检查尺寸、透明边界和清单完整性，再抽样人工视觉检查。
5. 图像模型生成稿只进入暂存区。进入`src/**`、替换旧资产、提交和推送必须由另行授权的第四层任务完成。
