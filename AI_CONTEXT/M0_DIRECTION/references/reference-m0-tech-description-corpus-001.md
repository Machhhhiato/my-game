| 部门交接 | 每个部门都完成了自己的工作，合起来却得到荒唐结果 |

### 8.4 已确认的写作质量门

正式写作前必须在草稿层跑通：

```text
科技具体改变了什么
→ 必然产生什么结果
→ 哪个相关但不直接负责科技的人因此必须改变工作
→ 玩家最终只看见这个人的一个侧面
```

退稿检查：

- 回答不了`这个人为什么一定会遇到它`，直接退稿；
- 换成不相关科技仍然成立，直接退稿；
- 只是把两个黑暗元素摆在一起，没有实际工作原因，直接退稿；
- 为了压成一句话而删掉必要线索，直接退稿；
- 把完整因果全部解释给玩家，也要重写；
- 玩家看完需要作者另行解释，不是留白，而是缺逻辑。

`一个侧面`只限制观察角度，不限制句数。载体可以是一句抱怨、短对话、两三句小场景、工作记录或生活细节；应按理解所需选择，不建立新固定模板。

### 9.1 第六项比例提案原文 · M0-S003-A171

~~~~text
下一步是第六项最后一块：确定三档比例。

我建议采用：

- `完全严肃：60%`
- `中度：30%`
- `重度：不超过10%`

换成玩家感受，就是每看到约10条新正文：

- 6条认真讲科技、工程和文明进步；
~~~~
