# NIGHT-M0-L4-402-R2-001 界面骨架修订报告

## 结论

用户接受的交互方向已经落为可操作界面：顶部资源显示名称，总部管理既有建筑岗位，科研呈现可点击的前置路径，探索只处理勘测，工程负责设施选择与地图落点，生产按整座工厂分配，日志只记录事实。当前状态为 `implemented_waiting_user_recheck`，不进入 `M0-L4-403`。

## 实现内容

- 资源：顶部同时显示资源名、库存与适用时的月度变化；不再依靠悬停才能知道资源种类。
- 总部：研究室和四类日常设施使用紧凑岗位行。研究室可启停、增减开放岗位；科研速度由启用设施的开放岗位和实际入职共同决定。
- 科研：删除玩家直接指定科研人数、远期目标按钮和解释性系统段落。两项现有科技按前置关系展示；选择后置科技会自动把未完成前置加入队列。“自动”是唯一自动模式按钮。
- 探索：只保留正在勘测的目标、当前地图选择和无人机状态。已经确认的候选地不继续占用探索页。
- 工程：建造、建设中和地块分为三个子页。建造先选设施，再从球面选择兼容地块；不兼容地块不能开工。已确认候选地和已建设施在地块页归档。
- 生产：使用当前唯一真实精密工坊形成两条产品线。投入单位是整座工厂，界面显示产品、单厂批次产量、原料、来源和去向；没有引入新的抽象生产力滑杆。
- 日志：只显示按时间发生的世界事实。泛化资产页和维修页从当前骨架移除。
- 存档：版本升为 v6。研究设施新增开放岗位字段，严格校验开放岗位不超过容量；旧 M0 存档不迁移。
