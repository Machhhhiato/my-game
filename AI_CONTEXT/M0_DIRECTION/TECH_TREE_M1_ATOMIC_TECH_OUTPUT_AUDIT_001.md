# M1 单项科技与独立产物重建审计 R3

> 这是结构审计，不是科技树摘要。每一行都对应 R2 的一个候选节点，并说明它在 R3 中被保留还是拆分。

- R2 候选：278 项
- R3 单项科技：611 项
- 独立产物：1485 项
- 科技前置关系：2784 条
- 科技到产物关系：2027 条
- 时间线：只用于科研难度与讨论周期，不形成日期门槛。

## 判定口径

1. 科技必须是可独立教学、验证与复现的方法、工艺、设计、标准或战术。
2. 产品、设施、工程、行动、记录、组织、编制、训练、协议、有限期政策选项全部是独立产物对象。
3. 研究只解锁资格，不自动生产、建设、执行、组建、签署或施行。
4. 原有汇总项只在其组成部分确实不可分时保留。
